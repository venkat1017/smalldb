2. The problem: our commands are not SQL

Our Part 5 shell was useful for learning storage, but it invented commands such as:

CREATE users name:TEXT(32) email:TEXT(64) age:INT
INSERT users alice alice@example.com 30
GET users 1
SCAN users

Those commands are not SQL. More importantly, the implementation used strings.Fields. That means the command language had almost no grammar. Whitespace simply chopped the line into words.

Try to insert a name with a space

What should INSERT users Alice Smith alice@example.com 30 mean? Is Alice the name and Smith the email? Is the name two words? A whitespace splitter cannot know, because we never gave the language rules for quoting or punctuation.

SQL fixes this by having syntax. We can write:

INSERT INTO users VALUES ('Alice Smith', 'alice@example.com', 30, true, NULL);

The commas, parentheses, keywords, quoted strings, boolean literal, NULL, and semicolon all carry meaning. That means our program must stop thinking in terms of “words separated by spaces” and start thinking in terms of a language.

Keep these questions separate

This separation is not academic. It explains why SELECT * FROM users WHERE age = 30; can be perfectly valid syntax even if our Part 6 executor does not yet know how to execute arbitrary predicates.

5. Lexing: turn characters into tokens

The lexer reads raw characters and emits tokens. A token has at least three useful pieces of information:

type Token struct {
    Kind   TokenKind
    Lexeme string
    Pos    int
}

Kind tells later stages what the token means syntactically. Lexeme preserves the source text or decoded string content. Pos records where the token began so an error can point near the right byte.

For:

SELECT rowid, name FROM users WHERE rowid = 2;

we want something conceptually like:

SELECTIDENT(rowid),IDENT(name)FROMIDENT(users)WHEREIDENT(rowid)=NUMBER(2);
The lexer does not know tables

When the lexer sees users, it should not ask the catalog whether a table called users exists. It only knows that the characters form an identifier. Catalog lookup belongs much later, during execution.

6. Keywords and identifiers are not the same thing

Consider the two words SELECT and users. They are both letter sequences, but one is a reserved keyword in our grammar and the other is usually an identifier.

word := input[start:pos]
if kind, ok := keywords[strings.ToUpper(word)]; ok {
    return Token{Kind: kind, Lexeme: word, Pos: start}
}
return Token{Kind: TokenIdentifier, Lexeme: word, Pos: start}

We normalize only for the keyword lookup. The lexeme can preserve what the user typed. This gives us case-insensitive keywords:

select * from users;
SELECT * FROM users;
SeLeCt * FrOm users;

All three produce the same keyword token kinds. Table and column lookup in our storage layer is already case-insensitive, so the pieces fit naturally.

7. String literals are where naive splitting breaks

The first place strings.Fields truly fails is text. SQL needs a way to say “these spaces are part of one value.” We use single-quoted string literals:

INSERT INTO users VALUES ('Alice Smith', 'alice@example.com', 30, true, NULL);

The lexer must enter a different mode after the opening quote: keep consuming characters until the matching quote. Spaces and commas inside the string are data, not token separators.

We also support the classic SQL-style way to include an apostrophe: double it.

INSERT INTO notes VALUES ('Ada''s note', 'hello world');

The token value becomes Ada's note. The pair '' is not the end of the string; it represents one quote character inside the value.

Why positions are byte positions

The storage engine already measures bounded TEXT in UTF-8 bytes. The lexer keeps its implementation small by tracking byte offsets too. That is fine for this chapter, but a production editor-quality parser might also track line/column positions and Unicode-aware character offsets.

8. Build the lexer one token at a time

Now we can implement nextToken() as a decision tree. Skip whitespace. If we reached the end, emit EOF. Otherwise inspect the current byte.

switch ch {
case ',': return COMMA
case '(': return LPAREN
case ')': return RPAREN
case ';': return SEMICOLON
case '*': return STAR
case '=': return EQUAL
case ''': return lexString()
}

if digit or '-' followed by digit:
    lex a NUMBER

if identifier-start:
    lex a word
    keyword lookup or IDENT

otherwise:
    lexical error

This code has an important property: it always either consumes input or returns an error. A lexer that can stay at the same position forever will hang the REPL.

10. Why tokens still are not enough

Tokens tell us what pieces exist, but not how they relate. The token sequence:

SELECT IDENT COMMA IDENT FROM IDENT WHERE IDENT EQUAL NUMBER

still needs structure. Which identifier is the table? Which identifiers are projections? Which tokens belong to the condition? Could the same IDENT EQUAL NUMBER appear somewhere else in a future grammar?

This is the parser's job. The parser checks whether the token stream matches the grammar and builds a structured representation of the statement.

11. Write the grammar before the parser

Writing the grammar before the parser prevents the code from becoming a pile of ad-hoc “if next token is…” rules. Here is the complete Part 6 language in compact EBNF-like notation:

statement = create_table | insert | select | delete ; create_table = CREATE TABLE identifier "(" column_def ("," column_def)* ")" [";"] ; column_def = identifier type_spec [NULL | NOT NULL] ; type_spec = INT | BOOL | TEXT "(" number ")" ; insert = INSERT INTO identifier VALUES "(" literal ("," literal)* ")" [";"] ; select = SELECT ("*" | identifier ("," identifier)*) FROM identifier [WHERE equality] [";"] ; delete = DELETE FROM identifier WHERE equality [";"] ; equality = identifier "=" literal ; literal = number | string | TRUE | FALSE | NULL ;

Notice how small it is. This grammar is not “SQL.” It is our Part 6 SQL subset. Being explicit about that boundary lets us produce useful errors instead of pretending unsupported syntax should somehow work.

12. AST: represent meaning, not punctuation

The parser should not hand the executor a bag of tokens. We want an abstract syntax tree: a Go value that represents the meaning of the statement after punctuation has done its job.

type Statement interface { statementNode() }

type CreateTableStmt struct {
    Name    string
    Columns []ColumnDef
}

type InsertStmt struct {
    Table  string
    Values []Literal
}

type SelectStmt struct {
    All     bool
    Columns []string
    Table   string
    Where   Expr
}

The AST for SELECT rowid, name FROM users WHERE rowid = 2; does not need to remember the comma or semicolon. Those characters helped the parser understand the statement, but they are not part of the semantic result.

Why “abstract” syntax tree?

Because it throws away concrete spelling details that no longer matter. Uppercase vs lowercase keywords, commas, and parentheses around the VALUES list are syntax. The AST keeps the table name, selected columns, values, and expression structure that later stages actually need.

13. Recursive descent: one grammar rule, one function

Our grammar is simple enough for a hand-written recursive-descent parser. The basic idea is wonderfully literal: one parser function corresponds to one grammar rule.

ParseStatement()
    ├── parseCreateTable()
    ├── parseInsert()
    ├── parseSelect()
    └── parseDelete()

parseSelect()
    └── parseEquality()   // only if WHERE appears

parseCreateTable()
    └── parseTypeSpec()

The parser maintains a cursor into the token slice. Three tiny helpers do most of the control work:

peek()               // look without consuming
advance()            // consume one token
expect(kind, message) // consume required token or return an error
match(kind)           // consume optional token if present

This makes parser code read almost like the grammar itself.

14. Parse CREATE TABLE

Start with a statement whose structure is visible: CREATE TABLE.

CREATE TABLE users (
    name TEXT(32) NOT NULL,
    email TEXT(64) NOT NULL,
    age INT NOT NULL,
    active BOOL NOT NULL,
    nickname TEXT(20)
);

The parser consumes CREATE, requires TABLE, requires a table identifier, requires (, then loops over column definitions separated by commas until it reaches ).

CREATE
  expect TABLE
  expect table identifier
  expect '('

  parse column
  while comma:
      parse next column

  expect ')'

Each column definition delegates the type syntax to parseTypeSpec(). That keeps parseCreateTable() focused on table grammar instead of mixing in TEXT-length rules.

15. SQL nullability changes one Part 5 assumption

Part 5 used a teaching shorthand where a trailing ? meant nullable. SQL has a more explicit convention, so Part 6 changes only the surface syntax.

Part 5 custom syntaxPart 6 SQL
name:TEXT(32)name TEXT(32) NOT NULL
nickname:TEXT(20)?nickname TEXT(20)

For our SQL subset, columns are nullable by default unless NOT NULL is present. The parser records that as a boolean in ColumnDef. The executor later converts the AST column definition into the existing Part 5 Column structure.

Same storage metadata, new syntax

The catalog does not care whether nullability came from a question mark in Part 5 or the words NOT NULL in Part 6. Both end up as the same persisted Nullable flag. This is exactly why layering matters.

16. Parse INSERT INTO ... VALUES

INSERT gives us our first list of typed literals:

INSERT INTO users VALUES ('Alice Smith', 'alice@example.com', 30, true, NULL);

The parser does not yet decide whether 30 is valid for the third column of users. It simply records an integer literal. It does not know the users schema yet.

type Literal struct {
    Kind LiteralKind
    Int  int64
    Text string
    Bool bool
}

That means parsing an INSERT can succeed even when execution later fails because the table expects a different number of values or a different type. Again: syntax and semantics are separate.

17. Parse SELECT projections and FROM

For SELECT, we support either a star or a comma-separated list of identifiers:

SELECT * FROM users;
SELECT rowid, name, age FROM users;

The AST records either All: true or a list such as ["rowid", "name", "age"]. Then it stores the table after FROM.

Notice what the parser still does not know: whether age actually exists in that table. A statement like SELECT banana FROM users; is grammatically valid. Column resolution belongs to the executor because it requires the catalog/schema.

18. Parse WHERE as an expression tree

Instead of baking rowid = 2 directly into SelectStmt, we introduce expression nodes:

type IdentifierExpr struct { Name string }
type LiteralExpr struct    { Value Literal }
type BinaryExpr struct {
    Left     Expr
    Operator TokenKind
    Right    Expr
}

So:

WHERE rowid = 2

becomes:

Binary EQUAL
  Identifier rowid
  Literal INT 2

Today, parseEquality() only understands one operator: =. But the tree shape gives us somewhere to grow later. <, >, AND, OR, arithmetic, and parentheses would extend the expression grammar rather than contaminate the SELECT parser.

19. Parse DELETE safely

We require a WHERE clause for DELETE in Part 6:

DELETE FROM users WHERE rowid = 2;

This is not a claim about standard SQL. It is a safety and scope decision for our tiny implementation. We have not implemented full-table delete semantics, and an accidental DELETE FROM users; would be a nasty surprise in a learning REPL.

The parser can therefore give an immediate message if WHERE is missing, before the executor or storage layer is touched.

20. Good parser errors are part of the design

A parser is also an error-reporting system. Compare these two experiences:

error

parse error at byte 0 near "SELEC": expected CREATE, INSERT, SELECT, or DELETE

Our expect() helper receives a message describing what grammar rule failed. The token carries the position and lexeme. Together they produce errors that teach the user what the parser wanted.

The lexer does the same for malformed strings:

22. Execution is a separate layer

Now we cross the boundary from language to database semantics. The executor receives a Statement and dispatches on its concrete AST type.

switch s := stmt.(type) {
case *CreateTableStmt:
    ...
case *InsertStmt:
    ...
case *SelectStmt:
    ...
case *DeleteStmt:
    ...
}

This is where table lookup, column lookup, schema type checking, B+tree access, and scans become legal. The parser should remain reusable even if the execution engine changes later.

A useful mental boundary

The parser answers: “What did the user ask for?”
The executor answers: “Can this database do that request, and which storage operation performs it?”

23. Execute CREATE TABLE through the Part 5 catalog

Executing CREATE is mostly translation. The AST has syntax-oriented ColumnDef values. The Store expects storage-oriented Column values.

for each AST column:
    Column{
        Name:     def.Name,
        Type:     def.Type.Type,
        MaxLen:   def.Type.TextLen,
        Nullable: def.Nullable,
    }

store.CreateTable(statement.Name, columns)

From that point downward, all the Part 5 machinery runs unchanged: schema compilation computes offsets, a B+tree root page is allocated, the table is written to the catalog, and metadata is updated.

This is a major payoff from the earlier architecture. SQL parsing is not rewriting the database engine. It is feeding a cleaner interface into it.

25. Execute SELECT: scan or indexed rowid lookup

SELECT lets us reconnect SQL to the performance story from Part 4.

No WHERE

SELECT * FROM users;

The executor calls Store.Scan. We must visit the table's rows because no usable predicate identifies one row.

rowid equality

SELECT * FROM users WHERE rowid = 42;

The executor extracts rowid 42 and calls Store.Get, which follows the persistent B+tree.

This is our first tiny taste of planning, but we keep it deliberately simple. There is no optimizer object. The executor has exactly two paths for SELECT in Part 6.

The parser does not choose the access path

The AST for the WHERE clause merely says “rowid equals 42.” Choosing Store.Get instead of Store.Scan is an execution decision. That distinction becomes essential once databases have multiple indexes and more complicated predicates.

26. Projection: SELECT * is not the same as SELECT name

SELECT * and SELECT name, age should not return the same shape. The executor resolves each requested name against the table schema and builds a projection.

SELECT * FROM users;
// output columns: rowid + every user column

SELECT rowid, name, age FROM users;
// output columns: exactly rowid, name, age

In this teaching database, we choose to include the implicit rowid in * output so the physical/index identity stays visible. That is a MiniSQLite teaching choice; do not infer that every SQL engine exposes hidden row identifiers this way.

A misspelled projection such as SELECT nmae FROM users; parses but fails during projection resolution with a schema-aware error.

27. Execute DELETE through a rowid predicate

DELETE reuses the same expression structure as SELECT, but the executor applies a stricter rule: the predicate must be rowid = integer.

DELETE FROM users WHERE rowid = 2;

Once the executor extracts 2, it calls Store.Delete. The B+tree finds the record pointer, and the row is tombstoned exactly as in Part 5.

We deliberately do not implement DELETE FROM users WHERE age = 30 by silently scanning and deleting matching rows. That would introduce expression evaluation and multi-row mutation semantics that deserve their own careful design.

29. Replace strings.Fields with a raw-line REPL

The old REPL began with:

parts := strings.Fields(scanner.Text())

That line must disappear from the SQL path. We keep the entire input line intact:

line := strings.TrimSpace(scanner.Text())

if strings.HasPrefix(line, ".") {
    handleMeta(store, line)
    continue
}

stmt, err := ParseSQL(line)
result, err := ExecuteStatement(store, stmt)

Now quoted strings can contain spaces because only the lexer decides where tokens begin and end.

One statement per line for now

The Part 6 REPL accepts one SQL statement per input line, with an optional trailing semicolon. A production shell usually buffers multiple lines until a complete statement terminator is seen. We intentionally postpone that UI feature so the chapter stays focused on lexing and parsing.

31. Lab: parser success can still mean executor rejection

Try this:

SELECT * FROM notes WHERE title = 'Ada''s note';

The lexer succeeds. The parser succeeds. The AST is a perfectly reasonable equality expression. Then execution says:

execution error: Part 6 executor only supports WHERE rowid = <integer>: left side must be rowid
This failure is a success

It proves the layers are doing their own jobs. The parser understands a generic equality shape. The executor honestly reports that its current access/evaluation capability is narrower. We have not polluted the grammar with the storage engine's current limitations.

Contrast that with a true syntax error:

SELEC * FROM notes;
parse error at byte 0 near "SELEC": expected CREATE, INSERT, SELECT, or DELETE

And a lexical error:

INSERT INTO notes VALUES ('oops, 'unterminated');
lex error ... unterminated string literal

32. Compatibility experiment: open a Part 5 database

If you still have a Part 5 database, open it with the Part 6 binary. Because the storage format did not change, the new SQL front end should be able to query the old rows.

./minidb part5.db

This experiment teaches a subtle systems lesson: the query language version and the file-format version are not the same thing. A database can gain syntax features without rewriting every page on disk.

If we had changed page layouts, catalog entry encoding, checksum metadata, or row encoding, then a file-format version discussion would be necessary. We did none of those things here.

33. What we deliberately did not solve

Our SQL front end is intentionally incomplete. The omissions are useful because each one points at a real database subsystem:

Missing featureWhy it is not “just parser work”
WHERE on normal columnsNeeds expression evaluation and usually scan/index planning
AND / OR / comparisonsNeeds precedence, richer AST nodes, evaluator semantics
INSERT column listsNeeds name-to-column mapping, omitted-value/default rules
UPDATENeeds mutation semantics; variable-size rows complicate replacement
JOINNeeds multiple table bindings and a join execution strategy
ORDER BYNeeds sorting or an index order the planner can exploit
TransactionsNeeds atomicity/recovery, not new grammar alone
SQL standard compatibilityRequires a much larger grammar and many semantic rules

The right takeaway is not “our parser is weak.” It is that parsing is only one part of SQL support. Real database behavior lives in the interaction between syntax, semantics, planning, execution, storage, and recovery.

34. Exercises

Exercise 1 — Predict the token stream

Before running .tokens, write the token kinds for INSERT INTO t VALUES ('hello world', -7, false, NULL);. Include punctuation and EOF.

Exercise 2 — Find the layer

For each failure, say whether it belongs to lexer, parser, executor, or storage: unterminated quote; missing FROM; unknown table; checksum mismatch.

Exercise 3 — Add != to the lexer and AST

Add a TokenNotEqual. Do not execute it yet. Make .tokens and .ast understand age != 30 first.

Exercise 4 — Add string position tests

Write table-driven tests for empty strings, doubled apostrophes, spaces, commas inside strings, and unterminated strings.

Exercise 5 — Add INSERT column lists

Support INSERT INTO users (name, age) VALUES ('alice', 30). Decide what omitted columns mean. Nullable? Default? Error? Write the rule before code.

Exercise 6 — Execute non-rowid equality by scanning

Let the parser stay unchanged. Add an executor path that scans rows and evaluates one equality predicate such as age = 30. Measure how many rows/pages are examined.

Exercise 7 — Operator precedence

Design, on paper first, a grammar for age = 30 AND active = true OR name = 'bob'. Which operator binds more tightly? Show the AST you want before coding.

Exercise 8 — Multi-line REPL

Buffer input until a semicolon appears outside a quoted string. Be careful: a semicolon inside 'text; still text' must not end the statement.

Exercise 9 — Parser tests without a database

Write tests that call ParseSQL only. This should prove the parser can be tested independently of files, pages, and B+trees.

Exercise 10 — Senior: separate binding from execution

Introduce a binder/semantic-analysis phase that resolves table and column names into catalog/schema references before execution. Ask what information should be stored in a bound SELECT.

	PageTypeCatalog       PageType = 5
)

func (t PageType) String() string {
	switch t {
	case PageTypeMetadata:
		return "metadata"
	case PageTypeData:
		return "data"
	case PageTypeBTreeLeaf:
		return "btree-leaf"
	case PageTypeBTreeInternal:
		return "btree-internal"
	case PageTypeCatalog:
		return "catalog"
	default:
		return fmt.Sprintf("unknown(%d)", uint8(t))
	}
}

func validPageType(t PageType) bool {
	return t == PageTypeMetadata || t == PageTypeData || t == PageTypeBTreeLeaf || t == PageTypeBTreeInternal || t == PageTypeCatalog
}

type PageHeaderInfo struct {
	Type       PageType
	Number     uint64
	Generation uint64
	Checksum   uint32
}

func initializePageData(data []byte, pageNum uint64, pageType PageType) error {
	if len(data) != PageSize {
		return fmt.Errorf("initialize page: expected %d bytes, got %d", PageSize, len(data))
	}
	if !validPageType(pageType) {
		return fmt.Errorf("initialize page: invalid page type %d", pageType)
	}
	clear(data)
	copy(data[0:4], []byte(PageMagic))
	binary.LittleEndian.PutUint16(data[4:6], PageHeaderVersion)
	data[6] = byte(pageType)
	binary.LittleEndian.PutUint64(data[8:16], pageNum)
	return nil
}

func computePageChecksum(data []byte) (uint32, error) {
	if len(data) != PageSize {
		return 0, fmt.Errorf("checksum: expected %d bytes, got %d", PageSize, len(data))
	}
	h := crc32.NewIEEE()
	_, _ = h.Write(data[:24])
	_, _ = h.Write([]byte{0, 0, 0, 0})
	_, _ = h.Write(data[28:])
	return h.Sum32(), nil
}

func decodePageHeader(data []byte) PageHeaderInfo {
	return PageHeaderInfo{
		Type:       PageType(data[6]),
		Number:     binary.LittleEndian.Uint64(data[8:16]),
		Generation: binary.LittleEndian.Uint64(data[16:24]),
		Checksum:   binary.LittleEndian.Uint32(data[24:28]),
	}
}

func sealPageData(data []byte) (PageHeaderInfo, error) {
	if len(data) != PageSize {
		return PageHeaderInfo{}, fmt.Errorf("seal page: expected %d bytes, got %d", PageSize, len(data))
	}
	generation := binary.LittleEndian.Uint64(data[16:24]) + 1
	binary.LittleEndian.PutUint64(data[16:24], generation)
	binary.LittleEndian.PutUint32(data[24:28], 0)
	checksum, err := computePageChecksum(data)
	if err != nil {
		return PageHeaderInfo{}, err
	}
	binary.LittleEndian.PutUint32(data[24:28], checksum)
	return decodePageHeader(data), nil
}

func validatePageData(expectedPageNum uint64, data []byte) (PageHeaderInfo, error) {
	if len(data) != PageSize {
		return PageHeaderInfo{}, fmt.Errorf("page %d: expected %d bytes, got %d", expectedPageNum, PageSize, len(data))
	}
	if string(data[0:4]) != PageMagic {
		return PageHeaderInfo{}, fmt.Errorf("page %d: bad page magic %q", expectedPageNum, string(data[0:4]))
	}
	if got := binary.LittleEndian.Uint16(data[4:6]); got != PageHeaderVersion {
		return PageHeaderInfo{}, fmt.Errorf("page %d: unsupported page-header version %d", expectedPageNum, got)
	}
	info := decodePageHeader(data)
	if !validPageType(info.Type) {
		return PageHeaderInfo{}, fmt.Errorf("page %d: invalid page type %d", expectedPageNum, info.Type)
	}
	if info.Number != expectedPageNum {
		return PageHeaderInfo{}, fmt.Errorf("page %d: stored page number is %d", expectedPageNum, info.Number)
	}
	if info.Checksum == 0 {
		return PageHeaderInfo{}, fmt.Errorf("page %d: missing checksum", expectedPageNum)
	}
	computed, err := computePageChecksum(data)
	if err != nil {
		return PageHeaderInfo{}, err
	}
	if computed != info.Checksum {
		return PageHeaderInfo{}, fmt.Errorf("page %d: checksum mismatch: stored=%08x computed=%08x", expectedPageNum, info.Checksum, computed)
	}
	return info, nil
}

pager.go

package main

import (
	"fmt"
	"io"
	"os"
)

type Page struct {
	Number uint64
	Type   PageType
	Data   []byte
	dirty  bool
}

func (p *Page) MarkDirty() { p.dirty = true }

type PagerStats struct {
	CachedPages        int
	TotalPages         uint64
	CacheHits          uint64
	DiskReads          uint64
	DiskWrites         uint64
	ValidationFailures uint64
}

type Pager struct {
	file               *os.File
	pages              map[uint64]*Page
	numPages           uint64
	cacheHits          uint64
	diskReads          uint64
	diskWrites         uint64
	validationFailures uint64
}

func OpenPager(path string) (*Pager, error) {
	file, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0644)
	if err != nil {
		return nil, err
	}
	info, err := file.Stat()
	if err != nil {
		file.Close()
		return nil, err
	}
	if info.Size()%PageSize != 0 {
		file.Close()
		return nil, fmt.Errorf("database size %d is not a multiple of page size %d", info.Size(), PageSize)
	}
	return &Pager{file: file, pages: make(map[uint64]*Page), numPages: uint64(info.Size() / PageSize)}, nil
}

func (p *Pager) GetPage(pageNum uint64) (*Page, error) {
	if page, ok := p.pages[pageNum]; ok {
		p.cacheHits++
		return page, nil
	}
	if pageNum >= p.numPages {
		return nil, fmt.Errorf("page %d does not exist", pageNum)
	}
	page := &Page{Number: pageNum, Data: make([]byte, PageSize)}
	n, err := p.file.ReadAt(page.Data, int64(pageNum)*PageSize)
	if err != nil && err != io.EOF {
		return nil, fmt.Errorf("read page %d: %w", pageNum, err)
	}
	if n != PageSize {
		return nil, fmt.Errorf("read page %d: expected %d bytes, got %d", pageNum, PageSize, n)
	}
	p.diskReads++
	info, err := validatePageData(pageNum, page.Data)
	if err != nil {
		p.validationFailures++
		return nil, err
	}
	page.Type = info.Type
	p.pages[pageNum] = page
	return page, nil
}

func (p *Pager) NewPage(pageType PageType) (*Page, error) {
	pageNum := p.numPages
	page := &Page{Number: pageNum, Type: pageType, Data: make([]byte, PageSize), dirty: true}
	if err := initializePageData(page.Data, pageNum, pageType); err != nil {
		return nil, err
	}
	p.pages[pageNum] = page
	p.numPages++
	return page, nil
}

func (p *Pager) FlushPage(pageNum uint64) error {
	page, ok := p.pages[pageNum]
	if !ok || !page.dirty {
		return nil
	}
	if _, err := sealPageData(page.Data); err != nil {
		return err
	}
	n, err := p.file.WriteAt(page.Data, int64(pageNum)*PageSize)
	if err != nil {
		return fmt.Errorf("write page %d: %w", pageNum, err)
	}
	if n != PageSize {
		return fmt.Errorf("write page %d: expected %d bytes, wrote %d", pageNum, PageSize, n)
	}
	page.dirty = false
	p.diskWrites++
	return nil
}

func (p *Pager) FlushAll() error {
	for pageNum := range p.pages {
		if err := p.FlushPage(pageNum); err != nil {
			return err
		}
	}
	return p.file.Sync()
}

func (p *Pager) VerifyAll() (uint64, error) {
	if err := p.FlushAll(); err != nil {
		return 0, err
	}
	buf := make([]byte, PageSize)
	for pageNum := uint64(0); pageNum < p.numPages; pageNum++ {
		n, err := p.file.ReadAt(buf, int64(pageNum)*PageSize)
		if err != nil && err != io.EOF {
			return pageNum, fmt.Errorf("verify page %d: %w", pageNum, err)
		}
		if n != PageSize {
			return pageNum, fmt.Errorf("verify page %d: expected %d bytes, got %d", pageNum, PageSize, n)
		}
		if _, err := validatePageData(pageNum, buf); err != nil {
			p.validationFailures++
			return pageNum, err
		}
	}
	return p.numPages, nil
}

func (p *Pager) PageInfo(pageNum uint64) (PageHeaderInfo, error) {
	page, err := p.GetPage(pageNum)
	if err != nil {
		return PageHeaderInfo{}, err
	}
	if page.dirty {
		if err := p.FlushPage(pageNum); err != nil {
			return PageHeaderInfo{}, err
		}
	}
	return validatePageData(pageNum, page.Data)
}

func (p *Pager) Stats() PagerStats {
	return PagerStats{len(p.pages), p.numPages, p.cacheHits, p.diskReads, p.diskWrites, p.validationFailures}
}

func (p *Pager) Close() error {
	flushErr := p.FlushAll()
	closeErr := p.file.Close()
	if flushErr != nil {
		return flushErr
	}
	return closeErr
}

package main

import (
	"encoding/binary"
	"fmt"
	"strings"
)

// BTreeMaxKeys is intentionally tiny so a learner can trigger splits with a
// handful of INSERTs. A production page would use far more of its 4096 bytes.
const BTreeMaxKeys = 7

const (
	nodeKeyCountOffset = PageHeaderSize
	nodeSpecialOffset  = 40 // leaf: next leaf; internal: first child
	nodeEntriesOffset  = 48
	leafEntrySize      = 24
	internalEntrySize  = 16
)

type RecordPointer struct {
	Page uint64
	Slot uint16
}

type leafEntry struct {
	Key int64
	Ptr RecordPointer
}

type internalEntry struct {
	Key        int64
	RightChild uint64
}

type splitResult struct {
	Separator int64
	RightPage uint64
}

type BTree struct {
	pager *Pager
	root  uint64
}

func newBTree(pager *Pager, root uint64) *BTree { return &BTree{pager: pager, root: root} }
func (t *BTree) RootPage() uint64               { return t.root }

func keyCount(page *Page) int {
	return int(binary.LittleEndian.Uint16(page.Data[nodeKeyCountOffset : nodeKeyCountOffset+2]))
}

func setKeyCount(page *Page, n int) {
	binary.LittleEndian.PutUint16(page.Data[nodeKeyCountOffset:nodeKeyCountOffset+2], uint16(n))
	page.MarkDirty()
}

func leafNext(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[nodeSpecialOffset : nodeSpecialOffset+8])
}
func setLeafNext(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[nodeSpecialOffset:nodeSpecialOffset+8], n)
	page.MarkDirty()
}
func internalFirstChild(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[nodeSpecialOffset : nodeSpecialOffset+8])
}
func setInternalFirstChild(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[nodeSpecialOffset:nodeSpecialOffset+8], n)
	page.MarkDirty()
}

func readLeafEntries(page *Page) []leafEntry {
	n := keyCount(page)
	out := make([]leafEntry, 0, n)
	for i := 0; i < n; i++ {
		off := nodeEntriesOffset + i*leafEntrySize
		out = append(out, leafEntry{
			Key: int64(binary.LittleEndian.Uint64(page.Data[off : off+8])),
			Ptr: RecordPointer{Page: binary.LittleEndian.Uint64(page.Data[off+8 : off+16]), Slot: binary.LittleEndian.Uint16(page.Data[off+16 : off+18])},
		})
	}
	return out
}

func writeLeafEntries(page *Page, entries []leafEntry) error {
	if len(entries) > BTreeMaxKeys {
		return fmt.Errorf("leaf page %d overflow: %d keys", page.Number, len(entries))
	}
	clear(page.Data[nodeEntriesOffset:])
	for i, e := range entries {
		off := nodeEntriesOffset + i*leafEntrySize
		binary.LittleEndian.PutUint64(page.Data[off:off+8], uint64(e.Key))
		binary.LittleEndian.PutUint64(page.Data[off+8:off+16], e.Ptr.Page)
		binary.LittleEndian.PutUint16(page.Data[off+16:off+18], e.Ptr.Slot)
	}
	setKeyCount(page, len(entries))
	page.MarkDirty()
	return nil
}

func readInternal(page *Page) ([]int64, []uint64) {
	n := keyCount(page)
	keys := make([]int64, 0, n)
	children := make([]uint64, 0, n+1)
	children = append(children, internalFirstChild(page))
	for i := 0; i < n; i++ {
		off := nodeEntriesOffset + i*internalEntrySize
		keys = append(keys, int64(binary.LittleEndian.Uint64(page.Data[off:off+8])))
		children = append(children, binary.LittleEndian.Uint64(page.Data[off+8:off+16]))
	}
	return keys, children
}

func writeInternal(page *Page, keys []int64, children []uint64) error {
	if len(keys) > BTreeMaxKeys {
		return fmt.Errorf("internal page %d overflow: %d keys", page.Number, len(keys))
	}
	if len(children) != len(keys)+1 {
		return fmt.Errorf("internal page %d: %d keys need %d children, got %d", page.Number, len(keys), len(keys)+1, len(children))
	}
	clear(page.Data[nodeEntriesOffset:])
	setInternalFirstChild(page, children[0])
	for i, key := range keys {
		off := nodeEntriesOffset + i*internalEntrySize
		binary.LittleEndian.PutUint64(page.Data[off:off+8], uint64(key))
		binary.LittleEndian.PutUint64(page.Data[off+8:off+16], children[i+1])
	}
	setKeyCount(page, len(keys))
	page.MarkDirty()
	return nil
}

func (t *BTree) Lookup(key int64) (RecordPointer, int, error) {
	pageNum := t.root
	visits := 0
	for {
		page, err := t.pager.GetPage(pageNum)
		if err != nil {
			return RecordPointer{}, visits, err
		}
		visits++
		switch page.Type {
		case PageTypeBTreeLeaf:
			entries := readLeafEntries(page)
			lo, hi := 0, len(entries)
			for lo < hi {
				mid := lo + (hi-lo)/2
				if entries[mid].Key < key {
					lo = mid + 1
				} else {
					hi = mid
				}
			}
			if lo < len(entries) && entries[lo].Key == key {
				return entries[lo].Ptr, visits, nil
			}
			return RecordPointer{}, visits, ErrNotFound
		case PageTypeBTreeInternal:
			keys, children := readInternal(page)
			childIndex := 0
			for childIndex < len(keys) && key >= keys[childIndex] {
				childIndex++
			}
			pageNum = children[childIndex]
		default:
			return RecordPointer{}, visits, fmt.Errorf("btree: page %d has type %s", page.Number, page.Type)
		}
	}
}

func (t *BTree) Insert(key int64, ptr RecordPointer) error {
	if _, _, err := t.Lookup(key); err == nil {
		return fmt.Errorf("duplicate index key %d", key)
	} else if err != ErrNotFound {
		return err
	}
	split, err := t.insertRecursive(t.root, key, ptr)
	if err != nil {
		return err
	}
	if split == nil {
		return nil
	}
	oldRoot := t.root
	newRoot, err := t.pager.NewPage(PageTypeBTreeInternal)
	if err != nil {
		return err
	}
	if err := writeInternal(newRoot, []int64{split.Separator}, []uint64{oldRoot, split.RightPage}); err != nil {
		return err
	}
	t.root = newRoot.Number
	return nil
}

func (t *BTree) insertRecursive(pageNum uint64, key int64, ptr RecordPointer) (*splitResult, error) {
	page, err := t.pager.GetPage(pageNum)
	if err != nil {
		return nil, err
	}
	switch page.Type {
	case PageTypeBTreeLeaf:
		return t.insertLeaf(page, key, ptr)
	case PageTypeBTreeInternal:
		keys, children := readInternal(page)
		childIndex := 0
		for childIndex < len(keys) && key >= keys[childIndex] {
			childIndex++
		}
		childSplit, err := t.insertRecursive(children[childIndex], key, ptr)
		if err != nil || childSplit == nil {
			return childSplit, err
		}

		keys = append(keys, 0)
		copy(keys[childIndex+1:], keys[childIndex:])
		keys[childIndex] = childSplit.Separator
		children = append(children, 0)
		copy(children[childIndex+2:], children[childIndex+1:])
		children[childIndex+1] = childSplit.RightPage

		if len(keys) <= BTreeMaxKeys {
			return nil, writeInternal(page, keys, children)
		}

		mid := len(keys) / 2
		promoted := keys[mid]
		leftKeys := append([]int64(nil), keys[:mid]...)
		leftChildren := append([]uint64(nil), children[:mid+1]...)
		rightKeys := append([]int64(nil), keys[mid+1:]...)
		rightChildren := append([]uint64(nil), children[mid+1:]...)

		if err := writeInternal(page, leftKeys, leftChildren); err != nil {
			return nil, err
		}
		right, err := t.pager.NewPage(PageTypeBTreeInternal)
		if err != nil {
			return nil, err
		}
		if err := writeInternal(right, rightKeys, rightChildren); err != nil {
			return nil, err
		}
		return &splitResult{Separator: promoted, RightPage: right.Number}, nil
	default:
		return nil, fmt.Errorf("btree insert: page %d has type %s", page.Number, page.Type)
	}
}

func (t *BTree) insertLeaf(page *Page, key int64, ptr RecordPointer) (*splitResult, error) {
	entries := readLeafEntries(page)
	pos := 0
	for pos < len(entries) && entries[pos].Key < key {
		pos++
	}
	if pos < len(entries) && entries[pos].Key == key {
		return nil, fmt.Errorf("duplicate index key %d", key)
	}
	entries = append(entries, leafEntry{})
	copy(entries[pos+1:], entries[pos:])
	entries[pos] = leafEntry{Key: key, Ptr: ptr}
	if len(entries) <= BTreeMaxKeys {
		return nil, writeLeafEntries(page, entries)
	}

	mid := len(entries) / 2
	leftEntries := append([]leafEntry(nil), entries[:mid]...)
	rightEntries := append([]leafEntry(nil), entries[mid:]...)
	oldNext := leafNext(page)
	right, err := t.pager.NewPage(PageTypeBTreeLeaf)
	if err != nil {
		return nil, err
	}
	if err := writeLeafEntries(page, leftEntries); err != nil {
		return nil, err
	}
	if err := writeLeafEntries(right, rightEntries); err != nil {
		return nil, err
	}
	setLeafNext(right, oldNext)
	setLeafNext(page, right.Number)
	return &splitResult{Separator: rightEntries[0].Key, RightPage: right.Number}, nil
}

func (t *BTree) leftmostLeaf() (uint64, error) {
	pageNum := t.root
	for {
		page, err := t.pager.GetPage(pageNum)
		if err != nil {
			return 0, err
		}
		if page.Type == PageTypeBTreeLeaf {
			return pageNum, nil
		}
		if page.Type != PageTypeBTreeInternal {
			return 0, fmt.Errorf("btree: page %d has type %s", page.Number, page.Type)
		}
		pageNum = internalFirstChild(page)
	}
}

func (t *BTree) AllPointers() ([]RecordPointer, error) {
	pageNum, err := t.leftmostLeaf()
	if err != nil {
		return nil, err
	}
	var out []RecordPointer
	for pageNum != 0 {
		page, err := t.pager.GetPage(pageNum)
		if err != nil {
			return nil, err
		}
		if page.Type != PageTypeBTreeLeaf {
			return nil, fmt.Errorf("btree scan: page %d is %s", pageNum, page.Type)
		}
		for _, e := range readLeafEntries(page) {
			out = append(out, e.Ptr)
		}
		pageNum = leafNext(page)
	}
	return out, nil
}

func (t *BTree) Dump() (string, error) {
	var b strings.Builder
	if err := t.dumpPage(&b, t.root, 0); err != nil {
		return "", err
	}
	return b.String(), nil
}

func (t *BTree) dumpPage(b *strings.Builder, pageNum uint64, depth int) error {
	page, err := t.pager.GetPage(pageNum)
	if err != nil {
		return err
	}
	indent := strings.Repeat("  ", depth)
	switch page.Type {
	case PageTypeBTreeLeaf:
		entries := readLeafEntries(page)
		fmt.Fprintf(b, "%sleaf page=%d keys=[", indent, pageNum)
		for i, e := range entries {
			if i > 0 {
				b.WriteString(" ")
			}
			fmt.Fprintf(b, "%d", e.Key)
		}
		fmt.Fprintf(b, "] next=%d\n", leafNext(page))
	case PageTypeBTreeInternal:
		keys, children := readInternal(page)
		fmt.Fprintf(b, "%sinternal page=%d keys=%v children=%v\n", indent, pageNum, keys, children)
		for _, child := range children {
			if err := t.dumpPage(b, child, depth+1); err != nil {
				return err
			}
		}
	default:
		return fmt.Errorf("tree dump: page %d has type %s", pageNum, page.Type)
	}
	return nil
}

package main

import (
	"encoding/binary"
	"fmt"
	"strconv"
	"strings"
)

const (
	MaxColumns       = 10
	MaxColumnNameLen = 24
	MaxTextLen       = 512
	RowHeaderSize    = 24
)

type ColumnType uint8

const (
	TypeInt64 ColumnType = 1
	TypeText  ColumnType = 2
	TypeBool  ColumnType = 3
)

func (t ColumnType) String() string {
	switch t {
	case TypeInt64:
		return "INT"
	case TypeText:
		return "TEXT"
	case TypeBool:
		return "BOOL"
	default:
		return fmt.Sprintf("UNKNOWN(%d)", uint8(t))
	}
}

type Column struct {
	Name     string
	Type     ColumnType
	Nullable bool
	MaxLen   uint16
	Offset   uint16
	Width    uint16
}

type Schema struct {
	Columns []Column
	RowSize uint32
}

type Value struct {
	Type ColumnType
	Null bool
	Int  int64
	Text string
	Bool bool
}

type Row struct {
	RowID   int64
	Deleted bool
	Values  []Value
}

func columnWidth(c Column) (uint16, error) {
	switch c.Type {
	case TypeInt64:
		return 8, nil
	case TypeBool:
		return 1, nil
	case TypeText:
		if c.MaxLen == 0 || c.MaxLen > MaxTextLen {
			return 0, fmt.Errorf("TEXT length must be between 1 and %d", MaxTextLen)
		}
		return 2 + c.MaxLen, nil
	default:
		return 0, fmt.Errorf("unsupported column type %d", c.Type)
	}
}

func CompileSchema(columns []Column) (Schema, error) {
	if len(columns) == 0 {
		return Schema{}, fmt.Errorf("a table needs at least one column")
	}
	if len(columns) > MaxColumns {
		return Schema{}, fmt.Errorf("at most %d columns are supported", MaxColumns)
	}
	seen := map[string]bool{}
	compiled := make([]Column, len(columns))
	offset := RowHeaderSize
	for i, c := range columns {
		if c.Name == "" || len([]byte(c.Name)) > MaxColumnNameLen {
			return Schema{}, fmt.Errorf("column %q must be 1..%d bytes", c.Name, MaxColumnNameLen)
		}
		key := strings.ToLower(c.Name)
		if seen[key] {
			return Schema{}, fmt.Errorf("duplicate column name %q", c.Name)
		}
		seen[key] = true
		width, err := columnWidth(c)
		if err != nil {
			return Schema{}, fmt.Errorf("column %s: %w", c.Name, err)
		}
		if offset+int(width) > 65535 {
			return Schema{}, fmt.Errorf("row layout is too large")
		}
		c.Offset = uint16(offset)
		c.Width = width
		compiled[i] = c
		offset += int(width)
	}
	// Round rows to 8 bytes so offsets are easier to inspect in a hex dump.
	if rem := offset % 8; rem != 0 {
		offset += 8 - rem
	}
	if offset > PageSize-dataRowsOffset {
		return Schema{}, fmt.Errorf("row size %d is too large to fit in one data page", offset)
	}
	return Schema{Columns: compiled, RowSize: uint32(offset)}, nil
}

func ParseColumnSpec(spec string) (Column, error) {
	pair := strings.SplitN(spec, ":", 2)
	if len(pair) != 2 || pair[0] == "" || pair[1] == "" {
		return Column{}, fmt.Errorf("column spec %q must look like name:INT, name:BOOL, or name:TEXT(40)", spec)
	}
	name := pair[0]
	typeSpec := pair[1]
	nullable := false
	if strings.HasSuffix(typeSpec, "?") {
		nullable = true
		typeSpec = strings.TrimSuffix(typeSpec, "?")
	}
	upper := strings.ToUpper(typeSpec)
	c := Column{Name: name, Nullable: nullable}
	switch {
	case upper == "INT" || upper == "INTEGER" || upper == "INT64":
		c.Type = TypeInt64
	case upper == "BOOL" || upper == "BOOLEAN":
		c.Type = TypeBool
	case strings.HasPrefix(upper, "TEXT(") && strings.HasSuffix(upper, ")"):
		raw := upper[len("TEXT(") : len(upper)-1]
		n, err := strconv.Atoi(raw)
		if err != nil || n < 1 || n > MaxTextLen {
			return Column{}, fmt.Errorf("TEXT length in %q must be 1..%d", spec, MaxTextLen)
		}
		c.Type = TypeText
		c.MaxLen = uint16(n)
	default:
		return Column{}, fmt.Errorf("unsupported type %q", typeSpec)
	}
	return c, nil
}

func ParseValueToken(c Column, token string) (Value, error) {
	if strings.EqualFold(token, "NULL") {
		if !c.Nullable {
			return Value{}, fmt.Errorf("column %s is NOT NULL", c.Name)
		}
		return Value{Type: c.Type, Null: true}, nil
	}
	v := Value{Type: c.Type}
	switch c.Type {
	case TypeInt64:
		n, err := strconv.ParseInt(token, 10, 64)
		if err != nil {
			return Value{}, fmt.Errorf("column %s expects INT, got %q", c.Name, token)
		}
		v.Int = n
	case TypeBool:
		switch strings.ToLower(token) {
		case "true", "1", "yes":
			v.Bool = true
		case "false", "0", "no":
			v.Bool = false
		default:
			return Value{}, fmt.Errorf("column %s expects BOOL, got %q", c.Name, token)
		}
	case TypeText:
		if len([]byte(token)) > int(c.MaxLen) {
			return Value{}, fmt.Errorf("column %s allows at most %d UTF-8 bytes", c.Name, c.MaxLen)
		}
		v.Text = token
	default:
		return Value{}, fmt.Errorf("column %s has unsupported type %d", c.Name, c.Type)
	}
	return v, nil
}

func setNullBit(buf []byte, index int) {
	byteIndex := 16 + index/8
	bit := uint(index % 8)
	buf[byteIndex] |= 1 << bit
}

func nullBit(buf []byte, index int) bool {
	byteIndex := 16 + index/8
	bit := uint(index % 8)
	return buf[byteIndex]&(1<<bit) != 0
}

func EncodeRow(schema Schema, rowID int64, values []Value) ([]byte, error) {
	if len(values) != len(schema.Columns) {
		return nil, fmt.Errorf("expected %d values, got %d", len(schema.Columns), len(values))
	}
	buf := make([]byte, schema.RowSize)
	binary.LittleEndian.PutUint64(buf[8:16], uint64(rowID))
	for i, c := range schema.Columns {
		v := values[i]
		if v.Null {
			if !c.Nullable {
				return nil, fmt.Errorf("column %s is NOT NULL", c.Name)
			}
			setNullBit(buf, i)
			continue
		}
		if v.Type != c.Type {
			return nil, fmt.Errorf("column %s type mismatch", c.Name)
		}
		off := int(c.Offset)
		switch c.Type {
		case TypeInt64:
			binary.LittleEndian.PutUint64(buf[off:off+8], uint64(v.Int))
		case TypeBool:
			if v.Bool {
				buf[off] = 1
			}
		case TypeText:
			raw := []byte(v.Text)
			if len(raw) > int(c.MaxLen) {
				return nil, fmt.Errorf("column %s allows at most %d UTF-8 bytes", c.Name, c.MaxLen)
			}
			binary.LittleEndian.PutUint16(buf[off:off+2], uint16(len(raw)))
			copy(buf[off+2:off+2+len(raw)], raw)
		}
	}
	return buf, nil
}

func DecodeRow(schema Schema, buf []byte) (Row, error) {
	if len(buf) != int(schema.RowSize) {
		return Row{}, fmt.Errorf("decode row: expected %d bytes, got %d", schema.RowSize, len(buf))
	}
	row := Row{
		RowID:   int64(binary.LittleEndian.Uint64(buf[8:16])),
		Deleted: buf[0]&1 != 0,
		Values:  make([]Value, len(schema.Columns)),
	}
	for i, c := range schema.Columns {
		v := Value{Type: c.Type}
		if nullBit(buf, i) {
			v.Null = true
			row.Values[i] = v
			continue
		}
		off := int(c.Offset)
		switch c.Type {
		case TypeInt64:
			v.Int = int64(binary.LittleEndian.Uint64(buf[off : off+8]))
		case TypeBool:
			v.Bool = buf[off] != 0
		case TypeText:
			n := int(binary.LittleEndian.Uint16(buf[off : off+2]))
			if n > int(c.MaxLen) {
				return Row{}, fmt.Errorf("column %s has invalid text length %d", c.Name, n)
			}
			v.Text = string(buf[off+2 : off+2+n])
		default:
			return Row{}, fmt.Errorf("column %s has unsupported type %d", c.Name, c.Type)
		}
		row.Values[i] = v
	}
	return row, nil
}

func FormatValue(v Value) string {
	if v.Null {
		return "NULL"
	}
	switch v.Type {
	case TypeInt64:
		return strconv.FormatInt(v.Int, 10)
	case TypeBool:
		return strconv.FormatBool(v.Bool)
	case TypeText:
		return v.Text
	default:
		return "<?>"
	}
}

package main

import (
	"encoding/binary"
	"fmt"
	"strings"

const (
	MaxTableNameLen = 32

	catalogSlotCountOffset = PageHeaderSize
	catalogNextPageOffset  = 40
	catalogEntriesOffset   = 64
	CatalogEntrySize       = 512
	CatalogSlotsPerPage    = (PageSize - catalogEntriesOffset) / CatalogEntrySize

	catalogActiveOffset    = 0
	catalogNameLenOffset   = 1
	catalogColumnCountOff  = 2
	catalogRowSizeOffset   = 4
	catalogTableIDOffset   = 8
	catalogRootPageOffset  = 16
	catalogFirstDataOffset = 24
	catalogLastDataOffset  = 32
	catalogNextRowIDOffset = 40
	catalogNameOffset      = 48
	catalogColumnsOffset   = 80

	catalogColumnSize       = 40
	catalogColTypeOffset    = 0
	catalogColNullableOff   = 1
	catalogColNameLenOffset = 2
	catalogColMaxLenOffset  = 4
	catalogColRowOffOffset  = 6
	catalogColWidthOffset   = 8
	catalogColNameOffset    = 16
)

type CatalogPointer struct {
	Page uint64
	Slot uint16
}

type Table struct {
	ID        uint64
	Name      string
	Schema    Schema
	tree      *BTree
	firstData uint64
	lastData  uint64
	nextRowID int64
	catalog   CatalogPointer
}

func catalogSlotCount(page *Page) int {
	return int(binary.LittleEndian.Uint16(page.Data[catalogSlotCountOffset : catalogSlotCountOffset+2]))
}

func setCatalogSlotCount(page *Page, n int) {
	binary.LittleEndian.PutUint16(page.Data[catalogSlotCountOffset:catalogSlotCountOffset+2], uint16(n))
	page.MarkDirty()
}

func catalogNextPage(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[catalogNextPageOffset : catalogNextPageOffset+8])
}

func setCatalogNextPage(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[catalogNextPageOffset:catalogNextPageOffset+8], n)
	page.MarkDirty()
}

func catalogEntryRange(slot int) (int, int, error) {
	if slot < 0 || slot >= CatalogSlotsPerPage {
		return 0, 0, fmt.Errorf("catalog slot %d out of range", slot)
	}
	start := catalogEntriesOffset + slot*CatalogEntrySize
	return start, start + CatalogEntrySize, nil
}

func writeCatalogEntry(page *Page, slot int, t *Table) error {
	if page.Type != PageTypeCatalog {
		return fmt.Errorf("page %d is %s, expected catalog", page.Number, page.Type)
	}
	if len([]byte(t.Name)) == 0 || len([]byte(t.Name)) > MaxTableNameLen {
		return fmt.Errorf("table name must be 1..%d bytes", MaxTableNameLen)
	}
	if len(t.Schema.Columns) > MaxColumns {
		return fmt.Errorf("table %s has too many columns", t.Name)
	}
	start, end, err := catalogEntryRange(slot)
	if err != nil {
		return err
	}
	entry := page.Data[start:end]
	clear(entry)
	entry[catalogActiveOffset] = 1
	entry[catalogNameLenOffset] = byte(len([]byte(t.Name)))
	entry[catalogColumnCountOff] = byte(len(t.Schema.Columns))
	binary.LittleEndian.PutUint32(entry[catalogRowSizeOffset:catalogRowSizeOffset+4], t.Schema.RowSize)
	binary.LittleEndian.PutUint64(entry[catalogTableIDOffset:catalogTableIDOffset+8], t.ID)
	binary.LittleEndian.PutUint64(entry[catalogRootPageOffset:catalogRootPageOffset+8], t.tree.RootPage())
	binary.LittleEndian.PutUint64(entry[catalogFirstDataOffset:catalogFirstDataOffset+8], t.firstData)
	binary.LittleEndian.PutUint64(entry[catalogLastDataOffset:catalogLastDataOffset+8], t.lastData)
	binary.LittleEndian.PutUint64(entry[catalogNextRowIDOffset:catalogNextRowIDOffset+8], uint64(t.nextRowID))
	copy(entry[catalogNameOffset:catalogNameOffset+MaxTableNameLen], []byte(t.Name))

	for i, c := range t.Schema.Columns {
		off := catalogColumnsOffset + i*catalogColumnSize
		col := entry[off : off+catalogColumnSize]
		col[catalogColTypeOffset] = byte(c.Type)
		if c.Nullable {
			col[catalogColNullableOff] = 1
		}
		col[catalogColNameLenOffset] = byte(len([]byte(c.Name)))
		binary.LittleEndian.PutUint16(col[catalogColMaxLenOffset:catalogColMaxLenOffset+2], c.MaxLen)
		binary.LittleEndian.PutUint16(col[catalogColRowOffOffset:catalogColRowOffOffset+2], c.Offset)
		binary.LittleEndian.PutUint16(col[catalogColWidthOffset:catalogColWidthOffset+2], c.Width)
		copy(col[catalogColNameOffset:catalogColNameOffset+MaxColumnNameLen], []byte(c.Name))
	}
	page.MarkDirty()
	return nil
}

func readCatalogEntry(page *Page, slot int) (*Table, error) {
	start, end, err := catalogEntryRange(slot)
	if err != nil {
		return nil, err
	}
	entry := page.Data[start:end]
	if entry[catalogActiveOffset] == 0 {
		return nil, nil
	}
	nameLen := int(entry[catalogNameLenOffset])
	if nameLen < 1 || nameLen > MaxTableNameLen {
		return nil, fmt.Errorf("catalog page %d slot %d has invalid table-name length %d", page.Number, slot, nameLen)
	}
	columnCount := int(entry[catalogColumnCountOff])
	if columnCount < 1 || columnCount > MaxColumns {
		return nil, fmt.Errorf("catalog page %d slot %d has invalid column count %d", page.Number, slot, columnCount)
	}
	name := string(entry[catalogNameOffset : catalogNameOffset+nameLen])
	columns := make([]Column, 0, columnCount)
	for i := 0; i < columnCount; i++ {
		off := catalogColumnsOffset + i*catalogColumnSize
		col := entry[off : off+catalogColumnSize]
		colNameLen := int(col[catalogColNameLenOffset])
		if colNameLen < 1 || colNameLen > MaxColumnNameLen {
			return nil, fmt.Errorf("catalog table %s column %d has invalid name length %d", name, i, colNameLen)
		}
		c := Column{
			Name:     string(col[catalogColNameOffset : catalogColNameOffset+colNameLen]),
			Type:     ColumnType(col[catalogColTypeOffset]),
			Nullable: col[catalogColNullableOff] != 0,
			MaxLen:   binary.LittleEndian.Uint16(col[catalogColMaxLenOffset : catalogColMaxLenOffset+2]),
			Offset:   binary.LittleEndian.Uint16(col[catalogColRowOffOffset : catalogColRowOffOffset+2]),
			Width:    binary.LittleEndian.Uint16(col[catalogColWidthOffset : catalogColWidthOffset+2]),
		}
		if _, err := columnWidth(c); err != nil {
			return nil, fmt.Errorf("catalog table %s column %s: %w", name, c.Name, err)
		}
		columns = append(columns, c)
	}
	schema := Schema{Columns: columns, RowSize: binary.LittleEndian.Uint32(entry[catalogRowSizeOffset : catalogRowSizeOffset+4])}
	compiled, err := CompileSchema(columns)
	if err != nil {
		return nil, fmt.Errorf("catalog table %s schema invalid: %w", name, err)
	}
	if compiled.RowSize != schema.RowSize {
		return nil, fmt.Errorf("catalog table %s row size %d does not match compiled size %d", name, schema.RowSize, compiled.RowSize)
	}
	for i := range compiled.Columns {
		if compiled.Columns[i].Offset != schema.Columns[i].Offset || compiled.Columns[i].Width != schema.Columns[i].Width {
			return nil, fmt.Errorf("catalog table %s column %s layout mismatch", name, schema.Columns[i].Name)
		}
	}
	t := &Table{
		ID:        binary.LittleEndian.Uint64(entry[catalogTableIDOffset : catalogTableIDOffset+8]),
		Name:      name,
		Schema:    schema,
		firstData: binary.LittleEndian.Uint64(entry[catalogFirstDataOffset : catalogFirstDataOffset+8]),
		lastData:  binary.LittleEndian.Uint64(entry[catalogLastDataOffset : catalogLastDataOffset+8]),
		nextRowID: int64(binary.LittleEndian.Uint64(entry[catalogNextRowIDOffset : catalogNextRowIDOffset+8])),
		catalog:   CatalogPointer{Page: page.Number, Slot: uint16(slot)},
	}
	root := binary.LittleEndian.Uint64(entry[catalogRootPageOffset : catalogRootPageOffset+8])
	if t.ID == 0 || root == 0 || t.nextRowID < 1 {
		return nil, fmt.Errorf("catalog table %s has invalid id/root/next-rowid", name)
	}
	if (t.firstData == 0) != (t.lastData == 0) {
		return nil, fmt.Errorf("catalog table %s data chain metadata disagrees", name)
	}
	t.tree = newBTree(nil, root) // pager is attached by Store after catalog loading.
	return t, nil
}

package main

import (
	"encoding/binary"
	"errors"
	"fmt"
	"sort"
	"strings"
)

const (
	DatabaseMagic   = "MINIDB05"
	DatabaseVersion = uint32(5)
	HeaderPage      = uint64(0)

	metaMagicOffset          = PageHeaderSize
	metaVersionOffset        = metaMagicOffset + 8
	metaPageSizeOffset       = metaVersionOffset + 4
	metaPageHeaderSizeOffset = metaPageSizeOffset + 4
	metaChecksumAlgOffset    = metaPageHeaderSizeOffset + 4
	metaFirstCatalogOffset   = 64
	metaLastCatalogOffset    = 72
	metaNextTableIDOffset    = 80
	metaTableCountOffset     = 88

	dataTableIDOffset   = PageHeaderSize
	dataSlotCountOffset = 40
	dataRowSizeOffset   = 44
	dataNextPageOffset  = 48
	dataRowsOffset      = 64
)

var (
	ErrNotFound = errors.New("record not found")
	ErrDeleted  = errors.New("record deleted")
)

type Store struct {
	pager            *Pager
	tables           map[string]*Table
	firstCatalogPage uint64
	lastCatalogPage  uint64
	nextTableID      uint64
	tableCount       uint64
}

func writeDatabaseMetadata(page *Page, firstCatalog, lastCatalog, nextTableID, tableCount uint64) {
	clear(page.Data[PageHeaderSize:])
	copy(page.Data[metaMagicOffset:metaMagicOffset+8], []byte(DatabaseMagic))
	binary.LittleEndian.PutUint32(page.Data[metaVersionOffset:metaVersionOffset+4], DatabaseVersion)
	binary.LittleEndian.PutUint32(page.Data[metaPageSizeOffset:metaPageSizeOffset+4], PageSize)
	binary.LittleEndian.PutUint32(page.Data[metaPageHeaderSizeOffset:metaPageHeaderSizeOffset+4], PageHeaderSize)
	binary.LittleEndian.PutUint32(page.Data[metaChecksumAlgOffset:metaChecksumAlgOffset+4], ChecksumAlgorithm)
	binary.LittleEndian.PutUint64(page.Data[metaFirstCatalogOffset:metaFirstCatalogOffset+8], firstCatalog)
	binary.LittleEndian.PutUint64(page.Data[metaLastCatalogOffset:metaLastCatalogOffset+8], lastCatalog)
	binary.LittleEndian.PutUint64(page.Data[metaNextTableIDOffset:metaNextTableIDOffset+8], nextTableID)
	binary.LittleEndian.PutUint64(page.Data[metaTableCountOffset:metaTableCountOffset+8], tableCount)
	page.MarkDirty()
}

func readDatabaseMetadata(page *Page) (firstCatalog, lastCatalog, nextTableID, tableCount uint64, err error) {
	if page.Type != PageTypeMetadata {
		err = fmt.Errorf("page 0 is %s, expected metadata", page.Type)
		return
	}
	if string(page.Data[metaMagicOffset:metaMagicOffset+8]) != DatabaseMagic {
		err = fmt.Errorf("not a compatible MiniDB file: bad database magic")
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaVersionOffset : metaVersionOffset+4]); got != DatabaseVersion {
		err = fmt.Errorf("unsupported database version %d", got)
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaPageSizeOffset : metaPageSizeOffset+4]); got != PageSize {
		err = fmt.Errorf("file page size is %d, program expects %d", got, PageSize)
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaPageHeaderSizeOffset : metaPageHeaderSizeOffset+4]); got != PageHeaderSize {
		err = fmt.Errorf("file page-header size is %d, program expects %d", got, PageHeaderSize)
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaChecksumAlgOffset : metaChecksumAlgOffset+4]); got != ChecksumAlgorithm {
		err = fmt.Errorf("unsupported checksum algorithm %d", got)
		return
	}
	firstCatalog = binary.LittleEndian.Uint64(page.Data[metaFirstCatalogOffset : metaFirstCatalogOffset+8])
	lastCatalog = binary.LittleEndian.Uint64(page.Data[metaLastCatalogOffset : metaLastCatalogOffset+8])
	nextTableID = binary.LittleEndian.Uint64(page.Data[metaNextTableIDOffset : metaNextTableIDOffset+8])
	tableCount = binary.LittleEndian.Uint64(page.Data[metaTableCountOffset : metaTableCountOffset+8])
	if firstCatalog == 0 || lastCatalog == 0 || nextTableID == 0 {
		err = fmt.Errorf("invalid catalog metadata: first=%d last=%d nextTableID=%d", firstCatalog, lastCatalog, nextTableID)
	}
	return
}

func initializeCatalogPage(page *Page) error {
	if page.Type != PageTypeCatalog {
		return fmt.Errorf("page %d is %s, expected catalog", page.Number, page.Type)
	}
	setCatalogSlotCount(page, 0)
	setCatalogNextPage(page, 0)
	return nil
}

func Open(path string) (*Store, error) {
	pager, err := OpenPager(path)
	if err != nil {
		return nil, err
	}
	s := &Store{pager: pager, tables: make(map[string]*Table)}

	if pager.numPages == 0 {
		meta, err := pager.NewPage(PageTypeMetadata)
		if err != nil {
			pager.Close()
			return nil, err
		}
		if meta.Number != HeaderPage {
			pager.Close()
			return nil, fmt.Errorf("new metadata page is %d, expected 0", meta.Number)
		}
		catalog, err := pager.NewPage(PageTypeCatalog)
		if err != nil {
			pager.Close()
			return nil, err
		}
		if err := initializeCatalogPage(catalog); err != nil {
			pager.Close()
			return nil, err
		}
		s.firstCatalogPage = catalog.Number
		s.lastCatalogPage = catalog.Number
		s.nextTableID = 1
		s.tableCount = 0
		writeDatabaseMetadata(meta, s.firstCatalogPage, s.lastCatalogPage, s.nextTableID, s.tableCount)
		if err := pager.FlushAll(); err != nil {
			pager.Close()
			return nil, err
		}
		return s, nil
	}

	meta, err := pager.GetPage(HeaderPage)
	if err != nil {
		pager.Close()
		return nil, err
	}
	first, last, nextID, count, err := readDatabaseMetadata(meta)
	if err != nil {
		pager.Close()
		return nil, err
	}
	s.firstCatalogPage, s.lastCatalogPage, s.nextTableID, s.tableCount = first, last, nextID, count
	if err := s.loadCatalog(); err != nil {
		pager.Close()
		return nil, err
	}
	if uint64(len(s.tables)) != s.tableCount {
		pager.Close()
		return nil, fmt.Errorf("catalog says %d tables but loaded %d", s.tableCount, len(s.tables))
	}
	return s, nil
}

func (s *Store) loadCatalog() error {
	seenPages := map[uint64]bool{}
	loadedIDs := map[uint64]bool{}
	pageNum := s.firstCatalogPage
	var lastSeen uint64
	for pageNum != 0 {
		if seenPages[pageNum] {
			return fmt.Errorf("catalog page cycle at %d", pageNum)
		}
		seenPages[pageNum] = true
		page, err := s.pager.GetPage(pageNum)
		if err != nil {
			return err
		}
		if page.Type != PageTypeCatalog {
			return fmt.Errorf("catalog chain page %d is %s", pageNum, page.Type)
		}
		n := catalogSlotCount(page)
		if n < 0 || n > CatalogSlotsPerPage {
			return fmt.Errorf("catalog page %d has invalid slot count %d", pageNum, n)
		}
		for slot := 0; slot < n; slot++ {
			t, err := readCatalogEntry(page, slot)
			if err != nil {
				return err
			}
			if t == nil {
				return fmt.Errorf("catalog page %d slot %d is unexpectedly empty", pageNum, slot)
			}
			key := normalizeTableName(t.Name)
			if _, exists := s.tables[key]; exists {
				return fmt.Errorf("duplicate table name %q in catalog", t.Name)
			}
			if loadedIDs[t.ID] {
				return fmt.Errorf("duplicate table id %d in catalog", t.ID)
			}
			loadedIDs[t.ID] = true
			t.tree.pager = s.pager
			s.tables[key] = t
		}
		lastSeen = pageNum
		pageNum = catalogNextPage(page)
	}
	if lastSeen != s.lastCatalogPage {
		return fmt.Errorf("catalog last-page metadata says %d but chain ends at %d", s.lastCatalogPage, lastSeen)
	}
	return nil
}

func (s *Store) persistMetadata() error {
	page, err := s.pager.GetPage(HeaderPage)
	if err != nil {
		return err
	}
	writeDatabaseMetadata(page, s.firstCatalogPage, s.lastCatalogPage, s.nextTableID, s.tableCount)
	return nil
}

func (s *Store) persistTable(t *Table) error {
	page, err := s.pager.GetPage(t.catalog.Page)
	if err != nil {
		return err
	}
	return writeCatalogEntry(page, int(t.catalog.Slot), t)
}

func validIdentifier(name string) bool {
	if name == "" {
		return false
	}
	for i, r := range name {
		if !(r == '_' || r >= 'a' && r <= 'z' || r >= 'A' && r <= 'Z' || i > 0 && r >= '0' && r <= '9') {
			return false
		}
	}
	return true
}

func (s *Store) CreateTable(name string, columns []Column) (*Table, error) {
	if !validIdentifier(name) || len([]byte(name)) > MaxTableNameLen {
		return nil, fmt.Errorf("table name must be a simple identifier of at most %d bytes", MaxTableNameLen)
	}
	key := normalizeTableName(name)
	if _, exists := s.tables[key]; exists {
		return nil, fmt.Errorf("table %q already exists", name)
	}
	schema, err := CompileSchema(columns)
	if err != nil {
		return nil, err
	}
	root, err := s.pager.NewPage(PageTypeBTreeLeaf)
	if err != nil {
		return nil, err
	}
	t := &Table{
		ID:        s.nextTableID,
		Name:      name,
		Schema:    schema,
		tree:      newBTree(s.pager, root.Number),
		nextRowID: 1,
	}

	catalogPage, err := s.pager.GetPage(s.lastCatalogPage)
	if err != nil {
		return nil, err
	}
	slot := catalogSlotCount(catalogPage)
	if slot >= CatalogSlotsPerPage {
		newPage, err := s.pager.NewPage(PageTypeCatalog)
		if err != nil {
			return nil, err
		}
		if err := initializeCatalogPage(newPage); err != nil {
			return nil, err
		}
		setCatalogNextPage(catalogPage, newPage.Number)
		s.lastCatalogPage = newPage.Number
		catalogPage = newPage
		slot = 0
	}
	t.catalog = CatalogPointer{Page: catalogPage.Number, Slot: uint16(slot)}
	if err := writeCatalogEntry(catalogPage, slot, t); err != nil {
		return nil, err
	}
	setCatalogSlotCount(catalogPage, slot+1)

	s.tables[key] = t
	s.nextTableID++
	s.tableCount++
	if err := s.persistMetadata(); err != nil {
		return nil, err
	}
	return t, nil
}

func (s *Store) Table(name string) (*Table, error) {
	t, ok := s.tables[normalizeTableName(name)]
	if !ok {
		return nil, fmt.Errorf("table %q not found", name)
	}
	return t, nil
}

func (s *Store) Tables() []*Table {
	out := make([]*Table, 0, len(s.tables))
	for _, t := range s.tables {
		out = append(out, t)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].ID < out[j].ID })
	return out
}

func dataTableID(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[dataTableIDOffset : dataTableIDOffset+8])
}
func dataSlotCount(page *Page) int {
	return int(binary.LittleEndian.Uint16(page.Data[dataSlotCountOffset : dataSlotCountOffset+2]))
}
func setDataSlotCount(page *Page, n int) {
	binary.LittleEndian.PutUint16(page.Data[dataSlotCountOffset:dataSlotCountOffset+2], uint16(n))
	page.MarkDirty()
}
func dataRowSize(page *Page) uint32 {
	return binary.LittleEndian.Uint32(page.Data[dataRowSizeOffset : dataRowSizeOffset+4])
}
func dataNextPage(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[dataNextPageOffset : dataNextPageOffset+8])
}
func setDataNextPage(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[dataNextPageOffset:dataNextPageOffset+8], n)
	page.MarkDirty()
}
func dataCapacity(rowSize uint32) int {
	if rowSize == 0 {
		return 0
	}
	return (PageSize - dataRowsOffset) / int(rowSize)
}

func initializeDataPage(page *Page, t *Table) error {
	if page.Type != PageTypeData {
		return fmt.Errorf("page %d is %s, expected data", page.Number, page.Type)
	}
	binary.LittleEndian.PutUint64(page.Data[dataTableIDOffset:dataTableIDOffset+8], t.ID)
	binary.LittleEndian.PutUint32(page.Data[dataRowSizeOffset:dataRowSizeOffset+4], t.Schema.RowSize)
	setDataSlotCount(page, 0)
	setDataNextPage(page, 0)
	page.MarkDirty()
	return nil
}

func validateDataPage(page *Page, t *Table) error {
	if page.Type != PageTypeData {
		return fmt.Errorf("page %d is %s, expected data", page.Number, page.Type)
	}
	if got := dataTableID(page); got != t.ID {
		return fmt.Errorf("data page %d belongs to table id %d, expected %d", page.Number, got, t.ID)
	}
	if got := dataRowSize(page); got != t.Schema.RowSize {
		return fmt.Errorf("data page %d row size is %d, table %s expects %d", page.Number, got, t.Name, t.Schema.RowSize)
	}
	count := dataSlotCount(page)
	if count < 0 || count > dataCapacity(t.Schema.RowSize) {
		return fmt.Errorf("data page %d has invalid slot count %d", page.Number, count)
	}
	return nil
}

func (s *Store) allocateDataPage(t *Table) (*Page, error) {
	page, err := s.pager.NewPage(PageTypeData)
	if err != nil {
		return nil, err
	}
	if err := initializeDataPage(page, t); err != nil {
		return nil, err
	}
	if t.lastData != 0 {
		last, err := s.pager.GetPage(t.lastData)
		if err != nil {
			return nil, err
		}
		if err := validateDataPage(last, t); err != nil {
			return nil, err
		}
		setDataNextPage(last, page.Number)
	} else {
		t.firstData = page.Number
	}
	t.lastData = page.Number
	return page, nil
}

func rowRange(t *Table, slot int) (int, int, error) {
	cap := dataCapacity(t.Schema.RowSize)
	if slot < 0 || slot >= cap {
		return 0, 0, fmt.Errorf("slot %d out of range for table %s", slot, t.Name)
	}
	start := dataRowsOffset + slot*int(t.Schema.RowSize)
	return start, start + int(t.Schema.RowSize), nil
}

func (s *Store) appendRow(t *Table, encoded []byte) (RecordPointer, error) {
	if len(encoded) != int(t.Schema.RowSize) {
		return RecordPointer{}, fmt.Errorf("encoded row has %d bytes, expected %d", len(encoded), t.Schema.RowSize)
	}
	var page *Page
	var err error
	if t.lastData == 0 {
		page, err = s.allocateDataPage(t)
		if err != nil {
			return RecordPointer{}, err
		}
	} else {
		page, err = s.pager.GetPage(t.lastData)
		if err != nil {
			return RecordPointer{}, err
		}
		if err := validateDataPage(page, t); err != nil {
			return RecordPointer{}, err
		}
		if dataSlotCount(page) >= dataCapacity(t.Schema.RowSize) {
			page, err = s.allocateDataPage(t)
			if err != nil {
				return RecordPointer{}, err
			}
		}
	}
	slot := dataSlotCount(page)
	start, end, err := rowRange(t, slot)
	if err != nil {
		return RecordPointer{}, err
	}
	copy(page.Data[start:end], encoded)
	setDataSlotCount(page, slot+1)
	page.MarkDirty()
	return RecordPointer{Page: page.Number, Slot: uint16(slot)}, nil
}

func (s *Store) readRowAt(t *Table, ptr RecordPointer) (Row, *Page, int, error) {
	page, err := s.pager.GetPage(ptr.Page)
	if err != nil {
		return Row{}, nil, 0, err
	}
	if err := validateDataPage(page, t); err != nil {
		return Row{}, nil, 0, err
	}
	if int(ptr.Slot) >= dataSlotCount(page) {
		return Row{}, nil, 0, fmt.Errorf("pointer %d:%d is past used slots", ptr.Page, ptr.Slot)
	}
	start, end, err := rowRange(t, int(ptr.Slot))
	if err != nil {
		return Row{}, nil, 0, err
	}
	row, err := DecodeRow(t.Schema, page.Data[start:end])
	return row, page, start, err
}

func (s *Store) Insert(tableName string, values []Value) (int64, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return 0, err
	}
	rowID := t.nextRowID
	encoded, err := EncodeRow(t.Schema, rowID, values)
	if err != nil {
		return 0, err
	}
	ptr, err := s.appendRow(t, encoded)
	if err != nil {
		return 0, err
	}
	if err := t.tree.Insert(rowID, ptr); err != nil {
		return 0, err
	}
	t.nextRowID++
	if err := s.persistTable(t); err != nil {
		return 0, err
	}
	return rowID, nil
}

func (s *Store) Get(tableName string, rowID int64) (Row, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return Row{}, err
	}
	ptr, _, err := t.tree.Lookup(rowID)
	if err != nil {
		return Row{}, err
	}
	row, _, _, err := s.readRowAt(t, ptr)
	if err != nil {
		return Row{}, err
	}
	if row.RowID != rowID {
		return Row{}, fmt.Errorf("index key %d points to rowid %d", rowID, row.RowID)
	}
	if row.Deleted {
		return Row{}, ErrDeleted
	}
	return row, nil
}

	if err != nil {
		return Row{}, 0, err
	}

		return Row{}, steps, err
	}

	if err != nil {
		return Row{}, steps, err
	}
	if row.RowID != rowID {
		return Row{}, steps, fmt.Errorf("index key %d points to rowid %d", rowID, row.RowID)
	}

func (s *Store) Scan(tableName string) ([]Row, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return nil, err
	}
	ptrs, err := t.tree.AllPointers()
	if err != nil {
		return nil, err
	}
	rows := make([]Row, 0, len(ptrs))
	for _, ptr := range ptrs {
		row, _, _, err := s.readRowAt(t, ptr)
		if err != nil {
			return nil, err
		}
		if row.Deleted {
			continue
		}
		rows = append(rows, row)
	}
	return rows, nil
}

func (s *Store) DataChain(tableName string) ([]uint64, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return nil, err
	}
	var out []uint64
	seen := map[uint64]bool{}
	for p := t.firstData; p != 0; {
		if seen[p] {
			return nil, fmt.Errorf("data-page cycle at %d", p)
		}
		seen[p] = true
		page, err := s.pager.GetPage(p)
		if err != nil {
			return nil, err
		}
		if err := validateDataPage(page, t); err != nil {
			return nil, err
		}
		out = append(out, p)
		p = dataNextPage(page)
	}
	if len(out) == 0 && t.lastData != 0 {
		return nil, fmt.Errorf("table %s has last data page but empty chain", t.Name)
	}
	if len(out) > 0 && out[len(out)-1] != t.lastData {
		return nil, fmt.Errorf("table %s last data metadata says %d but chain ends at %d", t.Name, t.lastData, out[len(out)-1])
	}
	return out, nil
}

func (s *Store) CatalogPages() ([]uint64, error) {
	var out []uint64
	seen := map[uint64]bool{}
	for p := s.firstCatalogPage; p != 0; {
		if seen[p] {
			return nil, fmt.Errorf("catalog cycle at %d", p)
		}
		seen[p] = true
		page, err := s.pager.GetPage(p)
		if err != nil {
			return nil, err
		}
		if page.Type != PageTypeCatalog {
			return nil, fmt.Errorf("catalog chain page %d is %s", p, page.Type)
		}
		out = append(out, p)
		p = catalogNextPage(page)
	}
	return out, nil
}

import (
	"fmt"
	"strings"

type TokenKind int

const (
	TokenEOF TokenKind = iota
	TokenIdentifier
	TokenNumber
	TokenString
	TokenComma
	TokenLParen
	TokenRParen
	TokenSemicolon
	TokenStar
	TokenEqual
	TokenCreate
	TokenTable
	TokenInsert
	TokenInto
	TokenValues
	TokenSelect
	TokenFrom
	TokenWhere
	TokenDelete
	TokenInt
	TokenBool
	TokenText
	TokenNull
	TokenNot
	TokenTrue
	TokenFalse
)

func (k TokenKind) String() string {
	names := map[TokenKind]string{
		TokenEOF: "EOF", TokenIdentifier: "IDENT", TokenNumber: "NUMBER", TokenString: "STRING",
		TokenComma: "COMMA", TokenLParen: "LPAREN", TokenRParen: "RPAREN", TokenSemicolon: "SEMICOLON",
		TokenStar: "STAR", TokenEqual: "EQUAL", TokenCreate: "CREATE", TokenTable: "TABLE",
		TokenInsert: "INSERT", TokenInto: "INTO", TokenValues: "VALUES", TokenSelect: "SELECT",
		TokenFrom: "FROM", TokenWhere: "WHERE", TokenDelete: "DELETE", TokenInt: "INT",
		TokenBool: "BOOL", TokenText: "TEXT", TokenNull: "NULL", TokenNot: "NOT",
		TokenTrue: "TRUE", TokenFalse: "FALSE",
	}
	if s, ok := names[k]; ok {
		return s
	}
	return fmt.Sprintf("TOKEN(%d)", int(k))
}

type Token struct {
	Kind   TokenKind
	Lexeme string
	Pos    int
}

var keywords = map[string]TokenKind{
	"CREATE": TokenCreate, "TABLE": TokenTable, "INSERT": TokenInsert, "INTO": TokenInto,
	"VALUES": TokenValues, "SELECT": TokenSelect, "FROM": TokenFrom, "WHERE": TokenWhere,
	"DELETE": TokenDelete, "INT": TokenInt, "INTEGER": TokenInt, "BOOL": TokenBool,
	"BOOLEAN": TokenBool, "TEXT": TokenText, "NULL": TokenNull, "NOT": TokenNot,
	"TRUE": TokenTrue, "FALSE": TokenFalse,
}

type Lexer struct {
	input string
	pos   int
}

func Lex(input string) ([]Token, error) {
	l := &Lexer{input: input}
	var tokens []Token
	for {
		tok, err := l.nextToken()
		if err != nil {
			return nil, err
		}
		tokens = append(tokens, tok)
		if tok.Kind == TokenEOF {
			return tokens, nil
		}
	}
}

func (l *Lexer) nextToken() (Token, error) {
	for l.pos < len(l.input) && isSpace(l.input[l.pos]) {
		l.pos++
	}
	if l.pos >= len(l.input) {
		return Token{Kind: TokenEOF, Pos: l.pos}, nil
	}

	start := l.pos
	ch := l.input[l.pos]
	switch ch {
	case ',':
		l.pos++
		return Token{Kind: TokenComma, Lexeme: ",", Pos: start}, nil
	case '(':
		l.pos++
		return Token{Kind: TokenLParen, Lexeme: "(", Pos: start}, nil
	case ')':
		l.pos++
		return Token{Kind: TokenRParen, Lexeme: ")", Pos: start}, nil
	case ';':
		l.pos++
		return Token{Kind: TokenSemicolon, Lexeme: ";", Pos: start}, nil
	case '*':
		l.pos++
		return Token{Kind: TokenStar, Lexeme: "*", Pos: start}, nil
	case '=':
		l.pos++
		return Token{Kind: TokenEqual, Lexeme: "=", Pos: start}, nil
	case '\'':
		return l.lexString()
	}

	if isDigit(ch) || (ch == '-' && l.pos+1 < len(l.input) && isDigit(l.input[l.pos+1])) {
		if ch == '-' {
			l.pos++
		}
		for l.pos < len(l.input) && isDigit(l.input[l.pos]) {
			l.pos++
		}
		return Token{Kind: TokenNumber, Lexeme: l.input[start:l.pos], Pos: start}, nil
	}
	if isIdentStart(ch) {
		l.pos++
		for l.pos < len(l.input) && isIdentContinue(l.input[l.pos]) {
			l.pos++
		}
		word := l.input[start:l.pos]
		if kind, ok := keywords[strings.ToUpper(word)]; ok {
			return Token{Kind: kind, Lexeme: word, Pos: start}, nil
		}
		return Token{Kind: TokenIdentifier, Lexeme: word, Pos: start}, nil
	}
	return Token{}, fmt.Errorf("lex error at byte %d: unexpected character %q", start, ch)
}

func (l *Lexer) lexString() (Token, error) {
	start := l.pos
	l.pos++
	var b strings.Builder
	for l.pos < len(l.input) {
		ch := l.input[l.pos]
		if ch == '\'' {
			if l.pos+1 < len(l.input) && l.input[l.pos+1] == '\'' {
				b.WriteByte('\'')
				l.pos += 2
				continue
			}
			l.pos++
			return Token{Kind: TokenString, Lexeme: b.String(), Pos: start}, nil
		}
		b.WriteByte(ch)
		l.pos++
	}
	return Token{}, fmt.Errorf("lex error at byte %d: unterminated string literal", start)
}

func isSpace(ch byte) bool { return ch == ' ' || ch == '\t' || ch == '\r' || ch == '\n' }
func isDigit(ch byte) bool { return ch >= '0' && ch <= '9' }
func isIdentStart(ch byte) bool {
	return ch == '_' || (ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z')
}
func isIdentContinue(ch byte) bool { return isIdentStart(ch) || isDigit(ch) }

package main

import (
	"fmt"
	"strconv"
	"strings"

type Statement interface{ statementNode() }
type Expr interface{ exprNode() }

type TypeSpec struct {

}
type ColumnDef struct {

type CreateTableStmt struct {

func (*CreateTableStmt) statementNode() {}

const (

func (*InsertStmt) statementNode() {}

func (*SelectStmt) statementNode() {}

func (*DeleteStmt) statementNode() {}

func (*IdentifierExpr) exprNode() {}

func (*LiteralExpr) exprNode() {}

	Right    Expr

type Parser struct {
	tokens []Token
	pos    int
}

func ParseSQL(input string) (Statement, error) {
	tokens, err := Lex(input)
	if err != nil {
		return nil, err
	}
	return NewParser(tokens).ParseStatement()
}
func NewParser(tokens []Token) *Parser { return &Parser{tokens: tokens} }

func (p *Parser) ParseStatement() (Statement, error) {
	var stmt Statement
	var err error
	switch p.peek().Kind {
	case TokenCreate:
		stmt, err = p.parseCreateTable()
	case TokenInsert:
		stmt, err = p.parseInsert()
	case TokenSelect:
		stmt, err = p.parseSelect()
	case TokenDelete:
		stmt, err = p.parseDelete()
	default:
		return nil, p.errorf(p.peek(), "expected CREATE, INSERT, SELECT, or DELETE")
	}
	if err != nil {
		return nil, err
	}
	p.match(TokenSemicolon)
	if p.peek().Kind != TokenEOF {
		return nil, p.errorf(p.peek(), "unexpected token after statement")
	}
	return stmt, nil
}

func (p *Parser) parseCreateTable() (Statement, error) {
	p.advance() // CREATE
	if _, err := p.expect(TokenTable, "expected TABLE after CREATE"); err != nil {
		return nil, err
	}
	name, err := p.expect(TokenIdentifier, "expected table name")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenLParen, "expected '(' after table name"); err != nil {
		return nil, err
	}
	var columns []ColumnDef
	for {
		colName, err := p.expect(TokenIdentifier, "expected column name")
		if err != nil {
			return nil, err
		}
		typeSpec, err := p.parseTypeSpec()
		if err != nil {
			return nil, err
		}
		nullable := true // SQL columns are nullable unless constrained NOT NULL.
		if p.match(TokenNot) {
			if _, err := p.expect(TokenNull, "expected NULL after NOT"); err != nil {
				return nil, err
			}
			nullable = false
		} else if p.match(TokenNull) {
			nullable = true
		}
		columns = append(columns, ColumnDef{Name: colName.Lexeme, Type: typeSpec, Nullable: nullable})
		if p.match(TokenComma) {
			continue
		}
		break
	}
	if _, err := p.expect(TokenRParen, "expected ')' after column definitions"); err != nil {
		return nil, err
	}
	return &CreateTableStmt{Name: name.Lexeme, Columns: columns}, nil
}

func (p *Parser) parseTypeSpec() (TypeSpec, error) {
	tok := p.advance()
	switch tok.Kind {
	case TokenInt:
		return TypeSpec{Type: TypeInt64}, nil
	case TokenBool:
		return TypeSpec{Type: TypeBool}, nil
	case TokenText:
		if _, err := p.expect(TokenLParen, "expected '(' after TEXT"); err != nil {
			return TypeSpec{}, err
		}
		nTok, err := p.expect(TokenNumber, "expected maximum length inside TEXT(...)")
		if err != nil {
			return TypeSpec{}, err
		}
		n, err := strconv.Atoi(nTok.Lexeme)
		if err != nil || n < 1 || n > MaxTextLen {
			return TypeSpec{}, p.errorf(nTok, "TEXT length must be 1..%d", MaxTextLen)
		}
		if _, err := p.expect(TokenRParen, "expected ')' after TEXT length"); err != nil {
			return TypeSpec{}, err
		}
		return TypeSpec{Type: TypeText, TextLen: uint16(n)}, nil
	default:
		return TypeSpec{}, p.errorf(tok, "expected INT, BOOL, or TEXT(n)")
	}
}

func (p *Parser) parseInsert() (Statement, error) {
	p.advance() // INSERT
	if _, err := p.expect(TokenInto, "expected INTO after INSERT"); err != nil {
		return nil, err
	}
	table, err := p.expect(TokenIdentifier, "expected table name")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenValues, "expected VALUES after table name"); err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenLParen, "expected '(' after VALUES"); err != nil {
		return nil, err
	}
	var values []Literal
	if p.peek().Kind != TokenRParen {
		for {
			v, err := p.parseLiteral()
			if err != nil {
				return nil, err
			}
			values = append(values, v)
			if p.match(TokenComma) {
				continue
			}
			break
		}
	}
	if _, err := p.expect(TokenRParen, "expected ')' after VALUES list"); err != nil {
		return nil, err
	}
	return &InsertStmt{Table: table.Lexeme, Values: values}, nil
}

func (p *Parser) parseSelect() (Statement, error) {
	p.advance() // SELECT
	stmt := &SelectStmt{}
	if p.match(TokenStar) {
		stmt.All = true
	} else {
		for {
			name, err := p.expect(TokenIdentifier, "expected column name or '*'")
			if err != nil {
				return nil, err
			}
			stmt.Columns = append(stmt.Columns, name.Lexeme)
			if p.match(TokenComma) {
				continue
			}
			break
		}
	}
	if _, err := p.expect(TokenFrom, "expected FROM after SELECT list"); err != nil {
		return nil, err
	}
	table, err := p.expect(TokenIdentifier, "expected table name after FROM")
	if err != nil {
		return nil, err
	}
	stmt.Table = table.Lexeme
	if p.match(TokenWhere) {
		expr, err := p.parseEquality()
		if err != nil {
			return nil, err
		}
		stmt.Where = expr
	}
	return stmt, nil
}

func (p *Parser) parseDelete() (Statement, error) {
	p.advance() // DELETE
	if _, err := p.expect(TokenFrom, "expected FROM after DELETE"); err != nil {
		return nil, err
	}
	table, err := p.expect(TokenIdentifier, "expected table name")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenWhere, "Part 6 DELETE requires a WHERE clause"); err != nil {
		return nil, err
	}
	expr, err := p.parseEquality()
	if err != nil {
		return nil, err
	}
	return &DeleteStmt{Table: table.Lexeme, Where: expr}, nil
}

func (p *Parser) parseEquality() (Expr, error) {
	leftTok, err := p.expect(TokenIdentifier, "expected column name on left side of WHERE")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenEqual, "Part 6 supports only '=' comparisons"); err != nil {
		return nil, err
	}
	lit, err := p.parseLiteral()
	if err != nil {
		return nil, err
	}
	return &BinaryExpr{Left: &IdentifierExpr{Name: leftTok.Lexeme}, Operator: TokenEqual, Right: &LiteralExpr{Value: lit}}, nil
}

func (p *Parser) parseLiteral() (Literal, error) {
	tok := p.advance()
	switch tok.Kind {
	case TokenNumber:
		n, err := strconv.ParseInt(tok.Lexeme, 10, 64)
		if err != nil {
			return Literal{}, p.errorf(tok, "integer is outside int64 range")
		}
		return Literal{Kind: LiteralInt, Int: n}, nil
	case TokenString:
		return Literal{Kind: LiteralString, Text: tok.Lexeme}, nil
	case TokenTrue:
		return Literal{Kind: LiteralBool, Bool: true}, nil
	case TokenFalse:
		return Literal{Kind: LiteralBool, Bool: false}, nil
	case TokenNull:
		return Literal{Kind: LiteralNull}, nil
	default:
		return Literal{}, p.errorf(tok, "expected literal value")
	}
}

func (p *Parser) peek() Token {
	if p.pos >= len(p.tokens) {
		return Token{Kind: TokenEOF}
	}
	return p.tokens[p.pos]
}
func (p *Parser) advance() Token {
	tok := p.peek()
	if p.pos < len(p.tokens) {
		p.pos++
	}
	return tok
}
func (p *Parser) match(kind TokenKind) bool {
	if p.peek().Kind == kind {
		p.pos++
		return true
	}
	return false
}
func (p *Parser) expect(kind TokenKind, message string) (Token, error) {
	if p.peek().Kind != kind {
		return Token{}, p.errorf(p.peek(), message)
	}
	return p.advance(), nil
}
func (p *Parser) errorf(tok Token, format string, args ...any) error {
	return fmt.Errorf("parse error at byte %d near %q: %s", tok.Pos, tok.Lexeme, fmt.Sprintf(format, args...))
}

func DescribeAST(stmt Statement) string {
	var b strings.Builder
	var writeExpr func(Expr, string)
	writeExpr = func(e Expr, indent string) {
		switch x := e.(type) {
		case *IdentifierExpr:
			fmt.Fprintf(&b, "%sIdentifier %s\n", indent, x.Name)
		case *LiteralExpr:
			fmt.Fprintf(&b, "%sLiteral %s\n", indent, literalString(x.Value))
		case *BinaryExpr:
			fmt.Fprintf(&b, "%sBinary %s\n", indent, x.Operator)
			writeExpr(x.Left, indent+"  ")
			writeExpr(x.Right, indent+"  ")
		}
	}
	switch s := stmt.(type) {
	case *CreateTableStmt:
		fmt.Fprintf(&b, "CreateTable %s\n", s.Name)
		for _, c := range s.Columns {
			nullText := "NULL"
			if !c.Nullable {
				nullText = "NOT NULL"
			}
			if c.Type.Type == TypeText {
				fmt.Fprintf(&b, "  Column %s TEXT(%d) %s\n", c.Name, c.Type.TextLen, nullText)
			} else {
				fmt.Fprintf(&b, "  Column %s %s %s\n", c.Name, c.Type.Type, nullText)
			}
		}
	case *InsertStmt:
		fmt.Fprintf(&b, "Insert %s\n", s.Table)
		for _, v := range s.Values {
			fmt.Fprintf(&b, "  %s\n", literalString(v))
		}
	case *SelectStmt:
		fmt.Fprintf(&b, "Select from %s\n", s.Table)
		if s.All {
			b.WriteString("  Columns *\n")
		} else {
			fmt.Fprintf(&b, "  Columns %s\n", strings.Join(s.Columns, ", "))
		}
		if s.Where != nil {
			b.WriteString("  Where\n")
			writeExpr(s.Where, "    ")
		}
	case *DeleteStmt:
		fmt.Fprintf(&b, "Delete from %s\n  Where\n", s.Table)
		writeExpr(s.Where, "    ")
	}
	return b.String()
}

func literalString(v Literal) string {
	switch v.Kind {
	case LiteralInt:
		return fmt.Sprintf("INT %d", v.Int)
	case LiteralString:
		return fmt.Sprintf("STRING %q", v.Text)
	case LiteralBool:
		return fmt.Sprintf("BOOL %t", v.Bool)
	case LiteralNull:
		return "NULL"
	default:
		return "?"
	}
}

package main

import (
	"errors"
	"fmt"

	"strings"

type ExecutionResult struct {
	Columns []string
	Rows    [][]string
	Message string
}

func ExecuteStatement(store *Store, stmt Statement) (ExecutionResult, error) {
	switch s := stmt.(type) {
	case *CreateTableStmt:
		cols := make([]Column, len(s.Columns))
		for i, c := range s.Columns {
			cols[i] = Column{Name: c.Name, Type: c.Type.Type, MaxLen: c.Type.TextLen, Nullable: c.Nullable}
		}
		t, err := store.CreateTable(s.Name, cols)
		if err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: fmt.Sprintf("created table=%s id=%d row_size=%d root_page=%d", t.Name, t.ID, t.Schema.RowSize, t.tree.RootPage())}, nil

	case *InsertStmt:
		t, err := store.Table(s.Table)
		if err != nil {
			return ExecutionResult{}, err
		}
		if len(s.Values) != len(t.Schema.Columns) {
			return ExecutionResult{}, fmt.Errorf("table %s expects %d values, got %d", t.Name, len(t.Schema.Columns), len(s.Values))
		}
		values := make([]Value, len(s.Values))
		for i, lit := range s.Values {
			v, err := literalToValue(t.Schema.Columns[i], lit)
			if err != nil {
				return ExecutionResult{}, err
			}
			values[i] = v
		}
		rowID, err := store.Insert(t.Name, values)
		if err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: fmt.Sprintf("inserted 1 row (rowid=%d)", rowID)}, nil

	case *SelectStmt:
		return executeSelect(store, s)

	case *DeleteStmt:
		rowID, err := rowIDPredicate(s.Where)
		if err != nil {
			return ExecutionResult{}, fmt.Errorf("DELETE: %w", err)
		}
		if err := store.Delete(s.Table, rowID); err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: "deleted 1 row"}, nil
	default:
		return ExecutionResult{}, fmt.Errorf("unsupported statement %T", stmt)
	}
}

func literalToValue(c Column, lit Literal) (Value, error) {
	if lit.Kind == LiteralNull {
		if !c.Nullable {
			return Value{}, fmt.Errorf("column %s is NOT NULL", c.Name)
		}
		return Value{Type: c.Type, Null: true}, nil
	}
	v := Value{Type: c.Type}
	switch c.Type {
	case TypeInt64:
		if lit.Kind != LiteralInt {
			return Value{}, fmt.Errorf("column %s expects INT", c.Name)
		}
		v.Int = lit.Int
	case TypeBool:
		if lit.Kind != LiteralBool {
			return Value{}, fmt.Errorf("column %s expects BOOL", c.Name)
		}
		v.Bool = lit.Bool
	case TypeText:
		if lit.Kind != LiteralString {
			return Value{}, fmt.Errorf("column %s expects a quoted TEXT literal", c.Name)
		}
		if len([]byte(lit.Text)) > int(c.MaxLen) {
			return Value{}, fmt.Errorf("column %s allows at most %d UTF-8 bytes", c.Name, c.MaxLen)
		}
		v.Text = lit.Text
	default:
		return Value{}, fmt.Errorf("unsupported column type %s", c.Type)
	}
	return v, nil
}

func executeSelect(store *Store, s *SelectStmt) (ExecutionResult, error) {
	t, err := store.Table(s.Table)
	if err != nil {
		return ExecutionResult{}, err
	}
	projection, err := resolveProjection(t, s)
	if err != nil {
		return ExecutionResult{}, err
	}
	var rows []Row
	if s.Where == nil {
		rows, err = store.Scan(t.Name)
	} else {
		rowID, predErr := rowIDPredicate(s.Where)
		if predErr != nil {
			return ExecutionResult{}, fmt.Errorf("Part 6 executor only supports WHERE rowid = <integer>: %w", predErr)
		}
		row, getErr := store.Get(t.Name, rowID)
		if errors.Is(getErr, ErrNotFound) || errors.Is(getErr, ErrDeleted) {
			rows = nil
		} else if getErr != nil {
			return ExecutionResult{}, getErr
		} else {
			rows = []Row{row}
		}
	}
	if err != nil {
		return ExecutionResult{}, err
	}
	result := ExecutionResult{Columns: projection.headers}
	for _, row := range rows {
		out := make([]string, len(projection.items))
		for i, item := range projection.items {
			if item.rowID {
				out[i] = strconv.FormatInt(row.RowID, 10)
			} else {
				out[i] = FormatValue(row.Values[item.columnIndex])
			}
		}
		result.Rows = append(result.Rows, out)
	}
	return result, nil
}

type projectionItem struct {
	rowID       bool
	columnIndex int
}
type resolvedProjection struct {
	headers []string
	items   []projectionItem
}

func resolveProjection(t *Table, s *SelectStmt) (resolvedProjection, error) {
	if s.All {
		p := resolvedProjection{headers: []string{"rowid"}, items: []projectionItem{{rowID: true}}}
		for i, c := range t.Schema.Columns {
			p.headers = append(p.headers, c.Name)
			p.items = append(p.items, projectionItem{columnIndex: i})
		}
		return p, nil
	}
	var p resolvedProjection
	for _, name := range s.Columns {
		if strings.EqualFold(name, "rowid") {
			p.headers = append(p.headers, "rowid")
			p.items = append(p.items, projectionItem{rowID: true})
			continue
		}
		idx := -1
		for i, c := range t.Schema.Columns {
			if strings.EqualFold(c.Name, name) {
				idx = i
				name = c.Name
				break
			}
		}
		if idx < 0 {
			return resolvedProjection{}, fmt.Errorf("column %q not found in table %s", name, t.Name)
		}
		p.headers = append(p.headers, name)
		p.items = append(p.items, projectionItem{columnIndex: idx})
	}
	return p, nil
}

func rowIDPredicate(expr Expr) (int64, error) {
	b, ok := expr.(*BinaryExpr)
	if !ok || b.Operator != TokenEqual {
		return 0, fmt.Errorf("predicate must be an equality")
	}
	left, ok := b.Left.(*IdentifierExpr)
	if !ok || !strings.EqualFold(left.Name, "rowid") {
		return 0, fmt.Errorf("left side must be rowid")
	}
	right, ok := b.Right.(*LiteralExpr)
	if !ok || right.Value.Kind != LiteralInt {
		return 0, fmt.Errorf("right side must be an integer")
	}
	if right.Value.Int < 1 {
		return 0, fmt.Errorf("rowid must be >= 1")
	}
	return right.Value.Int, nil
}

func handleMeta(store *Store, line string) bool {
	parts := strings.Fields(line)
	if len(parts) == 0 {
		return false
	}
	cmd := strings.ToLower(parts[0])
	switch cmd {
	case ".quit", ".exit":
		return true
	case ".help":
		fmt.Println("SQL:")
		fmt.Println("  CREATE TABLE t (name TEXT(40) NOT NULL, age INT, active BOOL);")
		fmt.Println("  INSERT INTO t VALUES ('alice', 30, true);")
		fmt.Println("  SELECT * FROM t;")
		fmt.Println("  SELECT rowid, name FROM t WHERE rowid = 1;")
		fmt.Println("  DELETE FROM t WHERE rowid = 1;")
		fmt.Println("Meta commands:")
		fmt.Println("  .tables | .schema <table> | .tree <table> | .datapages <table>")
		fmt.Println("  .catalogpages | .stats | .flush | .verify | .pageinfo <n>")
		fmt.Println("  .tokens <sql> | .ast <sql> | .quit")
	case ".tables":
		tables := store.Tables()
		if len(tables) == 0 {
			fmt.Println("(no tables)")
			break
		}
		for _, t := range tables {
			fmt.Printf("id=%d name=%s columns=%d row_size=%d root_page=%d next_rowid=%d\n", t.ID, t.Name, len(t.Schema.Columns), t.Schema.RowSize, t.tree.RootPage(), t.nextRowID)
		}
	case ".schema":
		if len(parts) != 2 {
			fmt.Println("usage: .schema <table>")
			break
		}
		text, err := store.DescribeTable(parts[1])
		if err != nil {
			fmt.Println("schema error:", err)
		} else {
			fmt.Print(text)
		}
	case ".tree":
		if len(parts) != 2 {
			fmt.Println("usage: .tree <table>")
			break
		}
		text, err := store.TreeDump(parts[1])
		if err != nil {
			fmt.Println("tree error:", err)
		} else {
			fmt.Print(text)
		}
	case ".datapages":
		if len(parts) != 2 {
			fmt.Println("usage: .datapages <table>")
			break
		}
		pages, err := store.DataChain(parts[1])
		if err != nil {
			fmt.Println("data pages error:", err)
		} else {
			fmt.Println("data_pages=", pages)
		}
	case ".catalogpages":
		pages, err := store.CatalogPages()
		if err != nil {
			fmt.Println("catalog pages error:", err)
		} else {
			fmt.Println("catalog_pages=", pages)
		}
	case ".stats":
		st := store.Stats()
		fmt.Printf("pages=%d cached=%d cache_hits=%d disk_reads=%d disk_writes=%d validation_failures=%d\n", st.TotalPages, st.CachedPages, st.CacheHits, st.DiskReads, st.DiskWrites, st.ValidationFailures)
	case ".flush":
		if err := store.Flush(); err != nil {
			fmt.Println("flush error:", err)
		} else {
			fmt.Println("dirty pages sealed, checksummed, and flushed")
		}
	case ".verify":
		pages, err := store.Verify()
		if err != nil {
			fmt.Println("verify error:", err)
		} else {
			fmt.Printf("verified %d pages\n", pages)
		}
	case ".pageinfo":
		if len(parts) != 2 {
			fmt.Println("usage: .pageinfo <page-number>")
			break
		}
		n, err := strconv.ParseUint(parts[1], 10, 64)
		if err != nil {
			fmt.Println("page number must be a non-negative integer")
			break
		}
		info, err := store.PageInfo(n)
		if err != nil {
			fmt.Println("pageinfo error:", err)
		} else {
			fmt.Printf("page=%d type=%s generation=%d checksum=%08x\n", info.Number, info.Type, info.Generation, info.Checksum)
		}
	case ".tokens":
		sql := strings.TrimSpace(strings.TrimPrefix(line, parts[0]))
		if sql == "" {
			fmt.Println("usage: .tokens <sql>")
			break
		}
		tokens, err := Lex(sql)
		if err != nil {
			fmt.Println(err)
			break
		}
		for _, tok := range tokens {
			fmt.Printf("%-10s pos=%-3d lexeme=%q\n", tok.Kind, tok.Pos, tok.Lexeme)
		}
	case ".ast":
		sql := strings.TrimSpace(strings.TrimPrefix(line, parts[0]))
		if sql == "" {
			fmt.Println("usage: .ast <sql>")
			break
		}
		stmt, err := ParseSQL(sql)
		if err != nil {
			fmt.Println(err)
		} else {
			fmt.Print(DescribeAST(stmt))
		}
	default:
		fmt.Println("unknown meta command; try .help")
	}
	return false
}

		os.Exit(1)

	for {
		fmt.Print("minidb> ")
		if !scanner.Scan() {
			fmt.Println()
			break
		}
		line := strings.TrimSpace(scanner.Text())
		if line == "" {
			continue
		}
		if strings.HasPrefix(line, ".") {

		}

	}
}

36. What you should understand before leaving Part 6

Before moving on, you should be able to explain the entire path of this statement without looking at the code:

SELECT rowid, name FROM users WHERE rowid = 2;
  1. The REPL preserves the raw line instead of splitting on whitespace.
  2. The lexer emits keyword, identifier, punctuation, operator, number, semicolon, and EOF tokens.
  3. The recursive-descent parser checks those tokens against the SELECT grammar.
  4. The parser builds a SelectStmt with a BinaryExpr WHERE tree.
  5. The executor resolves the users table and requested columns against the Part 5 catalog/schema.
  6. The executor recognizes the supported rowid = integer predicate.
  7. It calls Store.Get instead of scanning.
  8. The table's persistent B+tree maps rowid 2 to a physical record pointer.
  9. The pager supplies the data page and validates the page format/checksum as usual.
  10. The row decoder uses the persisted schema to recover values.
  11. The executor projects only rowid and name for output.
The architecture after Part 6

MiniSQLite now has two major halves that finally meet cleanly: a language front end (lexer → parser → AST) and a storage engine (catalog → schema → B+tree → pager → reliable pages). The executor is the bridge between them.

The pain that should now bother you

We can parse SQL, but our executor is primitive. It knows “scan everything” or “rowid lookup.” The parser can already describe predicates the executor refuses to run. That is the next natural pressure: expression evaluation, binding, planning, and richer query execution.

That discomfort is useful. Just as full scans motivated the B+tree and hard-coded rows motivated schemas, the gap between a valid AST and an efficient execution strategy will motivate the next database subsystem.
