Transactions and Recovery

A checksum can tell us that one page is damaged, but it cannot make three related page writes happen atomically. In Part 8 we add the first real transaction protocol: BEGIN, COMMIT, ROLLBACK, a page-oriented rollback journal, autocommit, crash simulation, and automatic recovery before the database is opened.

How to use this chapter

Start from the working Part 7 project and type the changes in order. Run the rollback and crash checkpoints even if the code seems obvious. Recovery code is learned by observing failure boundaries, not by reading a finished file once.

The database format does not need a migration

2. The failure Part 3 could detect but not repair

Part 3 added page headers and checksums. That lets us detect a page whose bytes are internally damaged. But a database can be logically inconsistent even when every individual page has a valid checksum.

Imagine one INSERT. In our engine that single logical action may touch several persistent structures:

INSERT INTO users VALUES ('alice', 30, true);

possible physical changes:
  data page       -> store the encoded row
  B+tree leaf     -> rowid -> (page, slot)
  B+tree internal -> maybe changed because of a split
  catalog page    -> next_rowid / root / data-chain metadata

Suppose the data page reaches disk, then the process crashes before the B+tree page does. Both pages that exist on disk may pass their checksums. The problem is not “one page is corrupt.” The problem is “the database contains half of one logical change.”

Checksums solve a different problem

A checksum answers “are these page bytes the same bytes we sealed?” It does not answer “did all pages belonging to one transaction reach disk together?” Part 8 is about the second question.

3. Atomicity: define the promise before writing code

A transaction gives us an atomicity boundary. For this chapter, the promise is intentionally simple:

BEGIN;
  change A
  change B
  change C
COMMIT;

visible durable outcome after a crash:
  either A + B + C
  or     none of A, B, C

There must not be a durable state containing only A and B. If the user explicitly asks for ROLLBACK, the same “none of them” result must happen without a crash.

We will also preserve the familiar durability rule: once COMMIT succeeds and returns to the caller, the database pages have been synced to disk.

Scope of Part 8

We are building a single-process, single-writer rollback-journal design. We are not implementing MVCC, concurrent readers during a writer, nested transactions, savepoints, or a production filesystem protocol. Those omissions are called out later instead of being hidden.

4. Why a rollback journal uses before-images

There are two broad ways to recover a transaction. A redo system remembers what the new state should become. A rollback journal remembers what the old state was. For this chapter we choose rollback because it connects directly to our page abstraction.

Before overwriting an existing database page, save its last durable 4096-byte image:

database page 7 before transaction
        |
        | copy old bytes first
        v
users.db-journal
  [page_number=7][4096-byte before-image]
        |
        | only after journal is durable
        v
users.db page 7 may be overwritten

If the transaction commits, those old bytes are no longer needed and the journal can be deleted. If it rolls back—or the process crashes while the journal still exists—we copy those old page images back.

The journal is an undo log

The journal does not contain SQL. It does not say “delete Alice.” It contains enough physical information to put persistent pages back exactly as they were before the transaction.

5. New pages require a different kind of undo

A before-image only exists for a page that already existed at BEGIN. What about a transaction that allocates pages for a new table, a new data page, or a B+tree split?

The simplest answer is to remember the original database length:

BEGIN
original_pages = 12

transaction allocates pages:
  12, 13, 14, 15

ROLLBACK
  restore old images for pages 0..11 that were overwritten
  truncate database back to 12 pages

This gives us both halves of undo:

ChangeUndo information
Existing page overwritten4096-byte before-image in journal
New page allocatedOriginal page count; truncate back to it

6. Design the journal file before implementing it

Like the main database, the journal needs a tiny format. Keeping it explicit makes crash reasoning much easier.

Journal header (32 bytes)
+0   8 bytes   magic        "MDBJNL01"
+8   4 bytes   version      1
+12  4 bytes   page_size    4096
+16  8 bytes   original_pages
+24  8 bytes   reserved

Then zero or more fixed-size entries:
+0   8 bytes   page_number
+8   4096      complete old database page

entry size = 4104 bytes

We do not need a separate checksum for the before-image in this teaching design because the image is itself a normal sealed database page. Recovery runs the normal page validator before restoring it.

What if the final journal entry is only half-written?

That is safe only because the pager follows a write-ahead rule: it never starts overwriting the corresponding database page until the complete journal entry has been written and synced. Therefore a partial final entry can be ignored during recovery.

7. The ordering rule that makes the journal meaningful

The entire recovery design depends on one ordering constraint. It is more important than any struct definition in this chapter:

WRONG:
  1. overwrite database page
  2. save old page in journal

crash between 1 and 2 -> old bytes are gone

RIGHT:
  1. write old page to journal
  2. fsync journal
  3. overwrite database page
  4. later fsync database

This is a form of the write-ahead rule: recovery information must become durable before the database page that depends on it is allowed to become durable.

Write order is part of correctness

If you remove or reorder the journal sync because it “looks slow,” you are not merely changing performance. You are deleting the guarantee that makes rollback after a crash possible.

9. A journal object should know only journal mechanics

Create transaction.go. Keep the sidecar format separate from SQL and separate from B+tree logic. A rollback journal needs only a few responsibilities:

type RollbackJournal struct {
    path          string
    file          *os.File
    originalPages uint64
    recorded      map[uint64]bool
}

The recorded map prevents us from saving page 7 ten times if the transaction modifies and flushes page 7 repeatedly. Undo needs the page image from before the transaction, not every intermediate version.

Create and sync the header at BEGIN

    path := dbPath + "-journal"
    f, err := os.OpenFile(path, os.O_CREATE|os.O_EXCL|os.O_RDWR, 0644)
    // write magic, version, page size, originalPages
    // f.Sync() before BEGIN is considered established
    ...
}

O_EXCL is useful here. A journal that already exists is not something a new transaction should silently overwrite; on normal startup it should have been recovered first.

10. Where do we get an old page after memory has already changed?

There is an easy trap in page-oriented journaling. Much of our existing code mutates page.Data and only then calls page.MarkDirty(). If we try to create the before-image at MarkDirty(), we may already be looking at the new bytes.

Instead, teach each cached page to remember its last durable image:

type Page struct {
    Number    uint64
    Type      PageType
    Data      []byte
    dirty     bool
    cleanData []byte // last bytes known to be durable on disk
}

When GetPage reads and validates a page from disk:

page.cleanData = cloneBytes(page.Data)

After a successful flush:

page.cleanData = cloneBytes(page.Data)

So even if Data has been edited in memory, cleanData remains the correct before-image until the page is durably written.

Journal at the dangerous boundary

We do not actually need to write the journal when memory changes. We need to write it immediately before an old database page would be overwritten on disk. That boundary is FlushPage.

11. BEGIN establishes the state we promise to restore

Pager.Begin first establishes a clean durable baseline. Then it creates the journal.

func (p *Pager) Begin() error {
    if p.txActive {
        return fmt.Errorf("transaction already active")
    }

    if err := p.FlushAll(); err != nil {
        return err
    }

    j, err := CreateRollbackJournal(p.path, p.numPages)
    if err != nil {
        return err
    }

    p.txActive = true
    p.txOriginalPages = p.numPages
    p.journal = j
    return nil
}

Why flush first? Because “the state before this transaction” must be a durable, well-defined state. Part 8 will later make ordinary mutations autocommit, so in normal use there should not be unrelated dirty writes waiting here anyway. The initial flush makes the invariant explicit.

12. Teach FlushPage to obey the journal rule

This is the heart of the implementation. Immediately before an existing page is overwritten, save its old durable image:

if p.txActive && pageNum < p.txOriginalPages {
    if err := p.journal.RecordPage(pageNum, page.cleanData); err != nil {
        return err
    }
}

sealPageData(page.Data)
p.file.WriteAt(page.Data, int64(pageNum)*PageSize)

RecordPage itself syncs the journal entry before returning. Therefore the database write cannot happen first.

Notice the condition pageNum < txOriginalPages. A page allocated after BEGIN has no old image. Rollback will remove it by truncating the file.

13. Why uncommitted rows can still be visible to the same transaction

A transaction is not required to hide its own changes from itself. Our executor and cursors read through the same pager cache that mutations update, so this is expected:

BEGIN;
INSERT INTO users VALUES ('bob', 25, true);
SELECT * FROM users;

-- bob is visible here, even before COMMIT

The important distinction is between visible in this process and committed/durable. The cached page may contain Bob while the durable pre-transaction image still sits in cleanData and/or the journal.

14. ROLLBACK has two jobs: restore disk and restore memory

Restoring physical pages is only half of rollback. During the transaction our Go objects may also have changed:

table.nextRowID
B+tree root page number
table.lastData
catalog entries
store.tableCount
store.nextTableID

Therefore rollback proceeds in two layers.

Layer 1 — pager rollback

1. close the open journal handle
2. restore every complete before-image
3. truncate database to original_pages * 4096
4. fsync database
5. delete journal
6. discard every cached Page object

Layer 2 — store reload

s.tables = make(map[string]*Table)
read page 0 metadata again
walk catalog pages again
reconstruct Table objects and B+tree roots again

This is deliberately conservative. Instead of trying to reverse every in-memory field mutation individually, we use the recovered disk image as the source of truth.

This pattern is worth remembering

Recovery is not complete until all layers agree on the recovered state. “Disk was fixed” is insufficient if the process keeps stale metadata objects that still point at rolled-back pages.

15. Implement recovery as a startup operation too

The same restore logic used by explicit ROLLBACK must run after a process crash. A crash does not give us a chance to call a Go method, so OpenPager checks for the sidecar journal before the Store loads metadata or catalog pages.

func OpenPager(path string) (*Pager, error) {
    file, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0644)
    ...

    if _, err := RecoverJournal(path, file); err != nil {
        file.Close()
        return nil, err
    }

    // only now inspect database length and start loading pages
    ...
}

This order matters. If page 0 was one of the uncommitted pages written before the crash, trying to interpret it first could load transaction-state metadata that should never survive.

16. How recovery reads a possibly interrupted journal

Recovery reads the durable 32-byte header first. Then it processes only complete entries:

for {
    read 8-byte page number
    read exactly 4096 bytes of before-image

    if final entry is incomplete:
        stop and ignore that partial tail

    validatePageData(pageNum, image)
    db.WriteAt(image, pageNum * 4096)
}

db.Truncate(originalPages * 4096)
db.Sync()
remove journal

Why validate the image? Because an invalid rollback image is worse than a clean recovery failure. If the journal claims to contain old page 5 but the page header says it is page 9, recovery refuses to guess.

17. COMMIT is mostly an ordering protocol

Once a transaction is ready to commit, we do not need to copy anything forward from the journal. The current pages in memory are already the desired new state. We need to make that state durable in the right order:

COMMIT
  1. for each dirty old page:
       ensure before-image is durable in journal
       write new sealed page to database
  2. write any newly allocated pages
  3. fsync database file
  4. close + delete rollback journal
  5. report COMMIT success

After step 3 the new database image is durable. If the process crashes before step 4 and before COMMIT returns, startup may see the remaining journal and roll the transaction back. That is acceptable for this model: the client never received a successful commit acknowledgement.

The journal file is the transaction marker

In this small design, “journal exists” means an unfinalized transaction may need undo. Deleting the journal is the final commit marker.

18. Normal statements need autocommit

Adding explicit transactions must not make ordinary SQL unsafe. Before Part 8, users could type a standalone INSERT without BEGIN. We keep that convenient behavior by wrapping each mutating statement in an automatic transaction when no explicit transaction is active.

INSERT INTO users VALUES ('alice', 30, true);

behaves like:

BEGIN;
INSERT INTO users VALUES ('alice', 30, true);
COMMIT;

The executor wrapper can express this cleanly:

if store.InTransaction() {
    return executeStatementBody(store, stmt)
}

store.Begin()
result, err := executeStatementBody(store, stmt)
if err != nil {
    store.Rollback()
    return error
}
store.Commit()
return result

SELECT does not need an automatic write transaction, while BEGIN, COMMIT, and ROLLBACK obviously manage their own transaction state.

19. Add observability before running destructive tests

Transactions are much easier to understand when we can see their physical artifacts. Add three meta commands that are explicitly for this course:

.tx
  transaction=active

.journal
  journal=present original_pages=4 entries=3 bytes=12344

.crash
  exits immediately with os.Exit(99)
  deferred Store.Close() does NOT run

.crash is intentionally different from .quit. A normal quit runs deferred cleanup and rolls back an open transaction. A simulated crash must bypass cleanup so that the journal is left behind for the next process to discover.

Use .crash only on practice databases

It intentionally exits without normal shutdown. That is exactly what we need for this chapter, but it is not a user-facing database command.

20. Checkpoint: explicit ROLLBACK without any disk flush

First test the easiest case. The modified pages remain only in memory, so rollback can discard the cache and reload the old committed database.

CREATE TABLE users (
    name TEXT(32) NOT NULL,
    age INT NOT NULL
);

INSERT INTO users VALUES ('alice', 30);

BEGIN;
INSERT INTO users VALUES ('bob', 25);
SELECT * FROM users;
.journal
ROLLBACK;
SELECT * FROM users;
.journal

During the transaction you should see Alice and Bob. Before any flush, the journal normally has zero page entries: its header exists, but no old database page has yet been overwritten. After rollback, Bob disappears and the journal disappears.

21. Checkpoint: force uncommitted bytes onto disk

Now make the problem real. Start a transaction, mutate data, and explicitly flush dirty pages while the transaction is still open:

BEGIN;
INSERT INTO users VALUES ('carol', 40);
.flush
.journal

At this point the database file may physically contain Carol. That is not a bug. The rollback journal contains the old images needed to undo those writes. You have separated two concepts that beginners often mix together:

written to database file != committed transaction

Then:

ROLLBACK;
SELECT * FROM users;

Carol must disappear even though her bytes had already reached the main file.

22. The crash experiment: leave a hot journal behind

This is the central lab for Part 8. Use a separate terminal or simply restart the program after it exits.

./minidb crash.db

minidb> CREATE TABLE users (name TEXT(32) NOT NULL, age INT NOT NULL);
minidb> INSERT INTO users VALUES ('alice', 30);
minidb> BEGIN;
minidb> INSERT INTO users VALUES ('uncommitted', 999);
minidb> .flush
minidb> .journal
journal=present original_pages=4 entries=3 bytes=12344
minidb> .crash

The process exits without Close. On disk you should now see both files:

crash.db
crash.db-journal

Restart:

./minidb crash.db
minidb> SELECT * FROM users;

rowid | name | age
1 | alice | 30
(1 row(s))

minidb> .journal
journal=absent

The second process performed recovery before it loaded the catalog. The uncommitted row never becomes part of the recovered database state.

This is the moment Part 8 becomes real

You have allowed uncommitted database pages to reach disk, killed the process without cleanup, and still recovered the previously committed state. That is qualitatively different from merely keeping changes in RAM until commit.

23. Rollback CREATE TABLE proves truncation matters

INSERT into an existing table mostly overwrites existing pages. Creating a table is a better test for newly allocated pages.

BEGIN;
CREATE TABLE temp (x INT NOT NULL);
INSERT INTO temp VALUES (1);
.flush
.tables
.stats
ROLLBACK;
.tables
.stats

During the transaction, pages for the new B+tree and data storage can be allocated and even written. After rollback the table must disappear and the database file must shrink back to the page count recorded at BEGIN.

This demonstrates why a journal full of old pages alone is not sufficient. There is no old image for a page that did not exist before the transaction.

24. Rollback DELETE proves before-images restore content

Deletion in our engine uses tombstones and may also update persistent structures. Test that undo restores the old row bytes:

BEGIN;
DELETE FROM users WHERE rowid = 1;
SELECT * FROM users;
.flush
ROLLBACK;
SELECT * FROM users;

The row should vanish inside the transaction and return after rollback. Again, the executor does not contain special “undelete” logic. Physical page restoration does the work.

25. Transaction state errors should be boring and explicit

A reliable transaction API also rejects impossible transitions:

BEGIN;
BEGIN;
-- error: transaction already active

COMMIT;
COMMIT;
-- error: no active transaction

ROLLBACK;
-- error: no active transaction

These errors belong at the transaction boundary, not in B+tree code or the parser. Keeping ownership clear is part of the architecture.

26. What happens when a statement fails inside BEGIN?

Part 8 gives the user transaction-level rollback, but it does not yet implement statement savepoints. Suppose an explicit transaction contains several successful changes and then one statement returns an execution error. The transaction remains active so the caller can inspect the situation and choose ROLLBACK.

A production SQL engine usually has stronger statement-level atomicity rules and savepoint machinery. We deliberately do not pretend we implemented those. The safe learning habit in this part is:

BEGIN;
...
-- if a mutating statement fails unexpectedly:
ROLLBACK;
A limitation is not a mystery if it is named

The goal is to understand the transaction mechanism we actually built. Adding hidden behavior that looks more SQLite-like but has not been derived would make the lesson less trustworthy.

27. Why Verify and PageInfo are still useful during a transaction

Part 3’s validation tools still matter. .flush, .verify, or .pageinfo may cause dirty pages to be written while a transaction is active. That is safe only because FlushPage now owns the journal-before-overwrite rule.

This is an architectural payoff: callers do not each need to remember “if transaction active, journal this page.” The pager centralizes that rule at the disk-write boundary.

Centralize dangerous invariants

Whenever correctness depends on “every physical page write must first do X,” put X in the one function through which physical page writes flow. Do not rely on dozens of higher-level callers remembering it.

29. The journal and checksums work together

Part 3 and Part 8 are complementary rather than competing designs.

checksums:
  "is this page internally the page we sealed?"

rollback journal:
  "if this transaction did not finish, what old page should be restored?"

Recovery validates a journal before-image using the same page header and CRC rules as normal reads. After recovery, .verify can scan the restored database. This layering is exactly why we spent time giving pages a stable physical format earlier in the project.

30. Autocommit changes the durability behavior of earlier chapters

In Part 7, ordinary mutations could sit dirty in the pager cache until a later flush or process close. Part 8 intentionally tightens that behavior: a standalone mutating SQL statement runs as a complete transaction and commits before reporting success.

INSERT ...;

Part 8 executor:
  BEGIN
  execute INSERT
  COMMIT -> FlushAll -> file.Sync -> remove journal
  print "inserted 1 row"

This means the REPL’s success message now has a stronger meaning. The statement’s transaction has crossed the durability boundary rather than merely modifying cached pages.

31. Why this is a rollback journal, not a WAL

The term write-ahead log is often used broadly, but the specific design here is a rollback journal: it stores old page images for undo, then database pages are written in place.

Rollback journal (this part)WAL-style design (future alternative)
Stores before-imagesTypically stores new changes/redo records
Main DB pages may be overwritten before commit completesMain DB can remain unchanged while log accumulates
Recovery undoes unfinished transactionRecovery commonly replays committed log records
Simple fit for our current pagerBetter foundation for reader/writer concurrency, but more machinery

Understanding this distinction prevents the common mistake of calling every journal “WAL” even when its recovery direction is undo rather than redo.

32. Important production details we are not hiding

This is a teaching transaction system, not a drop-in replacement for SQLite’s pager. Several hard problems remain:

  • Directory fsync: durable creation/deletion of the journal filename has filesystem-specific details we do not implement.
  • File locking: another process could open the same database while a transaction is active. We have no locking protocol.
  • Concurrent readers/writers: this engine assumes one process/writer model.
  • Savepoints and nested transactions: unsupported.
  • Statement rollback: no internal savepoint per statement.
  • Journal growth: a transaction that dirties many old pages stores a full 4096-byte before-image for each one.
  • Power-loss semantics: real databases reason carefully about filesystem and storage-device guarantees beyond a simple fsync call.
  • Atomic journal deletion/commit markers: production systems use more rigorous protocols for all edge cases.

None of these invalidate the lesson. They tell you exactly what guarantee the current implementation can and cannot defend.

33. Exercises that make the recovery model stick

Exercise A — repeat a dirty page

Inside one transaction, change and flush the same table page several times. Use .journal. Explain why that page needs only one before-image.

Exercise B — allocate then roll back

Create enough rows to allocate a new data page, flush, then roll back. Compare the database file size before BEGIN, before rollback, and after rollback.

Exercise C — crash before .flush

BEGIN, INSERT, then .crash without flushing. Why does recovery have almost nothing to restore?

Exercise D — crash after .flush

Repeat with .flush. Inspect journal entry count and prove the row disappears on restart.

Exercise E — transactional DDL

CREATE TABLE inside BEGIN, flush it, then roll back. Explain which old pages are restored and which new pages disappear by truncation.

Exercise F — corrupt the journal

On a disposable DB, alter bytes in a complete before-image. Recovery should reject the invalid page rather than silently install it.

}

func initializePageData(data []byte, pageNum uint64, pageType PageType) error {
	if len(data) != PageSize {
		return fmt.Errorf("initialize page: expected %d bytes, got %d", PageSize, len(data))
	}
	if !validPageType(pageType) {
		return fmt.Errorf("initialize page: invalid page type %d", pageType)
	}
	clear(data)
	copy(data[0:4], []byte(PageMagic))
	binary.LittleEndian.PutUint16(data[4:6], PageHeaderVersion)
	data[6] = byte(pageType)
	binary.LittleEndian.PutUint64(data[8:16], pageNum)
	return nil
}

func computePageChecksum(data []byte) (uint32, error) {
	if len(data) != PageSize {
		return 0, fmt.Errorf("checksum: expected %d bytes, got %d", PageSize, len(data))
	}
	h := crc32.NewIEEE()
	_, _ = h.Write(data[:24])
	_, _ = h.Write([]byte{0, 0, 0, 0})
	_, _ = h.Write(data[28:])
	return h.Sum32(), nil
}

func decodePageHeader(data []byte) PageHeaderInfo {
	return PageHeaderInfo{
		Type:       PageType(data[6]),
		Number:     binary.LittleEndian.Uint64(data[8:16]),
		Generation: binary.LittleEndian.Uint64(data[16:24]),
		Checksum:   binary.LittleEndian.Uint32(data[24:28]),
	}
}

func sealPageData(data []byte) (PageHeaderInfo, error) {
	if len(data) != PageSize {
		return PageHeaderInfo{}, fmt.Errorf("seal page: expected %d bytes, got %d", PageSize, len(data))
	}
	generation := binary.LittleEndian.Uint64(data[16:24]) + 1
	binary.LittleEndian.PutUint64(data[16:24], generation)
	binary.LittleEndian.PutUint32(data[24:28], 0)
	checksum, err := computePageChecksum(data)
	if err != nil {
		return PageHeaderInfo{}, err
	}
	binary.LittleEndian.PutUint32(data[24:28], checksum)
	return decodePageHeader(data), nil
}

func validatePageData(expectedPageNum uint64, data []byte) (PageHeaderInfo, error) {
	if len(data) != PageSize {
		return PageHeaderInfo{}, fmt.Errorf("page %d: expected %d bytes, got %d", expectedPageNum, PageSize, len(data))
	}
	if string(data[0:4]) != PageMagic {
		return PageHeaderInfo{}, fmt.Errorf("page %d: bad page magic %q", expectedPageNum, string(data[0:4]))
	}
	if got := binary.LittleEndian.Uint16(data[4:6]); got != PageHeaderVersion {
		return PageHeaderInfo{}, fmt.Errorf("page %d: unsupported page-header version %d", expectedPageNum, got)
	}
	info := decodePageHeader(data)
	if !validPageType(info.Type) {
		return PageHeaderInfo{}, fmt.Errorf("page %d: invalid page type %d", expectedPageNum, info.Type)
	}
	if info.Number != expectedPageNum {
		return PageHeaderInfo{}, fmt.Errorf("page %d: stored page number is %d", expectedPageNum, info.Number)
	}
	if info.Checksum == 0 {
		return PageHeaderInfo{}, fmt.Errorf("page %d: missing checksum", expectedPageNum)
	}
	computed, err := computePageChecksum(data)
	if err != nil {
		return PageHeaderInfo{}, err
	}
	if computed != info.Checksum {
		return PageHeaderInfo{}, fmt.Errorf("page %d: checksum mismatch: stored=%08x computed=%08x", expectedPageNum, info.Checksum, computed)
	}
	return info, nil
}

package main

import (
	"encoding/binary"
	"fmt"
	"io"
	"os"
)

const (
	JournalMagic      = "MDBJNL01"
	JournalVersion    = uint32(1)
	JournalHeaderSize = 32
	JournalEntrySize  = 8 + PageSize
)

type RollbackJournal struct {
	path          string
	file          *os.File
	originalPages uint64
	recorded      map[uint64]bool
}

func journalPath(dbPath string) string { return dbPath + "-journal" }

func CreateRollbackJournal(dbPath string, originalPages uint64) (*RollbackJournal, error) {
	path := journalPath(dbPath)
	f, err := os.OpenFile(path, os.O_CREATE|os.O_EXCL|os.O_RDWR, 0644)
	if err != nil {
		return nil, fmt.Errorf("create rollback journal: %w", err)
	}
	header := make([]byte, JournalHeaderSize)
	copy(header[0:8], []byte(JournalMagic))
	binary.LittleEndian.PutUint32(header[8:12], JournalVersion)
	binary.LittleEndian.PutUint32(header[12:16], PageSize)
	binary.LittleEndian.PutUint64(header[16:24], originalPages)
	if _, err := f.Write(header); err != nil {
		f.Close()
		return nil, err
	}
	if err := f.Sync(); err != nil {
		f.Close()
		return nil, err
	}
	return &RollbackJournal{path: path, file: f, originalPages: originalPages, recorded: make(map[uint64]bool)}, nil
}

func (j *RollbackJournal) RecordPage(pageNum uint64, before []byte) error {
	if j.recorded[pageNum] {
		return nil
	}
	if len(before) != PageSize {
		return fmt.Errorf("journal page %d: expected %d bytes, got %d", pageNum, PageSize, len(before))
	}
	if _, err := validatePageData(pageNum, before); err != nil {
		return fmt.Errorf("journal page %d before-image invalid: %w", pageNum, err)
	}
	entry := make([]byte, JournalEntrySize)
	binary.LittleEndian.PutUint64(entry[0:8], pageNum)
	copy(entry[8:], before)
	if _, err := j.file.Write(entry); err != nil {
		return fmt.Errorf("journal page %d: %w", pageNum, err)
	}
	// This sync is what makes it safe to overwrite the corresponding DB page.
	if err := j.file.Sync(); err != nil {
		return fmt.Errorf("sync journal page %d: %w", pageNum, err)
	}
	j.recorded[pageNum] = true
	return nil
}

func (j *RollbackJournal) Close() error {
	if j.file == nil {
		return nil
	}
	err := j.file.Close()
	j.file = nil
	return err
}

func (j *RollbackJournal) CloseAndRemove() error {
	if err := j.Close(); err != nil {
		return err
	}
	if err := os.Remove(j.path); err != nil && !os.IsNotExist(err) {
		return err
	}
	return nil
}

type JournalInfo struct {
	Exists        bool
	OriginalPages uint64
	Entries       int
	Size          int64
}

func InspectJournal(dbPath string) (JournalInfo, error) {
	path := journalPath(dbPath)
	info, err := os.Stat(path)
	if os.IsNotExist(err) {
		return JournalInfo{}, nil
	}
	if err != nil {
		return JournalInfo{}, err
	}
	f, err := os.Open(path)
	if err != nil {
		return JournalInfo{}, err
	}
	defer f.Close()
	original, err := readJournalHeader(f)
	if err != nil {
		return JournalInfo{Exists: true, Size: info.Size()}, err
	}
	complete := info.Size() - JournalHeaderSize
	entries := 0
	if complete > 0 {
		entries = int(complete / JournalEntrySize)
	}
	return JournalInfo{Exists: true, OriginalPages: original, Entries: entries, Size: info.Size()}, nil
}

func readJournalHeader(f *os.File) (uint64, error) {
	header := make([]byte, JournalHeaderSize)
	if _, err := io.ReadFull(f, header); err != nil {
		return 0, err
	}
	if string(header[0:8]) != JournalMagic {
		return 0, fmt.Errorf("bad journal magic")
	}
	if v := binary.LittleEndian.Uint32(header[8:12]); v != JournalVersion {
		return 0, fmt.Errorf("unsupported journal version %d", v)
	}
	if ps := binary.LittleEndian.Uint32(header[12:16]); ps != PageSize {
		return 0, fmt.Errorf("journal page size %d does not match %d", ps, PageSize)
	}
	return binary.LittleEndian.Uint64(header[16:24]), nil
}

// RecoverJournal restores every complete before-image and truncates pages that
// were allocated after BEGIN. A partial final journal entry is safe to ignore:
// the pager never overwrites that database page until the complete entry has
// been fsynced.
func RecoverJournal(dbPath string, db *os.File) (bool, error) {
	path := journalPath(dbPath)
	jf, err := os.Open(path)
	if os.IsNotExist(err) {
		return false, nil
	}
	if err != nil {
		return false, err
	}
	defer jf.Close()

	st, err := jf.Stat()
	if err != nil {
		return false, err
	}
	if st.Size() < JournalHeaderSize {
		// The journal header never became durable, so the pager could not have
		// started overwriting database pages under this transaction.
		jf.Close()
		_ = os.Remove(path)
		return true, nil
	}

	originalPages, err := readJournalHeader(jf)
	if err != nil {
		return false, fmt.Errorf("cannot recover %s: %w", path, err)
	}

	for {
		prefix := make([]byte, 8)
		n, err := io.ReadFull(jf, prefix)
		if err == io.EOF || err == io.ErrUnexpectedEOF {
			break
		}
		if err != nil {
			return false, err
		}
		if n != 8 {
			break
		}
		pageNum := binary.LittleEndian.Uint64(prefix)
		image := make([]byte, PageSize)
		if _, err := io.ReadFull(jf, image); err == io.EOF || err == io.ErrUnexpectedEOF {
			break
		} else if err != nil {
			return false, err
		}
		if pageNum >= originalPages {
			return false, fmt.Errorf("journal contains impossible old page %d (original pages=%d)", pageNum, originalPages)
		}
		if _, err := validatePageData(pageNum, image); err != nil {
			return false, fmt.Errorf("journal before-image page %d failed validation: %w", pageNum, err)
		}
		if _, err := db.WriteAt(image, int64(pageNum)*PageSize); err != nil {
			return false, err
		}
	}

	if err := db.Truncate(int64(originalPages) * PageSize); err != nil {
		return false, err
	}
	if err := db.Sync(); err != nil {
		return false, err
	}
	jf.Close()
	if err := os.Remove(path); err != nil && !os.IsNotExist(err) {
		return false, err
	}
	return true, nil
}

package main

import (
	"fmt"
	"io"
	"os"
	"sort"
)

type Page struct {
	Number    uint64
	Type      PageType
	Data      []byte
	dirty     bool
	cleanData []byte // last durable image of this page
}

func (p *Page) MarkDirty() { p.dirty = true }

type PagerStats struct {
	CachedPages        int
	TotalPages         uint64
	CacheHits          uint64
	DiskReads          uint64
	DiskWrites         uint64
	ValidationFailures uint64
}

type Pager struct {
	path               string
	file               *os.File
	pages              map[uint64]*Page
	numPages           uint64
	cacheHits          uint64
	diskReads          uint64
	diskWrites         uint64
	validationFailures uint64

	txActive        bool
	txOriginalPages uint64
	journal         *RollbackJournal
}

func OpenPager(path string) (*Pager, error) {
	file, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0644)
	if err != nil {
		return nil, err
	}

	if recovered, err := RecoverJournal(path, file); err != nil {
		file.Close()
		return nil, err
	} else if recovered {
		// Recovery writes directly to the file and fsyncs it before returning.
	}

	info, err := file.Stat()
	if err != nil {
		file.Close()
		return nil, err
	}
	if info.Size()%PageSize != 0 {
		file.Close()
		return nil, fmt.Errorf("database size %d is not a multiple of page size %d", info.Size(), PageSize)
	}
	return &Pager{path: path, file: file, pages: make(map[uint64]*Page), numPages: uint64(info.Size() / PageSize)}, nil
}

func cloneBytes(b []byte) []byte {
	out := make([]byte, len(b))
	copy(out, b)
	return out
}

func (p *Pager) GetPage(pageNum uint64) (*Page, error) {
	if page, ok := p.pages[pageNum]; ok {
		p.cacheHits++
		return page, nil
	}
	if pageNum >= p.numPages {
		return nil, fmt.Errorf("page %d does not exist", pageNum)
	}
	page := &Page{Number: pageNum, Data: make([]byte, PageSize)}
	n, err := p.file.ReadAt(page.Data, int64(pageNum)*PageSize)
	if err != nil && err != io.EOF {
		return nil, fmt.Errorf("read page %d: %w", pageNum, err)
	}
	if n != PageSize {
		return nil, fmt.Errorf("read page %d: expected %d bytes, got %d", pageNum, PageSize, n)
	}
	p.diskReads++
	info, err := validatePageData(pageNum, page.Data)
	if err != nil {
		p.validationFailures++
		return nil, err
	}
	page.Type = info.Type
	page.cleanData = cloneBytes(page.Data)
	p.pages[pageNum] = page
	return page, nil
}

func (p *Pager) NewPage(pageType PageType) (*Page, error) {
	pageNum := p.numPages
	page := &Page{Number: pageNum, Type: pageType, Data: make([]byte, PageSize), dirty: true}
	if err := initializePageData(page.Data, pageNum, pageType); err != nil {
		return nil, err
	}
	p.pages[pageNum] = page
	p.numPages++
	return page, nil
}

func (p *Pager) FlushPage(pageNum uint64) error {
	page, ok := p.pages[pageNum]
	if !ok || !page.dirty {
		return nil
	}

	// WAL rule for our rollback journal: before overwriting an old database
	// page, make its old durable image durable in the journal first.
	if p.txActive && pageNum < p.txOriginalPages {
		if page.cleanData == nil {
			return fmt.Errorf("page %d has no durable before-image", pageNum)
		}
		if err := p.journal.RecordPage(pageNum, page.cleanData); err != nil {
			return err
		}
	}

	if _, err := sealPageData(page.Data); err != nil {
		return err
	}
	n, err := p.file.WriteAt(page.Data, int64(pageNum)*PageSize)
	if err != nil {
		return fmt.Errorf("write page %d: %w", pageNum, err)
	}
	if n != PageSize {
		return fmt.Errorf("write page %d: expected %d bytes, wrote %d", pageNum, PageSize, n)
	}
	page.dirty = false
	page.cleanData = cloneBytes(page.Data)
	p.diskWrites++
	return nil
}

func (p *Pager) FlushAll() error {
	nums := make([]uint64, 0, len(p.pages))
	for n := range p.pages {
		nums = append(nums, n)
	}
	sort.Slice(nums, func(i, j int) bool { return nums[i] < nums[j] })
	for _, n := range nums {
		if err := p.FlushPage(n); err != nil {
			return err
		}
	}
	return p.file.Sync()
}

func (p *Pager) Begin() error {
	if p.txActive {
		return fmt.Errorf("transaction already active")
	}
	// Establish a clean, durable boundary for the state the journal protects.
	if err := p.FlushAll(); err != nil {
		return err
	}
	j, err := CreateRollbackJournal(p.path, p.numPages)
	if err != nil {
		return err
	}
	p.txActive = true
	p.txOriginalPages = p.numPages
	p.journal = j
	return nil
}

func (p *Pager) Commit() error {
	if !p.txActive {
		return fmt.Errorf("no active transaction")
	}
	if err := p.FlushAll(); err != nil {
		return err
	}
	if err := p.journal.CloseAndRemove(); err != nil {
		return err
	}
	p.txActive = false
	p.txOriginalPages = 0
	p.journal = nil
	return nil
}

func (p *Pager) Rollback() error {
	if !p.txActive {
		return fmt.Errorf("no active transaction")
	}
	if err := p.journal.Close(); err != nil {
		return err
	}
	if _, err := RecoverJournal(p.path, p.file); err != nil {
		return err
	}
	info, err := p.file.Stat()
	if err != nil {
		return err
	}
	p.pages = make(map[uint64]*Page)
	p.numPages = uint64(info.Size() / PageSize)
	p.txActive = false
	p.txOriginalPages = 0
	p.journal = nil
	return nil
}

func (p *Pager) InTransaction() bool { return p.txActive }

func (p *Pager) VerifyAll() (uint64, error) {
	if err := p.FlushAll(); err != nil {
		return 0, err
	}
	buf := make([]byte, PageSize)
	for pageNum := uint64(0); pageNum < p.numPages; pageNum++ {
		n, err := p.file.ReadAt(buf, int64(pageNum)*PageSize)
		if err != nil && err != io.EOF {
			return pageNum, fmt.Errorf("verify page %d: %w", pageNum, err)
		}
		if n != PageSize {
			return pageNum, fmt.Errorf("verify page %d: expected %d bytes, got %d", pageNum, PageSize, n)
		}
		if _, err := validatePageData(pageNum, buf); err != nil {
			p.validationFailures++
			return pageNum, err
		}
	}
	return p.numPages, nil
}

func (p *Pager) PageInfo(pageNum uint64) (PageHeaderInfo, error) {
	page, err := p.GetPage(pageNum)
	if err != nil {
		return PageHeaderInfo{}, err
	}
	if page.dirty {
		if err := p.FlushPage(pageNum); err != nil {
			return PageHeaderInfo{}, err
		}
	}
	return validatePageData(pageNum, page.Data)
}

func (p *Pager) Stats() PagerStats {
	return PagerStats{len(p.pages), p.numPages, p.cacheHits, p.diskReads, p.diskWrites, p.validationFailures}
}

func (p *Pager) Close() error {
	if p.txActive {
		if err := p.Rollback(); err != nil {
			_ = p.file.Close()
			return err
		}
	} else if err := p.FlushAll(); err != nil {
		_ = p.file.Close()
		return err
	}
	return p.file.Close()
}

package main

import (
	"encoding/binary"
	"fmt"
	"strconv"
	"strings"
)

const (
	MaxColumns       = 10
	MaxColumnNameLen = 24
	MaxTextLen       = 512
	RowHeaderSize    = 24
)

type ColumnType uint8

const (
	TypeInt64 ColumnType = 1
	TypeText  ColumnType = 2
	TypeBool  ColumnType = 3
)

func (t ColumnType) String() string {
	switch t {
	case TypeInt64:
		return "INT"
	case TypeText:
		return "TEXT"
	case TypeBool:
		return "BOOL"
	default:
		return fmt.Sprintf("UNKNOWN(%d)", uint8(t))
	}
}

type Column struct {
	Name     string
	Type     ColumnType
	Nullable bool
	MaxLen   uint16
	Offset   uint16
	Width    uint16
}

type Schema struct {
	Columns []Column
	RowSize uint32
}

type Value struct {
	Type ColumnType
	Null bool
	Int  int64
	Text string
	Bool bool
}

type Row struct {
	RowID   int64
	Deleted bool
	Values  []Value
}

func columnWidth(c Column) (uint16, error) {
	switch c.Type {
	case TypeInt64:
		return 8, nil
	case TypeBool:
		return 1, nil
	case TypeText:
		if c.MaxLen == 0 || c.MaxLen > MaxTextLen {
			return 0, fmt.Errorf("TEXT length must be between 1 and %d", MaxTextLen)
		}
		return 2 + c.MaxLen, nil
	default:
		return 0, fmt.Errorf("unsupported column type %d", c.Type)
	}
}

func CompileSchema(columns []Column) (Schema, error) {
	if len(columns) == 0 {
		return Schema{}, fmt.Errorf("a table needs at least one column")
	}
	if len(columns) > MaxColumns {
		return Schema{}, fmt.Errorf("at most %d columns are supported", MaxColumns)
	}
	seen := map[string]bool{}
	compiled := make([]Column, len(columns))
	offset := RowHeaderSize
	for i, c := range columns {
		if c.Name == "" || len([]byte(c.Name)) > MaxColumnNameLen {
			return Schema{}, fmt.Errorf("column %q must be 1..%d bytes", c.Name, MaxColumnNameLen)
		}
		key := strings.ToLower(c.Name)
		if seen[key] {
			return Schema{}, fmt.Errorf("duplicate column name %q", c.Name)
		}
		seen[key] = true
		width, err := columnWidth(c)
		if err != nil {
			return Schema{}, fmt.Errorf("column %s: %w", c.Name, err)
		}
		if offset+int(width) > 65535 {
			return Schema{}, fmt.Errorf("row layout is too large")
		}
		c.Offset = uint16(offset)
		c.Width = width
		compiled[i] = c
		offset += int(width)
	}
	// Round rows to 8 bytes so offsets are easier to inspect in a hex dump.
	if rem := offset % 8; rem != 0 {
		offset += 8 - rem
	}
	if offset > PageSize-dataRowsOffset {
		return Schema{}, fmt.Errorf("row size %d is too large to fit in one data page", offset)
	}
	return Schema{Columns: compiled, RowSize: uint32(offset)}, nil
}

func ParseColumnSpec(spec string) (Column, error) {
	pair := strings.SplitN(spec, ":", 2)
	if len(pair) != 2 || pair[0] == "" || pair[1] == "" {
		return Column{}, fmt.Errorf("column spec %q must look like name:INT, name:BOOL, or name:TEXT(40)", spec)
	}
	name := pair[0]
	typeSpec := pair[1]
	nullable := false
	if strings.HasSuffix(typeSpec, "?") {
		nullable = true
		typeSpec = strings.TrimSuffix(typeSpec, "?")
	}
	upper := strings.ToUpper(typeSpec)
	c := Column{Name: name, Nullable: nullable}
	switch {
	case upper == "INT" || upper == "INTEGER" || upper == "INT64":
		c.Type = TypeInt64
	case upper == "BOOL" || upper == "BOOLEAN":
		c.Type = TypeBool
	case strings.HasPrefix(upper, "TEXT(") && strings.HasSuffix(upper, ")"):
		raw := upper[len("TEXT(") : len(upper)-1]
		n, err := strconv.Atoi(raw)
		if err != nil || n < 1 || n > MaxTextLen {
			return Column{}, fmt.Errorf("TEXT length in %q must be 1..%d", spec, MaxTextLen)
		}
		c.Type = TypeText
		c.MaxLen = uint16(n)
	default:
		return Column{}, fmt.Errorf("unsupported type %q", typeSpec)
	}
	return c, nil
}

func ParseValueToken(c Column, token string) (Value, error) {
	if strings.EqualFold(token, "NULL") {
		if !c.Nullable {
			return Value{}, fmt.Errorf("column %s is NOT NULL", c.Name)
		}
		return Value{Type: c.Type, Null: true}, nil
	}
	v := Value{Type: c.Type}
	switch c.Type {
	case TypeInt64:
		n, err := strconv.ParseInt(token, 10, 64)
		if err != nil {
			return Value{}, fmt.Errorf("column %s expects INT, got %q", c.Name, token)
		}
		v.Int = n
	case TypeBool:
		switch strings.ToLower(token) {
		case "true", "1", "yes":
			v.Bool = true
		case "false", "0", "no":
			v.Bool = false
		default:
			return Value{}, fmt.Errorf("column %s expects BOOL, got %q", c.Name, token)
		}
	case TypeText:
		if len([]byte(token)) > int(c.MaxLen) {
			return Value{}, fmt.Errorf("column %s allows at most %d UTF-8 bytes", c.Name, c.MaxLen)
		}
		v.Text = token
	default:
		return Value{}, fmt.Errorf("column %s has unsupported type %d", c.Name, c.Type)
	}
	return v, nil
}

func setNullBit(buf []byte, index int) {
	byteIndex := 16 + index/8
	bit := uint(index % 8)
	buf[byteIndex] |= 1 << bit
}

func nullBit(buf []byte, index int) bool {
	byteIndex := 16 + index/8
	bit := uint(index % 8)
	return buf[byteIndex]&(1<<bit) != 0
}

func EncodeRow(schema Schema, rowID int64, values []Value) ([]byte, error) {
	if len(values) != len(schema.Columns) {
		return nil, fmt.Errorf("expected %d values, got %d", len(schema.Columns), len(values))
	}
	buf := make([]byte, schema.RowSize)
	binary.LittleEndian.PutUint64(buf[8:16], uint64(rowID))
	for i, c := range schema.Columns {
		v := values[i]
		if v.Null {
			if !c.Nullable {
				return nil, fmt.Errorf("column %s is NOT NULL", c.Name)
			}
			setNullBit(buf, i)
			continue
		}
		if v.Type != c.Type {
			return nil, fmt.Errorf("column %s type mismatch", c.Name)
		}
		off := int(c.Offset)
		switch c.Type {
		case TypeInt64:
			binary.LittleEndian.PutUint64(buf[off:off+8], uint64(v.Int))
		case TypeBool:
			if v.Bool {
				buf[off] = 1
			}
		case TypeText:
			raw := []byte(v.Text)
			if len(raw) > int(c.MaxLen) {
				return nil, fmt.Errorf("column %s allows at most %d UTF-8 bytes", c.Name, c.MaxLen)
			}
			binary.LittleEndian.PutUint16(buf[off:off+2], uint16(len(raw)))
			copy(buf[off+2:off+2+len(raw)], raw)
		}
	}
	return buf, nil
}

func DecodeRow(schema Schema, buf []byte) (Row, error) {
	if len(buf) != int(schema.RowSize) {
		return Row{}, fmt.Errorf("decode row: expected %d bytes, got %d", schema.RowSize, len(buf))
	}
	row := Row{
		RowID:   int64(binary.LittleEndian.Uint64(buf[8:16])),
		Deleted: buf[0]&1 != 0,
		Values:  make([]Value, len(schema.Columns)),
	}
	for i, c := range schema.Columns {
		v := Value{Type: c.Type}
		if nullBit(buf, i) {
			v.Null = true
			row.Values[i] = v
			continue
		}
		off := int(c.Offset)
		switch c.Type {
		case TypeInt64:
			v.Int = int64(binary.LittleEndian.Uint64(buf[off : off+8]))
		case TypeBool:
			v.Bool = buf[off] != 0
		case TypeText:
			n := int(binary.LittleEndian.Uint16(buf[off : off+2]))
			if n > int(c.MaxLen) {
				return Row{}, fmt.Errorf("column %s has invalid text length %d", c.Name, n)
			}
			v.Text = string(buf[off+2 : off+2+n])
		default:
			return Row{}, fmt.Errorf("column %s has unsupported type %d", c.Name, c.Type)
		}
		row.Values[i] = v
	}
	return row, nil
}

func FormatValue(v Value) string {
	if v.Null {
		return "NULL"
	}
	switch v.Type {
	case TypeInt64:
		return strconv.FormatInt(v.Int, 10)
	case TypeBool:
		return strconv.FormatBool(v.Bool)
	case TypeText:
		return v.Text
	default:
		return "<?>"
	}
}

	catalogNextPageOffset  = 40
	catalogEntriesOffset   = 64

	CatalogSlotsPerPage    = (PageSize - catalogEntriesOffset) / CatalogEntrySize

	catalogActiveOffset    = 0
	catalogNameLenOffset   = 1
	catalogColumnCountOff  = 2
	catalogRowSizeOffset   = 4
	catalogTableIDOffset   = 8
	catalogRootPageOffset  = 16
	catalogFirstDataOffset = 24
	catalogLastDataOffset  = 32
	catalogNextRowIDOffset = 40
	catalogNameOffset      = 48
	catalogColumnsOffset   = 80

	catalogColumnSize       = 40
	catalogColTypeOffset    = 0
	catalogColNullableOff   = 1
	catalogColNameLenOffset = 2
	catalogColMaxLenOffset  = 4
	catalogColRowOffOffset  = 6
	catalogColWidthOffset   = 8
	catalogColNameOffset    = 16
)

type CatalogPointer struct {
	Page uint64
	Slot uint16
}

type Table struct {
	ID        uint64
	Name      string
	Schema    Schema
	tree      *BTree
	firstData uint64

func catalogSlotCount(page *Page) int {

}

func setCatalogSlotCount(page *Page, n int) {

	page.MarkDirty()
}

func catalogNextPage(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[catalogNextPageOffset : catalogNextPageOffset+8])
}

	binary.LittleEndian.PutUint64(page.Data[catalogNextPageOffset:catalogNextPageOffset+8], n)
	page.MarkDirty()
}

func catalogEntryRange(slot int) (int, int, error) {
	if slot < 0 || slot >= CatalogSlotsPerPage {
		return 0, 0, fmt.Errorf("catalog slot %d out of range", slot)
	}
	start := catalogEntriesOffset + slot*CatalogEntrySize
	return start, start + CatalogEntrySize, nil
}

func writeCatalogEntry(page *Page, slot int, t *Table) error {
	if page.Type != PageTypeCatalog {
		return fmt.Errorf("page %d is %s, expected catalog", page.Number, page.Type)
	}
	if len([]byte(t.Name)) == 0 || len([]byte(t.Name)) > MaxTableNameLen {
		return fmt.Errorf("table name must be 1..%d bytes", MaxTableNameLen)
	}
	if len(t.Schema.Columns) > MaxColumns {
		return fmt.Errorf("table %s has too many columns", t.Name)
	}
	start, end, err := catalogEntryRange(slot)
	if err != nil {
		return err
	}
	entry := page.Data[start:end]
	clear(entry)
	entry[catalogActiveOffset] = 1
	entry[catalogNameLenOffset] = byte(len([]byte(t.Name)))
	entry[catalogColumnCountOff] = byte(len(t.Schema.Columns))
	binary.LittleEndian.PutUint32(entry[catalogRowSizeOffset:catalogRowSizeOffset+4], t.Schema.RowSize)
	binary.LittleEndian.PutUint64(entry[catalogTableIDOffset:catalogTableIDOffset+8], t.ID)
	binary.LittleEndian.PutUint64(entry[catalogRootPageOffset:catalogRootPageOffset+8], t.tree.RootPage())
	binary.LittleEndian.PutUint64(entry[catalogFirstDataOffset:catalogFirstDataOffset+8], t.firstData)
	binary.LittleEndian.PutUint64(entry[catalogLastDataOffset:catalogLastDataOffset+8], t.lastData)
	binary.LittleEndian.PutUint64(entry[catalogNextRowIDOffset:catalogNextRowIDOffset+8], uint64(t.nextRowID))
	copy(entry[catalogNameOffset:catalogNameOffset+MaxTableNameLen], []byte(t.Name))

	for i, c := range t.Schema.Columns {
		off := catalogColumnsOffset + i*catalogColumnSize
		col := entry[off : off+catalogColumnSize]
		col[catalogColTypeOffset] = byte(c.Type)
		if c.Nullable {
			col[catalogColNullableOff] = 1
		}
		col[catalogColNameLenOffset] = byte(len([]byte(c.Name)))
		binary.LittleEndian.PutUint16(col[catalogColMaxLenOffset:catalogColMaxLenOffset+2], c.MaxLen)
		binary.LittleEndian.PutUint16(col[catalogColRowOffOffset:catalogColRowOffOffset+2], c.Offset)
		binary.LittleEndian.PutUint16(col[catalogColWidthOffset:catalogColWidthOffset+2], c.Width)
		copy(col[catalogColNameOffset:catalogColNameOffset+MaxColumnNameLen], []byte(c.Name))
	}
	page.MarkDirty()
	return nil
}

func readCatalogEntry(page *Page, slot int) (*Table, error) {
	start, end, err := catalogEntryRange(slot)
	if err != nil {
		return nil, err
	}
	entry := page.Data[start:end]
	if entry[catalogActiveOffset] == 0 {
		return nil, nil
	}
	nameLen := int(entry[catalogNameLenOffset])
	if nameLen < 1 || nameLen > MaxTableNameLen {
		return nil, fmt.Errorf("catalog page %d slot %d has invalid table-name length %d", page.Number, slot, nameLen)
	}
	columnCount := int(entry[catalogColumnCountOff])
	if columnCount < 1 || columnCount > MaxColumns {
		return nil, fmt.Errorf("catalog page %d slot %d has invalid column count %d", page.Number, slot, columnCount)
	}
	name := string(entry[catalogNameOffset : catalogNameOffset+nameLen])
	columns := make([]Column, 0, columnCount)
	for i := 0; i < columnCount; i++ {
		off := catalogColumnsOffset + i*catalogColumnSize
		col := entry[off : off+catalogColumnSize]
		colNameLen := int(col[catalogColNameLenOffset])
		if colNameLen < 1 || colNameLen > MaxColumnNameLen {
			return nil, fmt.Errorf("catalog table %s column %d has invalid name length %d", name, i, colNameLen)
		}
		c := Column{
			Name:     string(col[catalogColNameOffset : catalogColNameOffset+colNameLen]),
			Type:     ColumnType(col[catalogColTypeOffset]),
			Nullable: col[catalogColNullableOff] != 0,
			MaxLen:   binary.LittleEndian.Uint16(col[catalogColMaxLenOffset : catalogColMaxLenOffset+2]),
			Offset:   binary.LittleEndian.Uint16(col[catalogColRowOffOffset : catalogColRowOffOffset+2]),
			Width:    binary.LittleEndian.Uint16(col[catalogColWidthOffset : catalogColWidthOffset+2]),
		}
		if _, err := columnWidth(c); err != nil {
			return nil, fmt.Errorf("catalog table %s column %s: %w", name, c.Name, err)
		}
		columns = append(columns, c)
	}
	schema := Schema{Columns: columns, RowSize: binary.LittleEndian.Uint32(entry[catalogRowSizeOffset : catalogRowSizeOffset+4])}
	compiled, err := CompileSchema(columns)
	if err != nil {
		return nil, fmt.Errorf("catalog table %s schema invalid: %w", name, err)
	}
	if compiled.RowSize != schema.RowSize {
		return nil, fmt.Errorf("catalog table %s row size %d does not match compiled size %d", name, schema.RowSize, compiled.RowSize)
	}
	for i := range compiled.Columns {
		if compiled.Columns[i].Offset != schema.Columns[i].Offset || compiled.Columns[i].Width != schema.Columns[i].Width {
			return nil, fmt.Errorf("catalog table %s column %s layout mismatch", name, schema.Columns[i].Name)
		}
	}
	t := &Table{
		ID:        binary.LittleEndian.Uint64(entry[catalogTableIDOffset : catalogTableIDOffset+8]),
		Name:      name,
		Schema:    schema,
		firstData: binary.LittleEndian.Uint64(entry[catalogFirstDataOffset : catalogFirstDataOffset+8]),
		lastData:  binary.LittleEndian.Uint64(entry[catalogLastDataOffset : catalogLastDataOffset+8]),
		nextRowID: int64(binary.LittleEndian.Uint64(entry[catalogNextRowIDOffset : catalogNextRowIDOffset+8])),
		catalog:   CatalogPointer{Page: page.Number, Slot: uint16(slot)},
	}
	root := binary.LittleEndian.Uint64(entry[catalogRootPageOffset : catalogRootPageOffset+8])
	if t.ID == 0 || root == 0 || t.nextRowID < 1 {
		return nil, fmt.Errorf("catalog table %s has invalid id/root/next-rowid", name)
	}
	if (t.firstData == 0) != (t.lastData == 0) {
		return nil, fmt.Errorf("catalog table %s data chain metadata disagrees", name)
	}
	t.tree = newBTree(nil, root) // pager is attached by Store after catalog loading.
	return t, nil
}

package main

import (
	"encoding/binary"
	"fmt"
	"strings"
)

// BTreeMaxKeys is intentionally tiny so a learner can trigger splits with a
// handful of INSERTs. A production page would use far more of its 4096 bytes.
const BTreeMaxKeys = 7

const (
	nodeKeyCountOffset = PageHeaderSize
	nodeSpecialOffset  = 40 // leaf: next leaf; internal: first child
	nodeEntriesOffset  = 48
	leafEntrySize      = 24
	internalEntrySize  = 16
)

type RecordPointer struct {
	Page uint64
	Slot uint16
}

type leafEntry struct {
	Key int64
	Ptr RecordPointer
}

type internalEntry struct {
	Key        int64
	RightChild uint64
}

type splitResult struct {
	Separator int64
	RightPage uint64
}

type BTree struct {
	pager *Pager
	root  uint64
}

func newBTree(pager *Pager, root uint64) *BTree { return &BTree{pager: pager, root: root} }
func (t *BTree) RootPage() uint64               { return t.root }

func keyCount(page *Page) int {
	return int(binary.LittleEndian.Uint16(page.Data[nodeKeyCountOffset : nodeKeyCountOffset+2]))
}

func setKeyCount(page *Page, n int) {
	binary.LittleEndian.PutUint16(page.Data[nodeKeyCountOffset:nodeKeyCountOffset+2], uint16(n))
	page.MarkDirty()
}

func leafNext(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[nodeSpecialOffset : nodeSpecialOffset+8])
}
func setLeafNext(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[nodeSpecialOffset:nodeSpecialOffset+8], n)
	page.MarkDirty()
}
func internalFirstChild(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[nodeSpecialOffset : nodeSpecialOffset+8])
}
func setInternalFirstChild(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[nodeSpecialOffset:nodeSpecialOffset+8], n)
	page.MarkDirty()
}

func readLeafEntries(page *Page) []leafEntry {
	n := keyCount(page)
	out := make([]leafEntry, 0, n)
	for i := 0; i < n; i++ {
		off := nodeEntriesOffset + i*leafEntrySize
		out = append(out, leafEntry{
			Key: int64(binary.LittleEndian.Uint64(page.Data[off : off+8])),
			Ptr: RecordPointer{Page: binary.LittleEndian.Uint64(page.Data[off+8 : off+16]), Slot: binary.LittleEndian.Uint16(page.Data[off+16 : off+18])},
		})
	}
	return out
}

func writeLeafEntries(page *Page, entries []leafEntry) error {
	if len(entries) > BTreeMaxKeys {
		return fmt.Errorf("leaf page %d overflow: %d keys", page.Number, len(entries))
	}
	clear(page.Data[nodeEntriesOffset:])
	for i, e := range entries {
		off := nodeEntriesOffset + i*leafEntrySize
		binary.LittleEndian.PutUint64(page.Data[off:off+8], uint64(e.Key))
		binary.LittleEndian.PutUint64(page.Data[off+8:off+16], e.Ptr.Page)
		binary.LittleEndian.PutUint16(page.Data[off+16:off+18], e.Ptr.Slot)
	}
	setKeyCount(page, len(entries))
	page.MarkDirty()
	return nil
}

func readInternal(page *Page) ([]int64, []uint64) {
	n := keyCount(page)
	keys := make([]int64, 0, n)
	children := make([]uint64, 0, n+1)
	children = append(children, internalFirstChild(page))
	for i := 0; i < n; i++ {
		off := nodeEntriesOffset + i*internalEntrySize
		keys = append(keys, int64(binary.LittleEndian.Uint64(page.Data[off:off+8])))
		children = append(children, binary.LittleEndian.Uint64(page.Data[off+8:off+16]))
	}
	return keys, children
}

func writeInternal(page *Page, keys []int64, children []uint64) error {
	if len(keys) > BTreeMaxKeys {
		return fmt.Errorf("internal page %d overflow: %d keys", page.Number, len(keys))
	}
	if len(children) != len(keys)+1 {
		return fmt.Errorf("internal page %d: %d keys need %d children, got %d", page.Number, len(keys), len(keys)+1, len(children))
	}
	clear(page.Data[nodeEntriesOffset:])
	setInternalFirstChild(page, children[0])
	for i, key := range keys {
		off := nodeEntriesOffset + i*internalEntrySize
		binary.LittleEndian.PutUint64(page.Data[off:off+8], uint64(key))
		binary.LittleEndian.PutUint64(page.Data[off+8:off+16], children[i+1])
	}
	setKeyCount(page, len(keys))
	page.MarkDirty()
	return nil
}

func (t *BTree) Lookup(key int64) (RecordPointer, int, error) {
	pageNum := t.root
	visits := 0
	for {
		page, err := t.pager.GetPage(pageNum)
		if err != nil {
			return RecordPointer{}, visits, err
		}
		visits++
		switch page.Type {
		case PageTypeBTreeLeaf:
			entries := readLeafEntries(page)
			lo, hi := 0, len(entries)
			for lo < hi {
				mid := lo + (hi-lo)/2
				if entries[mid].Key < key {
					lo = mid + 1
				} else {
					hi = mid
				}
			}
			if lo < len(entries) && entries[lo].Key == key {
				return entries[lo].Ptr, visits, nil
			}
			return RecordPointer{}, visits, ErrNotFound
		case PageTypeBTreeInternal:
			keys, children := readInternal(page)
			childIndex := 0
			for childIndex < len(keys) && key >= keys[childIndex] {
				childIndex++
			}
			pageNum = children[childIndex]
		default:
			return RecordPointer{}, visits, fmt.Errorf("btree: page %d has type %s", page.Number, page.Type)
		}
	}
}

func (t *BTree) Insert(key int64, ptr RecordPointer) error {
	if _, _, err := t.Lookup(key); err == nil {
		return fmt.Errorf("duplicate index key %d", key)
	} else if err != ErrNotFound {
		return err
	}
	split, err := t.insertRecursive(t.root, key, ptr)
	if err != nil {
		return err
	}
	if split == nil {
		return nil
	}
	oldRoot := t.root
	newRoot, err := t.pager.NewPage(PageTypeBTreeInternal)
	if err != nil {
		return err
	}
	if err := writeInternal(newRoot, []int64{split.Separator}, []uint64{oldRoot, split.RightPage}); err != nil {
		return err
	}
	t.root = newRoot.Number
	return nil
}

func (t *BTree) insertRecursive(pageNum uint64, key int64, ptr RecordPointer) (*splitResult, error) {
	page, err := t.pager.GetPage(pageNum)
	if err != nil {
		return nil, err
	}
	switch page.Type {
	case PageTypeBTreeLeaf:
		return t.insertLeaf(page, key, ptr)
	case PageTypeBTreeInternal:
		keys, children := readInternal(page)
		childIndex := 0
		for childIndex < len(keys) && key >= keys[childIndex] {
			childIndex++
		}
		childSplit, err := t.insertRecursive(children[childIndex], key, ptr)
		if err != nil || childSplit == nil {
			return childSplit, err
		}

		keys = append(keys, 0)
		copy(keys[childIndex+1:], keys[childIndex:])
		keys[childIndex] = childSplit.Separator
		children = append(children, 0)
		copy(children[childIndex+2:], children[childIndex+1:])
		children[childIndex+1] = childSplit.RightPage

		if len(keys) <= BTreeMaxKeys {
			return nil, writeInternal(page, keys, children)
		}

		mid := len(keys) / 2
		promoted := keys[mid]
		leftKeys := append([]int64(nil), keys[:mid]...)
		leftChildren := append([]uint64(nil), children[:mid+1]...)
		rightKeys := append([]int64(nil), keys[mid+1:]...)
		rightChildren := append([]uint64(nil), children[mid+1:]...)

		if err := writeInternal(page, leftKeys, leftChildren); err != nil {
			return nil, err
		}
		right, err := t.pager.NewPage(PageTypeBTreeInternal)
		if err != nil {
			return nil, err
		}
		if err := writeInternal(right, rightKeys, rightChildren); err != nil {
			return nil, err
		}
		return &splitResult{Separator: promoted, RightPage: right.Number}, nil
	default:
		return nil, fmt.Errorf("btree insert: page %d has type %s", page.Number, page.Type)
	}
}

func (t *BTree) insertLeaf(page *Page, key int64, ptr RecordPointer) (*splitResult, error) {
	entries := readLeafEntries(page)
	pos := 0
	for pos < len(entries) && entries[pos].Key < key {
		pos++
	}
	if pos < len(entries) && entries[pos].Key == key {
		return nil, fmt.Errorf("duplicate index key %d", key)
	}
	entries = append(entries, leafEntry{})
	copy(entries[pos+1:], entries[pos:])
	entries[pos] = leafEntry{Key: key, Ptr: ptr}
	if len(entries) <= BTreeMaxKeys {
		return nil, writeLeafEntries(page, entries)
	}

	mid := len(entries) / 2
	leftEntries := append([]leafEntry(nil), entries[:mid]...)
	rightEntries := append([]leafEntry(nil), entries[mid:]...)
	oldNext := leafNext(page)
	right, err := t.pager.NewPage(PageTypeBTreeLeaf)
	if err != nil {
		return nil, err
	}
	if err := writeLeafEntries(page, leftEntries); err != nil {
		return nil, err
	}
	if err := writeLeafEntries(right, rightEntries); err != nil {
		return nil, err
	}
	setLeafNext(right, oldNext)
	setLeafNext(page, right.Number)
	return &splitResult{Separator: rightEntries[0].Key, RightPage: right.Number}, nil
}

func (t *BTree) leftmostLeaf() (uint64, error) {
	pageNum := t.root
	for {
		page, err := t.pager.GetPage(pageNum)
		if err != nil {
			return 0, err
		}
		if page.Type == PageTypeBTreeLeaf {
			return pageNum, nil
		}
		if page.Type != PageTypeBTreeInternal {
			return 0, fmt.Errorf("btree: page %d has type %s", page.Number, page.Type)
		}
		pageNum = internalFirstChild(page)
	}
}

func (t *BTree) AllPointers() ([]RecordPointer, error) {
	pageNum, err := t.leftmostLeaf()
	if err != nil {
		return nil, err
	}
	var out []RecordPointer
	for pageNum != 0 {
		page, err := t.pager.GetPage(pageNum)
		if err != nil {
			return nil, err
		}
		if page.Type != PageTypeBTreeLeaf {
			return nil, fmt.Errorf("btree scan: page %d is %s", pageNum, page.Type)
		}
		for _, e := range readLeafEntries(page) {
			out = append(out, e.Ptr)
		}
		pageNum = leafNext(page)
	}
	return out, nil
}

func (t *BTree) Dump() (string, error) {
	var b strings.Builder
	if err := t.dumpPage(&b, t.root, 0); err != nil {
		return "", err
	}
	return b.String(), nil
}

func (t *BTree) dumpPage(b *strings.Builder, pageNum uint64, depth int) error {
	page, err := t.pager.GetPage(pageNum)
	if err != nil {
		return err
	}
	indent := strings.Repeat("  ", depth)
	switch page.Type {
	case PageTypeBTreeLeaf:
		entries := readLeafEntries(page)
		fmt.Fprintf(b, "%sleaf page=%d keys=[", indent, pageNum)
		for i, e := range entries {
			if i > 0 {
				b.WriteString(" ")
			}
			fmt.Fprintf(b, "%d", e.Key)
		}
		fmt.Fprintf(b, "] next=%d\n", leafNext(page))
	case PageTypeBTreeInternal:
		keys, children := readInternal(page)
		fmt.Fprintf(b, "%sinternal page=%d keys=%v children=%v\n", indent, pageNum, keys, children)
		for _, child := range children {
			if err := t.dumpPage(b, child, depth+1); err != nil {
				return err
			}
		}
	default:
		return fmt.Errorf("tree dump: page %d has type %s", pageNum, page.Type)
	}
	return nil
}

	metaVersionOffset        = metaMagicOffset + 8
	metaPageSizeOffset       = metaVersionOffset + 4
	metaPageHeaderSizeOffset = metaPageSizeOffset + 4
	metaChecksumAlgOffset    = metaPageHeaderSizeOffset + 4
	metaFirstCatalogOffset   = 64
	metaLastCatalogOffset    = 72
	metaNextTableIDOffset    = 80
	metaTableCountOffset     = 88

	dataTableIDOffset   = PageHeaderSize
	dataSlotCountOffset = 40
	dataRowSizeOffset   = 44
	dataNextPageOffset  = 48
	dataRowsOffset      = 64
)

var (
	ErrNotFound = errors.New("record not found")
	ErrDeleted  = errors.New("record deleted")
)

type Store struct {
	pager            *Pager
	tables           map[string]*Table
	firstCatalogPage uint64
	lastCatalogPage  uint64
	nextTableID      uint64
	tableCount       uint64
}

func writeDatabaseMetadata(page *Page, firstCatalog, lastCatalog, nextTableID, tableCount uint64) {
	clear(page.Data[PageHeaderSize:])
	copy(page.Data[metaMagicOffset:metaMagicOffset+8], []byte(DatabaseMagic))
	binary.LittleEndian.PutUint32(page.Data[metaVersionOffset:metaVersionOffset+4], DatabaseVersion)
	binary.LittleEndian.PutUint32(page.Data[metaPageSizeOffset:metaPageSizeOffset+4], PageSize)
	binary.LittleEndian.PutUint32(page.Data[metaPageHeaderSizeOffset:metaPageHeaderSizeOffset+4], PageHeaderSize)
	binary.LittleEndian.PutUint32(page.Data[metaChecksumAlgOffset:metaChecksumAlgOffset+4], ChecksumAlgorithm)
	binary.LittleEndian.PutUint64(page.Data[metaFirstCatalogOffset:metaFirstCatalogOffset+8], firstCatalog)
	binary.LittleEndian.PutUint64(page.Data[metaLastCatalogOffset:metaLastCatalogOffset+8], lastCatalog)
	binary.LittleEndian.PutUint64(page.Data[metaNextTableIDOffset:metaNextTableIDOffset+8], nextTableID)
	binary.LittleEndian.PutUint64(page.Data[metaTableCountOffset:metaTableCountOffset+8], tableCount)
	page.MarkDirty()
}

func readDatabaseMetadata(page *Page) (firstCatalog, lastCatalog, nextTableID, tableCount uint64, err error) {
	if page.Type != PageTypeMetadata {
		err = fmt.Errorf("page 0 is %s, expected metadata", page.Type)
		return
	}
	if string(page.Data[metaMagicOffset:metaMagicOffset+8]) != DatabaseMagic {
		err = fmt.Errorf("not a compatible MiniDB file: bad database magic")
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaVersionOffset : metaVersionOffset+4]); got != DatabaseVersion {
		err = fmt.Errorf("unsupported database version %d", got)
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaPageSizeOffset : metaPageSizeOffset+4]); got != PageSize {
		err = fmt.Errorf("file page size is %d, program expects %d", got, PageSize)
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaPageHeaderSizeOffset : metaPageHeaderSizeOffset+4]); got != PageHeaderSize {
		err = fmt.Errorf("file page-header size is %d, program expects %d", got, PageHeaderSize)
		return
	}
	if got := binary.LittleEndian.Uint32(page.Data[metaChecksumAlgOffset : metaChecksumAlgOffset+4]); got != ChecksumAlgorithm {
		err = fmt.Errorf("unsupported checksum algorithm %d", got)
		return
	}
	firstCatalog = binary.LittleEndian.Uint64(page.Data[metaFirstCatalogOffset : metaFirstCatalogOffset+8])
	lastCatalog = binary.LittleEndian.Uint64(page.Data[metaLastCatalogOffset : metaLastCatalogOffset+8])
	nextTableID = binary.LittleEndian.Uint64(page.Data[metaNextTableIDOffset : metaNextTableIDOffset+8])
	tableCount = binary.LittleEndian.Uint64(page.Data[metaTableCountOffset : metaTableCountOffset+8])
	if firstCatalog == 0 || lastCatalog == 0 || nextTableID == 0 {
		err = fmt.Errorf("invalid catalog metadata: first=%d last=%d nextTableID=%d", firstCatalog, lastCatalog, nextTableID)
	}
	return
}

func initializeCatalogPage(page *Page) error {
	if page.Type != PageTypeCatalog {
		return fmt.Errorf("page %d is %s, expected catalog", page.Number, page.Type)
	}
	setCatalogSlotCount(page, 0)
	setCatalogNextPage(page, 0)
	return nil
}

func Open(path string) (*Store, error) {
	pager, err := OpenPager(path)
	if err != nil {
		return nil, err
	}
	s := &Store{pager: pager, tables: make(map[string]*Table)}

	if pager.numPages == 0 {
		meta, err := pager.NewPage(PageTypeMetadata)
		if err != nil {
			pager.Close()
			return nil, err
		}
		if meta.Number != HeaderPage {
			pager.Close()
			return nil, fmt.Errorf("new metadata page is %d, expected 0", meta.Number)
		}
		catalog, err := pager.NewPage(PageTypeCatalog)
		if err != nil {
			pager.Close()
			return nil, err
		}
		if err := initializeCatalogPage(catalog); err != nil {
			pager.Close()
			return nil, err
		}
		s.firstCatalogPage = catalog.Number
		s.lastCatalogPage = catalog.Number
		s.nextTableID = 1
		s.tableCount = 0
		writeDatabaseMetadata(meta, s.firstCatalogPage, s.lastCatalogPage, s.nextTableID, s.tableCount)
		if err := pager.FlushAll(); err != nil {
			pager.Close()
			return nil, err
		}
		return s, nil
	}

	meta, err := pager.GetPage(HeaderPage)
	if err != nil {
		pager.Close()
		return nil, err
	}
	first, last, nextID, count, err := readDatabaseMetadata(meta)
	if err != nil {
		pager.Close()
		return nil, err
	}
	s.firstCatalogPage, s.lastCatalogPage, s.nextTableID, s.tableCount = first, last, nextID, count
	if err := s.loadCatalog(); err != nil {
		pager.Close()
		return nil, err
	}
	if uint64(len(s.tables)) != s.tableCount {
		pager.Close()
		return nil, fmt.Errorf("catalog says %d tables but loaded %d", s.tableCount, len(s.tables))
	}
	return s, nil
}

func (s *Store) loadCatalog() error {
	seenPages := map[uint64]bool{}
	loadedIDs := map[uint64]bool{}
	pageNum := s.firstCatalogPage
	var lastSeen uint64
	for pageNum != 0 {
		if seenPages[pageNum] {
			return fmt.Errorf("catalog page cycle at %d", pageNum)
		}
		seenPages[pageNum] = true
		page, err := s.pager.GetPage(pageNum)
		if err != nil {
			return err
		}
		if page.Type != PageTypeCatalog {
			return fmt.Errorf("catalog chain page %d is %s", pageNum, page.Type)
		}
		n := catalogSlotCount(page)
		if n < 0 || n > CatalogSlotsPerPage {
			return fmt.Errorf("catalog page %d has invalid slot count %d", pageNum, n)
		}
		for slot := 0; slot < n; slot++ {
			t, err := readCatalogEntry(page, slot)
			if err != nil {
				return err
			}
			if t == nil {
				return fmt.Errorf("catalog page %d slot %d is unexpectedly empty", pageNum, slot)
			}
			key := normalizeTableName(t.Name)
			if _, exists := s.tables[key]; exists {
				return fmt.Errorf("duplicate table name %q in catalog", t.Name)
			}
			if loadedIDs[t.ID] {
				return fmt.Errorf("duplicate table id %d in catalog", t.ID)
			}
			loadedIDs[t.ID] = true
			t.tree.pager = s.pager
			s.tables[key] = t
		}
		lastSeen = pageNum
		pageNum = catalogNextPage(page)
	}
	if lastSeen != s.lastCatalogPage {
		return fmt.Errorf("catalog last-page metadata says %d but chain ends at %d", s.lastCatalogPage, lastSeen)
	}
	return nil
}

func (s *Store) persistMetadata() error {
	page, err := s.pager.GetPage(HeaderPage)
	if err != nil {
		return err
	}
	writeDatabaseMetadata(page, s.firstCatalogPage, s.lastCatalogPage, s.nextTableID, s.tableCount)
	return nil
}

func (s *Store) persistTable(t *Table) error {
	page, err := s.pager.GetPage(t.catalog.Page)
	if err != nil {
		return err
	}
	return writeCatalogEntry(page, int(t.catalog.Slot), t)
}

func validIdentifier(name string) bool {
	if name == "" {
		return false
	}
	for i, r := range name {
		if !(r == '_' || r >= 'a' && r <= 'z' || r >= 'A' && r <= 'Z' || i > 0 && r >= '0' && r <= '9') {
			return false
		}
	}
	return true
}

func (s *Store) CreateTable(name string, columns []Column) (*Table, error) {
	if !validIdentifier(name) || len([]byte(name)) > MaxTableNameLen {
		return nil, fmt.Errorf("table name must be a simple identifier of at most %d bytes", MaxTableNameLen)
	}
	key := normalizeTableName(name)
	if _, exists := s.tables[key]; exists {
		return nil, fmt.Errorf("table %q already exists", name)
	}
	schema, err := CompileSchema(columns)
	if err != nil {
		return nil, err
	}
	root, err := s.pager.NewPage(PageTypeBTreeLeaf)
	if err != nil {
		return nil, err
	}
	t := &Table{
		ID:        s.nextTableID,
		Name:      name,
		Schema:    schema,
		tree:      newBTree(s.pager, root.Number),
		nextRowID: 1,
	}

	catalogPage, err := s.pager.GetPage(s.lastCatalogPage)
	if err != nil {
		return nil, err
	}
	slot := catalogSlotCount(catalogPage)
	if slot >= CatalogSlotsPerPage {
		newPage, err := s.pager.NewPage(PageTypeCatalog)
		if err != nil {
			return nil, err
		}
		if err := initializeCatalogPage(newPage); err != nil {
			return nil, err
		}
		setCatalogNextPage(catalogPage, newPage.Number)
		s.lastCatalogPage = newPage.Number
		catalogPage = newPage
		slot = 0
	}
	t.catalog = CatalogPointer{Page: catalogPage.Number, Slot: uint16(slot)}
	if err := writeCatalogEntry(catalogPage, slot, t); err != nil {
		return nil, err
	}
	setCatalogSlotCount(catalogPage, slot+1)

	s.tables[key] = t
	s.nextTableID++
	s.tableCount++
	if err := s.persistMetadata(); err != nil {
		return nil, err
	}
	return t, nil
}

func (s *Store) Table(name string) (*Table, error) {
	t, ok := s.tables[normalizeTableName(name)]
	if !ok {
		return nil, fmt.Errorf("table %q not found", name)
	}
	return t, nil
}

func (s *Store) Tables() []*Table {
	out := make([]*Table, 0, len(s.tables))
	for _, t := range s.tables {
		out = append(out, t)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].ID < out[j].ID })
	return out
}

func dataTableID(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[dataTableIDOffset : dataTableIDOffset+8])
}
func dataSlotCount(page *Page) int {
	return int(binary.LittleEndian.Uint16(page.Data[dataSlotCountOffset : dataSlotCountOffset+2]))
}
func setDataSlotCount(page *Page, n int) {
	binary.LittleEndian.PutUint16(page.Data[dataSlotCountOffset:dataSlotCountOffset+2], uint16(n))
	page.MarkDirty()
}
func dataRowSize(page *Page) uint32 {
	return binary.LittleEndian.Uint32(page.Data[dataRowSizeOffset : dataRowSizeOffset+4])
}
func dataNextPage(page *Page) uint64 {
	return binary.LittleEndian.Uint64(page.Data[dataNextPageOffset : dataNextPageOffset+8])
}
func setDataNextPage(page *Page, n uint64) {
	binary.LittleEndian.PutUint64(page.Data[dataNextPageOffset:dataNextPageOffset+8], n)
	page.MarkDirty()
}
func dataCapacity(rowSize uint32) int {
	if rowSize == 0 {
		return 0
	}
	return (PageSize - dataRowsOffset) / int(rowSize)
}

func initializeDataPage(page *Page, t *Table) error {
	if page.Type != PageTypeData {
		return fmt.Errorf("page %d is %s, expected data", page.Number, page.Type)
	}
	binary.LittleEndian.PutUint64(page.Data[dataTableIDOffset:dataTableIDOffset+8], t.ID)
	binary.LittleEndian.PutUint32(page.Data[dataRowSizeOffset:dataRowSizeOffset+4], t.Schema.RowSize)
	setDataSlotCount(page, 0)
	setDataNextPage(page, 0)
	page.MarkDirty()
	return nil
}

func validateDataPage(page *Page, t *Table) error {
	if page.Type != PageTypeData {
		return fmt.Errorf("page %d is %s, expected data", page.Number, page.Type)
	}
	if got := dataTableID(page); got != t.ID {
		return fmt.Errorf("data page %d belongs to table id %d, expected %d", page.Number, got, t.ID)
	}
	if got := dataRowSize(page); got != t.Schema.RowSize {
		return fmt.Errorf("data page %d row size is %d, table %s expects %d", page.Number, got, t.Name, t.Schema.RowSize)
	}
	count := dataSlotCount(page)
	if count < 0 || count > dataCapacity(t.Schema.RowSize) {
		return fmt.Errorf("data page %d has invalid slot count %d", page.Number, count)
	}
	return nil
}

func (s *Store) allocateDataPage(t *Table) (*Page, error) {
	page, err := s.pager.NewPage(PageTypeData)
	if err != nil {
		return nil, err
	}
	if err := initializeDataPage(page, t); err != nil {
		return nil, err
	}
	if t.lastData != 0 {
		last, err := s.pager.GetPage(t.lastData)
		if err != nil {
			return nil, err
		}
		if err := validateDataPage(last, t); err != nil {
			return nil, err
		}
		setDataNextPage(last, page.Number)
	} else {
		t.firstData = page.Number
	}
	t.lastData = page.Number
	return page, nil
}

func rowRange(t *Table, slot int) (int, int, error) {
	cap := dataCapacity(t.Schema.RowSize)
	if slot < 0 || slot >= cap {
		return 0, 0, fmt.Errorf("slot %d out of range for table %s", slot, t.Name)
	}
	start := dataRowsOffset + slot*int(t.Schema.RowSize)
	return start, start + int(t.Schema.RowSize), nil
}

func (s *Store) appendRow(t *Table, encoded []byte) (RecordPointer, error) {
	if len(encoded) != int(t.Schema.RowSize) {
		return RecordPointer{}, fmt.Errorf("encoded row has %d bytes, expected %d", len(encoded), t.Schema.RowSize)
	}
	var page *Page
	var err error
	if t.lastData == 0 {
		page, err = s.allocateDataPage(t)
		if err != nil {
			return RecordPointer{}, err
		}
	} else {
		page, err = s.pager.GetPage(t.lastData)
		if err != nil {
			return RecordPointer{}, err
		}
		if err := validateDataPage(page, t); err != nil {
			return RecordPointer{}, err
		}
		if dataSlotCount(page) >= dataCapacity(t.Schema.RowSize) {
			page, err = s.allocateDataPage(t)
			if err != nil {
				return RecordPointer{}, err
			}
		}
	}
	slot := dataSlotCount(page)
	start, end, err := rowRange(t, slot)
	if err != nil {
		return RecordPointer{}, err
	}
	copy(page.Data[start:end], encoded)
	setDataSlotCount(page, slot+1)
	page.MarkDirty()
	return RecordPointer{Page: page.Number, Slot: uint16(slot)}, nil
}

func (s *Store) readRowAt(t *Table, ptr RecordPointer) (Row, *Page, int, error) {
	page, err := s.pager.GetPage(ptr.Page)
	if err != nil {
		return Row{}, nil, 0, err
	}
	if err := validateDataPage(page, t); err != nil {
		return Row{}, nil, 0, err
	}
	if int(ptr.Slot) >= dataSlotCount(page) {
		return Row{}, nil, 0, fmt.Errorf("pointer %d:%d is past used slots", ptr.Page, ptr.Slot)
	}
	start, end, err := rowRange(t, int(ptr.Slot))
	if err != nil {
		return Row{}, nil, 0, err
	}
	row, err := DecodeRow(t.Schema, page.Data[start:end])
	return row, page, start, err
}

func (s *Store) Insert(tableName string, values []Value) (int64, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return 0, err
	}
	rowID := t.nextRowID
	encoded, err := EncodeRow(t.Schema, rowID, values)
	if err != nil {
		return 0, err
	}
	ptr, err := s.appendRow(t, encoded)
	if err != nil {
		return 0, err
	}
	if err := t.tree.Insert(rowID, ptr); err != nil {
		return 0, err
	}
	t.nextRowID++
	if err := s.persistTable(t); err != nil {
		return 0, err
	}
	return rowID, nil
}

func (s *Store) Get(tableName string, rowID int64) (Row, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return Row{}, err
	}
	ptr, _, err := t.tree.Lookup(rowID)
	if err != nil {
		return Row{}, err
	}
	row, _, _, err := s.readRowAt(t, ptr)
	if err != nil {
		return Row{}, err
	}
	if row.RowID != rowID {
		return Row{}, fmt.Errorf("index key %d points to rowid %d", rowID, row.RowID)
	}
	if row.Deleted {
		return Row{}, ErrDeleted
	}
	return row, nil
}

func (s *Store) GetWithSteps(tableName string, rowID int64) (Row, int, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return Row{}, 0, err
	}
	ptr, steps, err := t.tree.Lookup(rowID)
	if err != nil {
		return Row{}, steps, err
	}
	row, _, _, err := s.readRowAt(t, ptr)
	if err != nil {
		return Row{}, steps, err
	}
	if row.RowID != rowID {
		return Row{}, steps, fmt.Errorf("index key %d points to rowid %d", rowID, row.RowID)
	}
	if row.Deleted {
		return Row{}, steps, ErrDeleted
	}
	return row, steps, nil
}

func (s *Store) Scan(tableName string) ([]Row, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return nil, err
	}
	ptrs, err := t.tree.AllPointers()
	if err != nil {
		return nil, err
	}
	rows := make([]Row, 0, len(ptrs))
	for _, ptr := range ptrs {
		row, _, _, err := s.readRowAt(t, ptr)
		if err != nil {
			return nil, err
		}
		if row.Deleted {
			continue
		}
		rows = append(rows, row)
	}
	return rows, nil
}

func (s *Store) Delete(tableName string, rowID int64) error {
	t, err := s.Table(tableName)
	if err != nil {
		return err
	}
	ptr, _, err := t.tree.Lookup(rowID)
	if err != nil {
		return err
	}
	row, page, start, err := s.readRowAt(t, ptr)
	if err != nil {
		return err
	}
	if row.Deleted {
		return ErrDeleted
	}
	page.Data[start] |= 1
	page.MarkDirty()
	return nil
}

func (s *Store) TreeDump(tableName string) (string, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return "", err
	}
	return t.tree.Dump()
}

func (s *Store) DataChain(tableName string) ([]uint64, error) {
	t, err := s.Table(tableName)
	if err != nil {
		return nil, err
	}
	var out []uint64
	seen := map[uint64]bool{}
	for p := t.firstData; p != 0; {
		if seen[p] {
			return nil, fmt.Errorf("data-page cycle at %d", p)
		}
		seen[p] = true
		page, err := s.pager.GetPage(p)
		if err != nil {
			return nil, err
		}
		if err := validateDataPage(page, t); err != nil {
			return nil, err
		}
		out = append(out, p)
		p = dataNextPage(page)
	}
	if len(out) == 0 && t.lastData != 0 {
		return nil, fmt.Errorf("table %s has last data page but empty chain", t.Name)
	}
	if len(out) > 0 && out[len(out)-1] != t.lastData {
		return nil, fmt.Errorf("table %s last data metadata says %d but chain ends at %d", t.Name, t.lastData, out[len(out)-1])
	}
	return out, nil
}

func (s *Store) CatalogPages() ([]uint64, error) {
	var out []uint64
	seen := map[uint64]bool{}
	for p := s.firstCatalogPage; p != 0; {
		if seen[p] {
			return nil, fmt.Errorf("catalog cycle at %d", p)
		}
		seen[p] = true
		page, err := s.pager.GetPage(p)
		if err != nil {
			return nil, err
		}
		if page.Type != PageTypeCatalog {
			return nil, fmt.Errorf("catalog chain page %d is %s", p, page.Type)
		}
		out = append(out, p)
		p = catalogNextPage(page)
	}
	return out, nil
}

	return s.pager.VerifyAll()
}

func describeColumn(c Column) string {
	typ := c.Type.String()
	if c.Type == TypeText {
		typ = fmt.Sprintf("TEXT(%d)", c.MaxLen)
	}
	nullability := "NOT NULL"
	if c.Nullable {
		nullability = "NULL"
	}
	return fmt.Sprintf("%s %s %s offset=%d width=%d", c.Name, typ, nullability, c.Offset, c.Width)
}

func (s *Store) DescribeTable(name string) (string, error) {
	t, err := s.Table(name)
	if err != nil {
		return "", err
	}
	var b strings.Builder
	fmt.Fprintf(&b, "table=%s id=%d row_size=%d rows_per_page=%d root_page=%d next_rowid=%d\n", t.Name, t.ID, t.Schema.RowSize, dataCapacity(t.Schema.RowSize), t.tree.RootPage(), t.nextRowID)
	b.WriteString("rowid INT (implicit key)\n")
	for i, c := range t.Schema.Columns {
		fmt.Fprintf(&b, "%d %s\n", i, describeColumn(c))
	}
	return b.String(), nil
}

func (k TokenKind) String() string {
	names := map[TokenKind]string{
		TokenEOF: "EOF", TokenIdentifier: "IDENT", TokenNumber: "NUMBER", TokenString: "STRING",
		TokenComma: "COMMA", TokenLParen: "LPAREN", TokenRParen: "RPAREN", TokenSemicolon: "SEMICOLON",
		TokenStar: "STAR", TokenEqual: "EQUAL", TokenCreate: "CREATE", TokenTable: "TABLE",
		TokenInsert: "INSERT", TokenInto: "INTO", TokenValues: "VALUES", TokenSelect: "SELECT",
		TokenFrom: "FROM", TokenWhere: "WHERE", TokenDelete: "DELETE", TokenInt: "INT",
		TokenBool: "BOOL", TokenText: "TEXT", TokenNull: "NULL", TokenNot: "NOT",
		TokenTrue: "TRUE", TokenFalse: "FALSE", TokenBegin: "BEGIN", TokenCommit: "COMMIT",
		TokenRollback: "ROLLBACK", TokenTransaction: "TRANSACTION",
	}

		return s

	Pos    int
}

var keywords = map[string]TokenKind{
	"CREATE": TokenCreate, "TABLE": TokenTable, "INSERT": TokenInsert, "INTO": TokenInto,
	"VALUES": TokenValues, "SELECT": TokenSelect, "FROM": TokenFrom, "WHERE": TokenWhere,
	"DELETE": TokenDelete, "INT": TokenInt, "INTEGER": TokenInt, "BOOL": TokenBool,
	"BOOLEAN": TokenBool, "TEXT": TokenText, "NULL": TokenNull, "NOT": TokenNot,
	"TRUE": TokenTrue, "FALSE": TokenFalse, "BEGIN": TokenBegin, "COMMIT": TokenCommit,
	"ROLLBACK": TokenRollback, "TRANSACTION": TokenTransaction,
}

type Lexer struct {
	input string
	pos   int
}

func Lex(input string) ([]Token, error) {
	l := &Lexer{input: input}
	var tokens []Token
	for {
		tok, err := l.nextToken()
		if err != nil {
			return nil, err
		}
		tokens = append(tokens, tok)
		if tok.Kind == TokenEOF {
			return tokens, nil
		}
	}
}

func (l *Lexer) nextToken() (Token, error) {
	for l.pos < len(l.input) && isSpace(l.input[l.pos]) {
		l.pos++
	}
	if l.pos >= len(l.input) {
		return Token{Kind: TokenEOF, Pos: l.pos}, nil
	}

	start := l.pos
	ch := l.input[l.pos]
	switch ch {
	case ',':
		l.pos++
		return Token{Kind: TokenComma, Lexeme: ",", Pos: start}, nil
	case '(':
		l.pos++
		return Token{Kind: TokenLParen, Lexeme: "(", Pos: start}, nil
	case ')':
		l.pos++
		return Token{Kind: TokenRParen, Lexeme: ")", Pos: start}, nil
	case ';':
		l.pos++
		return Token{Kind: TokenSemicolon, Lexeme: ";", Pos: start}, nil
	case '*':
		l.pos++
		return Token{Kind: TokenStar, Lexeme: "*", Pos: start}, nil
	case '=':
		l.pos++
		return Token{Kind: TokenEqual, Lexeme: "=", Pos: start}, nil
	case '\'':
		return l.lexString()
	}

	if isDigit(ch) || (ch == '-' && l.pos+1 < len(l.input) && isDigit(l.input[l.pos+1])) {
		if ch == '-' {
			l.pos++
		}
		for l.pos < len(l.input) && isDigit(l.input[l.pos]) {
			l.pos++
		}
		return Token{Kind: TokenNumber, Lexeme: l.input[start:l.pos], Pos: start}, nil
	}
	if isIdentStart(ch) {
		l.pos++
		for l.pos < len(l.input) && isIdentContinue(l.input[l.pos]) {
			l.pos++
		}
		word := l.input[start:l.pos]
		if kind, ok := keywords[strings.ToUpper(word)]; ok {
			return Token{Kind: kind, Lexeme: word, Pos: start}, nil
		}
		return Token{Kind: TokenIdentifier, Lexeme: word, Pos: start}, nil
	}
	return Token{}, fmt.Errorf("lex error at byte %d: unexpected character %q", start, ch)
}

func (l *Lexer) lexString() (Token, error) {
	start := l.pos
	l.pos++
	var b strings.Builder
	for l.pos < len(l.input) {
		ch := l.input[l.pos]
		if ch == '\'' {
			if l.pos+1 < len(l.input) && l.input[l.pos+1] == '\'' {
				b.WriteByte('\'')
				l.pos += 2
				continue
			}
			l.pos++
			return Token{Kind: TokenString, Lexeme: b.String(), Pos: start}, nil
		}
		b.WriteByte(ch)
		l.pos++
	}
	return Token{}, fmt.Errorf("lex error at byte %d: unterminated string literal", start)
}

func isSpace(ch byte) bool { return ch == ' ' || ch == '\t' || ch == '\r' || ch == '\n' }
func isDigit(ch byte) bool { return ch >= '0' && ch <= '9' }
func isIdentStart(ch byte) bool {
	return ch == '_' || (ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z')
}
func isIdentContinue(ch byte) bool { return isIdentStart(ch) || isDigit(ch) }

func NewParser(tokens []Token) *Parser { return &Parser{tokens: tokens} }

func (p *Parser) ParseStatement() (Statement, error) {
	var stmt Statement
	var err error
	switch p.peek().Kind {
	case TokenCreate:
		stmt, err = p.parseCreateTable()
	case TokenInsert:
		stmt, err = p.parseInsert()
	case TokenSelect:
		stmt, err = p.parseSelect()
	case TokenDelete:
		stmt, err = p.parseDelete()
	case TokenBegin:
		p.advance()
		p.match(TokenTransaction)
		stmt = &BeginStmt{}
	case TokenCommit:
		p.advance()
		p.match(TokenTransaction)
		stmt = &CommitStmt{}
	case TokenRollback:
		p.advance()
		p.match(TokenTransaction)
		stmt = &RollbackStmt{}
	default:
		return nil, p.errorf(p.peek(), "expected CREATE, INSERT, SELECT, DELETE, BEGIN, COMMIT, or ROLLBACK")
	}
	if err != nil {
		return nil, err
	}
	p.match(TokenSemicolon)
	if p.peek().Kind != TokenEOF {
		return nil, p.errorf(p.peek(), "unexpected token after statement")
	}
	return stmt, nil
}

func (p *Parser) parseCreateTable() (Statement, error) {
	p.advance() // CREATE
	if _, err := p.expect(TokenTable, "expected TABLE after CREATE"); err != nil {
		return nil, err
	}
	name, err := p.expect(TokenIdentifier, "expected table name")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenLParen, "expected '(' after table name"); err != nil {
		return nil, err
	}
	var columns []ColumnDef
	for {
		colName, err := p.expect(TokenIdentifier, "expected column name")
		if err != nil {
			return nil, err
		}
		typeSpec, err := p.parseTypeSpec()
		if err != nil {
			return nil, err
		}
		nullable := true // SQL columns are nullable unless constrained NOT NULL.
		if p.match(TokenNot) {
			if _, err := p.expect(TokenNull, "expected NULL after NOT"); err != nil {
				return nil, err
			}
			nullable = false
		} else if p.match(TokenNull) {
			nullable = true
		}
		columns = append(columns, ColumnDef{Name: colName.Lexeme, Type: typeSpec, Nullable: nullable})
		if p.match(TokenComma) {
			continue
		}
		break
	}
	if _, err := p.expect(TokenRParen, "expected ')' after column definitions"); err != nil {
		return nil, err
	}
	return &CreateTableStmt{Name: name.Lexeme, Columns: columns}, nil
}

func (p *Parser) parseTypeSpec() (TypeSpec, error) {
	tok := p.advance()
	switch tok.Kind {
	case TokenInt:
		return TypeSpec{Type: TypeInt64}, nil
	case TokenBool:
		return TypeSpec{Type: TypeBool}, nil
	case TokenText:
		if _, err := p.expect(TokenLParen, "expected '(' after TEXT"); err != nil {
			return TypeSpec{}, err
		}
		nTok, err := p.expect(TokenNumber, "expected maximum length inside TEXT(...)")
		if err != nil {
			return TypeSpec{}, err
		}
		n, err := strconv.Atoi(nTok.Lexeme)
		if err != nil || n < 1 || n > MaxTextLen {
			return TypeSpec{}, p.errorf(nTok, "TEXT length must be 1..%d", MaxTextLen)
		}
		if _, err := p.expect(TokenRParen, "expected ')' after TEXT length"); err != nil {
			return TypeSpec{}, err
		}
		return TypeSpec{Type: TypeText, TextLen: uint16(n)}, nil
	default:
		return TypeSpec{}, p.errorf(tok, "expected INT, BOOL, or TEXT(n)")
	}
}

func (p *Parser) parseInsert() (Statement, error) {
	p.advance() // INSERT
	if _, err := p.expect(TokenInto, "expected INTO after INSERT"); err != nil {
		return nil, err
	}
	table, err := p.expect(TokenIdentifier, "expected table name")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenValues, "expected VALUES after table name"); err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenLParen, "expected '(' after VALUES"); err != nil {
		return nil, err
	}
	var values []Literal
	if p.peek().Kind != TokenRParen {
		for {
			v, err := p.parseLiteral()
			if err != nil {
				return nil, err
			}
			values = append(values, v)
			if p.match(TokenComma) {
				continue
			}
			break
		}
	}
	if _, err := p.expect(TokenRParen, "expected ')' after VALUES list"); err != nil {
		return nil, err
	}
	return &InsertStmt{Table: table.Lexeme, Values: values}, nil
}

func (p *Parser) parseSelect() (Statement, error) {
	p.advance() // SELECT
	stmt := &SelectStmt{}
	if p.match(TokenStar) {
		stmt.All = true
	} else {
		for {
			name, err := p.expect(TokenIdentifier, "expected column name or '*'")
			if err != nil {
				return nil, err
			}
			stmt.Columns = append(stmt.Columns, name.Lexeme)
			if p.match(TokenComma) {
				continue
			}
			break
		}
	}
	if _, err := p.expect(TokenFrom, "expected FROM after SELECT list"); err != nil {
		return nil, err
	}
	table, err := p.expect(TokenIdentifier, "expected table name after FROM")
	if err != nil {
		return nil, err
	}
	stmt.Table = table.Lexeme
	if p.match(TokenWhere) {
		expr, err := p.parseEquality()
		if err != nil {
			return nil, err
		}
		stmt.Where = expr
	}
	return stmt, nil
}

func (p *Parser) parseDelete() (Statement, error) {
	p.advance() // DELETE
	if _, err := p.expect(TokenFrom, "expected FROM after DELETE"); err != nil {
		return nil, err
	}
	table, err := p.expect(TokenIdentifier, "expected table name")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenWhere, "Part 6 DELETE requires a WHERE clause"); err != nil {
		return nil, err
	}
	expr, err := p.parseEquality()
	if err != nil {
		return nil, err
	}
	return &DeleteStmt{Table: table.Lexeme, Where: expr}, nil
}

func (p *Parser) parseEquality() (Expr, error) {
	leftTok, err := p.expect(TokenIdentifier, "expected column name on left side of WHERE")
	if err != nil {
		return nil, err
	}
	if _, err := p.expect(TokenEqual, "Part 7 supports only '=' comparisons"); err != nil {
		return nil, err
	}
	lit, err := p.parseLiteral()
	if err != nil {
		return nil, err
	}
	return &BinaryExpr{Left: &IdentifierExpr{Name: leftTok.Lexeme}, Operator: TokenEqual, Right: &LiteralExpr{Value: lit}}, nil
}

func (p *Parser) parseLiteral() (Literal, error) {
	tok := p.advance()
	switch tok.Kind {
	case TokenNumber:
		n, err := strconv.ParseInt(tok.Lexeme, 10, 64)
		if err != nil {
			return Literal{}, p.errorf(tok, "integer is outside int64 range")
		}
		return Literal{Kind: LiteralInt, Int: n}, nil
	case TokenString:
		return Literal{Kind: LiteralString, Text: tok.Lexeme}, nil
	case TokenTrue:
		return Literal{Kind: LiteralBool, Bool: true}, nil
	case TokenFalse:
		return Literal{Kind: LiteralBool, Bool: false}, nil
	case TokenNull:
		return Literal{Kind: LiteralNull}, nil
	default:
		return Literal{}, p.errorf(tok, "expected literal value")
	}
}

func (p *Parser) peek() Token {
	if p.pos >= len(p.tokens) {
		return Token{Kind: TokenEOF}
	}
	return p.tokens[p.pos]
}
func (p *Parser) advance() Token {
	tok := p.peek()
	if p.pos < len(p.tokens) {
		p.pos++
	}
	return tok
}
func (p *Parser) match(kind TokenKind) bool {
	if p.peek().Kind == kind {
		p.pos++
		return true
	}
	return false
}
func (p *Parser) expect(kind TokenKind, message string) (Token, error) {
	if p.peek().Kind != kind {
		return Token{}, p.errorf(p.peek(), message)
	}
	return p.advance(), nil
}
func (p *Parser) errorf(tok Token, format string, args ...any) error {
	return fmt.Errorf("parse error at byte %d near %q: %s", tok.Pos, tok.Lexeme, fmt.Sprintf(format, args...))
}

func DescribeAST(stmt Statement) string {
	var b strings.Builder
	var writeExpr func(Expr, string)
	writeExpr = func(e Expr, indent string) {
		switch x := e.(type) {
		case *IdentifierExpr:
			fmt.Fprintf(&b, "%sIdentifier %s\n", indent, x.Name)
		case *LiteralExpr:
			fmt.Fprintf(&b, "%sLiteral %s\n", indent, literalString(x.Value))
		case *BinaryExpr:
			fmt.Fprintf(&b, "%sBinary %s\n", indent, x.Operator)
			writeExpr(x.Left, indent+"  ")
			writeExpr(x.Right, indent+"  ")
		}
	}
	switch s := stmt.(type) {
	case *CreateTableStmt:
		fmt.Fprintf(&b, "CreateTable %s\n", s.Name)
		for _, c := range s.Columns {
			nullText := "NULL"
			if !c.Nullable {
				nullText = "NOT NULL"
			}
			if c.Type.Type == TypeText {
				fmt.Fprintf(&b, "  Column %s TEXT(%d) %s\n", c.Name, c.Type.TextLen, nullText)
			} else {
				fmt.Fprintf(&b, "  Column %s %s %s\n", c.Name, c.Type.Type, nullText)
			}
		}
	case *InsertStmt:
		fmt.Fprintf(&b, "Insert %s\n", s.Table)
		for _, v := range s.Values {
			fmt.Fprintf(&b, "  %s\n", literalString(v))
		}
	case *SelectStmt:
		fmt.Fprintf(&b, "Select from %s\n", s.Table)
		if s.All {
			b.WriteString("  Columns *\n")
		} else {
			fmt.Fprintf(&b, "  Columns %s\n", strings.Join(s.Columns, ", "))
		}
		if s.Where != nil {
			b.WriteString("  Where\n")
			writeExpr(s.Where, "    ")
		}
	case *DeleteStmt:
		fmt.Fprintf(&b, "Delete from %s\n  Where\n", s.Table)
		writeExpr(s.Where, "    ")
	case *BeginStmt:
		b.WriteString("BeginTransaction\n")
	case *CommitStmt:
		b.WriteString("CommitTransaction\n")
	case *RollbackStmt:
		b.WriteString("RollbackTransaction\n")
	}
	return b.String()
}

func literalString(v Literal) string {
	switch v.Kind {
	case LiteralInt:
		return fmt.Sprintf("INT %d", v.Int)
	case LiteralString:
		return fmt.Sprintf("STRING %q", v.Text)
	case LiteralBool:
		return fmt.Sprintf("BOOL %t", v.Bool)
	case LiteralNull:
		return "NULL"
	default:
		return "?"
	}
}

// RowCursor is the pull-based execution interface used by Part 7.
// Each call to Next returns at most one visible row and remembers
// enough state to continue on the next call.
type RowCursor interface {
	Next() (Row, bool, error)
}

// TableScanCursor walks the table's linked list of data pages directly.
// It does not call Store.Scan and does not materialize the whole table.
type TableScanCursor struct {
	store   *Store
	table   *Table
	pageNum uint64
	page    *Page
	slot    int
}

func NewTableScanCursor(store *Store, table *Table) *TableScanCursor {
	return &TableScanCursor{store: store, table: table, pageNum: table.firstData}
}

func (c *TableScanCursor) Next() (Row, bool, error) {
	for c.pageNum != 0 {
		if c.page == nil {
			page, err := c.store.pager.GetPage(c.pageNum)
			if err != nil {
				return Row{}, false, err
			}
			if err := validateDataPage(page, c.table); err != nil {
				return Row{}, false, err
			}
			c.page = page
			c.slot = 0
		}

		count := dataSlotCount(c.page)
		for c.slot < count {
			slot := c.slot
			c.slot++

			start, end, err := rowRange(c.table, slot)
			if err != nil {
				return Row{}, false, err
			}
			row, err := DecodeRow(c.table.Schema, c.page.Data[start:end])
			if err != nil {
				return Row{}, false, err
			}
			if row.Deleted {
				continue
			}
			return row, true, nil
		}

		c.pageNum = dataNextPage(c.page)
		c.page = nil
	}
	return Row{}, false, nil
}

// RowIDLookupCursor turns the B+tree point lookup into the same interface
// as a scan. That lets higher execution operators ignore how rows arrive.
type RowIDLookupCursor struct {
	store *Store
	table *Table
	rowID int64
	done  bool
}

func NewRowIDLookupCursor(store *Store, table *Table, rowID int64) *RowIDLookupCursor {
	return &RowIDLookupCursor{store: store, table: table, rowID: rowID}
}

func (c *RowIDLookupCursor) Next() (Row, bool, error) {
	if c.done {
		return Row{}, false, nil
	}
	c.done = true
	row, err := c.store.Get(c.table.Name, c.rowID)
	if err == ErrNotFound || err == ErrDeleted {
		return Row{}, false, nil
	}
	if err != nil {
		return Row{}, false, err
	}
	return row, true, nil
}

type CompiledPredicate struct {
	rowID       bool
	columnIndex int
	literal     Literal
}

func CompilePredicate(table *Table, expr Expr) (CompiledPredicate, error) {
	b, ok := expr.(*BinaryExpr)
	if !ok || b.Operator != TokenEqual {
		return CompiledPredicate{}, fmt.Errorf("Part 7 supports equality predicates only")
	}
	left, ok := b.Left.(*IdentifierExpr)
	if !ok {
		return CompiledPredicate{}, fmt.Errorf("left side of WHERE must be a column name")
	}
	right, ok := b.Right.(*LiteralExpr)
	if !ok {
		return CompiledPredicate{}, fmt.Errorf("right side of WHERE must be a literal")
	}
	if right.Value.Kind == LiteralNull {
		return CompiledPredicate{}, fmt.Errorf("Part 7 does not implement IS NULL; '= NULL' is not a supported predicate")
	}

	if strings.EqualFold(left.Name, "rowid") {
		if right.Value.Kind != LiteralInt {
			return CompiledPredicate{}, fmt.Errorf("rowid must be compared with an integer")
		}
		return CompiledPredicate{rowID: true, columnIndex: -1, literal: right.Value}, nil
	}

	for i, col := range table.Schema.Columns {
		if !strings.EqualFold(col.Name, left.Name) {
			continue
		}
		switch col.Type {
		case TypeInt64:
			if right.Value.Kind != LiteralInt {
				return CompiledPredicate{}, fmt.Errorf("column %s expects an INT predicate", col.Name)
			}
		case TypeText:
			if right.Value.Kind != LiteralString {
				return CompiledPredicate{}, fmt.Errorf("column %s expects a quoted TEXT predicate", col.Name)
			}
			if len([]byte(right.Value.Text)) > int(col.MaxLen) {
				return CompiledPredicate{}, fmt.Errorf("column %s allows at most %d UTF-8 bytes", col.Name, col.MaxLen)
			}
		case TypeBool:
			if right.Value.Kind != LiteralBool {
				return CompiledPredicate{}, fmt.Errorf("column %s expects a BOOL predicate", col.Name)
			}
		default:
			return CompiledPredicate{}, fmt.Errorf("column %s has unsupported type %s", col.Name, col.Type)
		}
		return CompiledPredicate{columnIndex: i, literal: right.Value}, nil
	}
	return CompiledPredicate{}, fmt.Errorf("column %q not found in table %s", left.Name, table.Name)
}

func (p CompiledPredicate) Matches(row Row) bool {
	if p.rowID {
		return row.RowID == p.literal.Int
	}
	if p.columnIndex < 0 || p.columnIndex >= len(row.Values) {
		return false
	}
	value := row.Values[p.columnIndex]
	if value.Null {
		return false
	}
	switch p.literal.Kind {
	case LiteralInt:
		return value.Type == TypeInt64 && value.Int == p.literal.Int
	case LiteralString:
		return value.Type == TypeText && value.Text == p.literal.Text
	case LiteralBool:
		return value.Type == TypeBool && value.Bool == p.literal.Bool
	default:
		return false
	}
}

// FilterCursor is an execution operator. It pulls rows from its child until
// one satisfies the compiled predicate, then yields that row to its parent.
type FilterCursor struct {
	child     RowCursor
	predicate CompiledPredicate
}

func NewFilterCursor(child RowCursor, predicate CompiledPredicate) *FilterCursor {
	return &FilterCursor{child: child, predicate: predicate}
}

func (c *FilterCursor) Next() (Row, bool, error) {
	for {
		row, ok, err := c.child.Next()
		if err != nil || !ok {
			return Row{}, ok, err
		}
		if c.predicate.Matches(row) {
			return row, true, nil
		}
	}
}

package main

import (
	"errors"
	"fmt"
	"strconv"
	"strings"
)

type ExecutionResult struct {
	Columns []string
	Rows    [][]string
	Message string
}

func ExecuteStatement(store *Store, stmt Statement) (ExecutionResult, error) {
	switch stmt.(type) {
	case *BeginStmt, *CommitStmt, *RollbackStmt, *SelectStmt:
		return executeStatementBody(store, stmt)
	}

	// Mutating SQL outside an explicit transaction runs in its own automatic
	// transaction. This is the simplest useful form of autocommit.
	if store.InTransaction() {
		return executeStatementBody(store, stmt)
	}
	if err := store.Begin(); err != nil {
		return ExecutionResult{}, err
	}
	result, err := executeStatementBody(store, stmt)
	if err != nil {
		_ = store.Rollback()
		return ExecutionResult{}, err
	}
	if err := store.Commit(); err != nil {
		_ = store.Rollback()
		return ExecutionResult{}, err
	}
	return result, nil
}

func executeStatementBody(store *Store, stmt Statement) (ExecutionResult, error) {
	switch s := stmt.(type) {
	case *CreateTableStmt:
		cols := make([]Column, len(s.Columns))
		for i, c := range s.Columns {
			cols[i] = Column{Name: c.Name, Type: c.Type.Type, MaxLen: c.Type.TextLen, Nullable: c.Nullable}
		}
		t, err := store.CreateTable(s.Name, cols)
		if err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: fmt.Sprintf("created table=%s id=%d row_size=%d root_page=%d", t.Name, t.ID, t.Schema.RowSize, t.tree.RootPage())}, nil

	case *InsertStmt:
		t, err := store.Table(s.Table)
		if err != nil {
			return ExecutionResult{}, err
		}
		if len(s.Values) != len(t.Schema.Columns) {
			return ExecutionResult{}, fmt.Errorf("table %s expects %d values, got %d", t.Name, len(t.Schema.Columns), len(s.Values))
		}
		values := make([]Value, len(s.Values))
		for i, lit := range s.Values {
			v, err := literalToValue(t.Schema.Columns[i], lit)
			if err != nil {
				return ExecutionResult{}, err
			}
			values[i] = v
		}
		rowID, err := store.Insert(t.Name, values)
		if err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: fmt.Sprintf("inserted 1 row (rowid=%d)", rowID)}, nil

	case *SelectStmt:
		return executeSelect(store, s)

	case *DeleteStmt:
		return executeDelete(store, s)

	case *BeginStmt:
		if err := store.Begin(); err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: "transaction started"}, nil

	case *CommitStmt:
		if err := store.Commit(); err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: "transaction committed"}, nil

	case *RollbackStmt:
		if err := store.Rollback(); err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: "transaction rolled back"}, nil

	default:
		return ExecutionResult{}, fmt.Errorf("unsupported statement %T", stmt)
	}
}

func literalToValue(c Column, lit Literal) (Value, error) {
	if lit.Kind == LiteralNull {
		if !c.Nullable {
			return Value{}, fmt.Errorf("column %s is NOT NULL", c.Name)
		}
		return Value{Type: c.Type, Null: true}, nil
	}
	v := Value{Type: c.Type}
	switch c.Type {
	case TypeInt64:
		if lit.Kind != LiteralInt {
			return Value{}, fmt.Errorf("column %s expects INT", c.Name)
		}
		v.Int = lit.Int
	case TypeBool:
		if lit.Kind != LiteralBool {
			return Value{}, fmt.Errorf("column %s expects BOOL", c.Name)
		}
		v.Bool = lit.Bool
	case TypeText:
		if lit.Kind != LiteralString {
			return Value{}, fmt.Errorf("column %s expects a quoted TEXT literal", c.Name)
		}
		if len([]byte(lit.Text)) > int(c.MaxLen) {
			return Value{}, fmt.Errorf("column %s allows at most %d UTF-8 bytes", c.Name, c.MaxLen)
		}
		v.Text = lit.Text
	default:
		return Value{}, fmt.Errorf("unsupported column type %s", c.Type)
	}
	return v, nil
}

func executeSelect(store *Store, s *SelectStmt) (ExecutionResult, error) {
	t, err := store.Table(s.Table)
	if err != nil {
		return ExecutionResult{}, err
	}
	projection, err := resolveProjection(t, s)
	if err != nil {
		return ExecutionResult{}, err
	}

	cursor, _, err := buildRowSource(store, t, s.Where)
	if err != nil {
		return ExecutionResult{}, err
	}

	result := ExecutionResult{Columns: projection.headers}
	for {
		row, ok, err := cursor.Next()
		if err != nil {
			return ExecutionResult{}, err
		}
		if !ok {
			break
		}
		out := make([]string, len(projection.items))
		for i, item := range projection.items {
			if item.rowID {
				out[i] = strconv.FormatInt(row.RowID, 10)
			} else {
				out[i] = FormatValue(row.Values[item.columnIndex])
			}
		}
		result.Rows = append(result.Rows, out)
	}
	return result, nil
}

func executeDelete(store *Store, s *DeleteStmt) (ExecutionResult, error) {
	t, err := store.Table(s.Table)
	if err != nil {
		return ExecutionResult{}, err
	}

	// The fast path stays fast: a rowid equality can go straight through
	// the persistent B+tree without scanning the table.
	if rowID, err := rowIDPredicate(s.Where); err == nil {
		err := store.Delete(t.Name, rowID)
		if errors.Is(err, ErrNotFound) || errors.Is(err, ErrDeleted) {
			return ExecutionResult{Message: "deleted 0 rows"}, nil
		}
		if err != nil {
			return ExecutionResult{}, err
		}
		return ExecutionResult{Message: "deleted 1 row"}, nil
	}

	// General equality predicates are executed by a scan + filter cursor.
	// First collect rowids, then mutate. This keeps the scan phase simple.
	cursor, _, err := buildRowSource(store, t, s.Where)
	if err != nil {
		return ExecutionResult{}, err
	}
	var ids []int64
	for {
		row, ok, err := cursor.Next()
		if err != nil {
			return ExecutionResult{}, err
		}
		if !ok {
			break
		}
		ids = append(ids, row.RowID)
	}
	for _, id := range ids {
		if err := store.Delete(t.Name, id); err != nil {
			return ExecutionResult{}, fmt.Errorf("delete rowid %d: %w", id, err)
		}
	}
	return ExecutionResult{Message: fmt.Sprintf("deleted %d row(s)", len(ids))}, nil
}

func buildRowSource(store *Store, t *Table, where Expr) (RowCursor, []string, error) {
	if where == nil {
		return NewTableScanCursor(store, t), []string{fmt.Sprintf("TableScan(table=%s)", t.Name)}, nil
	}

	if rowID, err := rowIDPredicate(where); err == nil {
		return NewRowIDLookupCursor(store, t, rowID), []string{fmt.Sprintf("RowIDLookup(table=%s, rowid=%d)", t.Name, rowID)}, nil
	}

	pred, err := CompilePredicate(t, where)
	if err != nil {
		return nil, nil, err
	}
	scan := NewTableScanCursor(store, t)
	return NewFilterCursor(scan, pred), []string{
		fmt.Sprintf("Filter(%s)", describeExprInline(where)),
		fmt.Sprintf("TableScan(table=%s)", t.Name),
	}, nil
}

func ExplainStatement(store *Store, stmt Statement) (string, error) {
	switch s := stmt.(type) {
	case *CreateTableStmt:
		return fmt.Sprintf("CreateTable(table=%s)\n  -> Catalog + B+tree allocation\n", s.Name), nil
	case *InsertStmt:
		t, err := store.Table(s.Table)
		if err != nil {
			return "", err
		}
		return fmt.Sprintf("Insert(table=%s)\n  -> EncodeRow(row_size=%d)\n  -> AppendDataRow\n  -> BTreeInsert(rowid -> pointer)\n", t.Name, t.Schema.RowSize), nil
	case *SelectStmt:
		t, err := store.Table(s.Table)
		if err != nil {
			return "", err
		}
		p, err := resolveProjection(t, s)
		if err != nil {
			return "", err
		}
		_, source, err := buildRowSource(store, t, s.Where)
		if err != nil {
			return "", err
		}
		var b strings.Builder
		fmt.Fprintf(&b, "Project(%s)\n", strings.Join(p.headers, ", "))
		for _, line := range source {
			fmt.Fprintf(&b, "  -> %s\n", line)
		}
		return b.String(), nil
	case *DeleteStmt:
		t, err := store.Table(s.Table)
		if err != nil {
			return "", err
		}
		if rowID, err := rowIDPredicate(s.Where); err == nil {
			return fmt.Sprintf("Delete(table=%s)\n  -> RowIDLookup(rowid=%d)\n  -> TombstoneRow\n", t.Name, rowID), nil
		}
		_, source, err := buildRowSource(store, t, s.Where)
		if err != nil {
			return "", err
		}
		var b strings.Builder
		fmt.Fprintf(&b, "Delete(table=%s)\n", t.Name)
		for _, line := range source {
			fmt.Fprintf(&b, "  -> %s\n", line)
		}
		b.WriteString("  -> TombstoneMatchingRows\n")
		return b.String(), nil
	case *BeginStmt:
		return "BeginTransaction\n  -> Create rollback journal\n  -> Remember original database length\n", nil
	case *CommitStmt:
		return "CommitTransaction\n  -> Journal before-images for overwritten pages\n  -> Flush + fsync database\n  -> Delete rollback journal\n", nil
	case *RollbackStmt:
		return "RollbackTransaction\n  -> Restore journaled before-images\n  -> Truncate newly allocated pages\n  -> Reload catalog state\n", nil
	default:
		return "", fmt.Errorf("cannot explain statement %T", stmt)
	}
}

func describeExprInline(expr Expr) string {
	b, ok := expr.(*BinaryExpr)
	if !ok {
		return "expression"
	}
	left, _ := b.Left.(*IdentifierExpr)
	right, _ := b.Right.(*LiteralExpr)
	if left == nil || right == nil {
		return "expression"
	}
	var value string
	switch right.Value.Kind {
	case LiteralInt:
		value = strconv.FormatInt(right.Value.Int, 10)
	case LiteralString:
		value = strconv.Quote(right.Value.Text)
	case LiteralBool:
		value = strconv.FormatBool(right.Value.Bool)
	case LiteralNull:
		value = "NULL"
	default:
		value = "?"
	}
	return fmt.Sprintf("%s = %s", left.Name, value)
}

type projectionItem struct {
	rowID       bool
	columnIndex int
}
type resolvedProjection struct {
	headers []string
	items   []projectionItem
}

func resolveProjection(t *Table, s *SelectStmt) (resolvedProjection, error) {
	if s.All {
		p := resolvedProjection{headers: []string{"rowid"}, items: []projectionItem{{rowID: true}}}
		for i, c := range t.Schema.Columns {
			p.headers = append(p.headers, c.Name)
			p.items = append(p.items, projectionItem{columnIndex: i})
		}
		return p, nil
	}
	var p resolvedProjection
	for _, name := range s.Columns {
		if strings.EqualFold(name, "rowid") {
			p.headers = append(p.headers, "rowid")
			p.items = append(p.items, projectionItem{rowID: true})
			continue
		}
		idx := -1
		for i, c := range t.Schema.Columns {
			if strings.EqualFold(c.Name, name) {
				idx = i
				name = c.Name
				break
			}
		}
		if idx < 0 {
			return resolvedProjection{}, fmt.Errorf("column %q not found in table %s", name, t.Name)
		}
		p.headers = append(p.headers, name)
		p.items = append(p.items, projectionItem{columnIndex: idx})
	}
	return p, nil
}

func rowIDPredicate(expr Expr) (int64, error) {
	b, ok := expr.(*BinaryExpr)
	if !ok || b.Operator != TokenEqual {
		return 0, fmt.Errorf("predicate must be an equality")
	}
	left, ok := b.Left.(*IdentifierExpr)
	if !ok || !strings.EqualFold(left.Name, "rowid") {
		return 0, fmt.Errorf("left side must be rowid")
	}
	right, ok := b.Right.(*LiteralExpr)
	if !ok || right.Value.Kind != LiteralInt {
		return 0, fmt.Errorf("right side must be an integer")
	}
	if right.Value.Int < 1 {
		return 0, fmt.Errorf("rowid must be >= 1")
	}
	return right.Value.Int, nil
}

func printResult(r ExecutionResult) {
	if r.Message != "" {
		fmt.Println(r.Message)
	}

		return
	}

func handleMeta(store *Store, line string) bool {
	parts := strings.Fields(line)
	if len(parts) == 0 {
		return false
	}
	cmd := strings.ToLower(parts[0])
	switch cmd {
	case ".quit", ".exit":
		return true
	case ".help":
		fmt.Println("SQL:")
		fmt.Println("  CREATE TABLE t (name TEXT(40) NOT NULL, age INT, active BOOL);")
		fmt.Println("  INSERT INTO t VALUES ('alice', 30, true);")
		fmt.Println("  SELECT * FROM t;")
		fmt.Println("  SELECT rowid, name FROM t WHERE rowid = 1;")
		fmt.Println("  DELETE FROM t WHERE rowid = 1;")
		fmt.Println("  BEGIN;  COMMIT;  ROLLBACK;")
		fmt.Println("Meta commands:")
		fmt.Println("  .tables | .schema <table> | .tree <table> | .datapages <table>")
		fmt.Println("  .catalogpages | .stats | .flush | .verify | .pageinfo <n>")
		fmt.Println("  .tx | .journal | .crash")
		fmt.Println("  .tokens <sql> | .ast <sql> | .explain <sql> | .quit")
	case ".tables":
		tables := store.Tables()
		if len(tables) == 0 {
			fmt.Println("(no tables)")
			break
		}
		for _, t := range tables {
			fmt.Printf("id=%d name=%s columns=%d row_size=%d root_page=%d next_rowid=%d\n", t.ID, t.Name, len(t.Schema.Columns), t.Schema.RowSize, t.tree.RootPage(), t.nextRowID)
		}
	case ".schema":
		if len(parts) != 2 {
			fmt.Println("usage: .schema <table>")
			break
		}
		text, err := store.DescribeTable(parts[1])
		if err != nil {
			fmt.Println("schema error:", err)
		} else {
			fmt.Print(text)
		}
	case ".tree":
		if len(parts) != 2 {
			fmt.Println("usage: .tree <table>")
			break
		}
		text, err := store.TreeDump(parts[1])
		if err != nil {
			fmt.Println("tree error:", err)
		} else {
			fmt.Print(text)
		}
	case ".datapages":
		if len(parts) != 2 {
			fmt.Println("usage: .datapages <table>")
			break
		}
		pages, err := store.DataChain(parts[1])
		if err != nil {
			fmt.Println("data pages error:", err)
		} else {
			fmt.Println("data_pages=", pages)
		}
	case ".catalogpages":
		pages, err := store.CatalogPages()
		if err != nil {
			fmt.Println("catalog pages error:", err)
		} else {
			fmt.Println("catalog_pages=", pages)
		}
	case ".stats":
		st := store.Stats()
		fmt.Printf("pages=%d cached=%d cache_hits=%d disk_reads=%d disk_writes=%d validation_failures=%d\n", st.TotalPages, st.CachedPages, st.CacheHits, st.DiskReads, st.DiskWrites, st.ValidationFailures)
	case ".tx":
		if store.InTransaction() {
			fmt.Println("transaction=active")
		} else {
			fmt.Println("transaction=none (autocommit mode)")
		}
	case ".journal":
		info, err := store.JournalInfo()
		if err != nil {
			fmt.Println("journal error:", err)
		} else if !info.Exists {
			fmt.Println("journal=absent")
		} else {
			fmt.Printf("journal=present original_pages=%d entries=%d bytes=%d\n", info.OriginalPages, info.Entries, info.Size)
		}
	case ".crash":
		fmt.Println("simulating process crash now; deferred Close will NOT run")
		os.Exit(99)
	case ".flush":
		if err := store.Flush(); err != nil {
			fmt.Println("flush error:", err)
		} else {
			fmt.Println("dirty pages sealed, checksummed, and flushed")
		}
	case ".verify":
		pages, err := store.Verify()
		if err != nil {
			fmt.Println("verify error:", err)
		} else {
			fmt.Printf("verified %d pages\n", pages)
		}
	case ".pageinfo":
		if len(parts) != 2 {
			fmt.Println("usage: .pageinfo <page-number>")
			break
		}
		n, err := strconv.ParseUint(parts[1], 10, 64)
		if err != nil {
			fmt.Println("page number must be a non-negative integer")
			break
		}
		info, err := store.PageInfo(n)
		if err != nil {
			fmt.Println("pageinfo error:", err)
		} else {
			fmt.Printf("page=%d type=%s generation=%d checksum=%08x\n", info.Number, info.Type, info.Generation, info.Checksum)
		}
	case ".tokens":
		sql := strings.TrimSpace(strings.TrimPrefix(line, parts[0]))
		if sql == "" {
			fmt.Println("usage: .tokens <sql>")
			break
		}
		tokens, err := Lex(sql)
		if err != nil {
			fmt.Println(err)
			break
		}
		for _, tok := range tokens {
			fmt.Printf("%-10s pos=%-3d lexeme=%q\n", tok.Kind, tok.Pos, tok.Lexeme)
		}
	case ".explain":
		sql := strings.TrimSpace(strings.TrimPrefix(line, parts[0]))
		if sql == "" {
			fmt.Println("usage: .explain <sql>")
			break
		}
		stmt, err := ParseSQL(sql)
		if err != nil {
			fmt.Println(err)
			break
		}
		plan, err := ExplainStatement(store, stmt)
		if err != nil {
			fmt.Println("explain error:", err)
		} else {
			fmt.Print(plan)
		}
	case ".ast":
		sql := strings.TrimSpace(strings.TrimPrefix(line, parts[0]))
		if sql == "" {
			fmt.Println("usage: .ast <sql>")
			break
		}
		stmt, err := ParseSQL(sql)
		if err != nil {
			fmt.Println(err)
		} else {
			fmt.Print(DescribeAST(stmt))
		}
	default:
		fmt.Println("unknown meta command; try .help")
	}
	return false
}

func main() {
	if len(os.Args) != 2 {
		fmt.Println("usage: minidb <database-file>")
		os.Exit(1)
	}
	store, err := Open(os.Args[1])
	if err != nil {
		fmt.Println("open error:", err)
		os.Exit(1)
	}
	defer store.Close()

	fmt.Println("MiniSQLite Part 8 — Transactions and recovery")
	fmt.Println("Type .help for examples. SQL statements may end with ';'.")
	scanner := bufio.NewScanner(os.Stdin)
	for {
		fmt.Print("minidb> ")
		if !scanner.Scan() {
			fmt.Println()
			break
		}
		line := strings.TrimSpace(scanner.Text())
		if line == "" {
			continue
		}
		if strings.HasPrefix(line, ".") {
			if handleMeta(store, line) {
				return
			}
			continue
		}
		stmt, err := ParseSQL(line)
		if err != nil {
			fmt.Println(err)
			continue
		}
		result, err := ExecuteStatement(store, stmt)
		if err != nil {
			fmt.Println("execution error:", err)
			continue
		}
		printResult(result)
	}
	if err := scanner.Err(); err != nil {
		fmt.Println("input error:", err)
	}
}

36. What you should understand before leaving Part 8

Do not measure success by whether you can recite RollbackJournal. You should be able to reason through these questions without looking at the implementation:

  1. Why can every page pass its checksum while the database is still transactionally inconsistent?
  2. What exactly is a before-image?
  3. Why must the journal entry be synced before its database page is overwritten?
  4. Why do newly allocated pages need truncation rather than before-images?
  5. Why must rollback discard/reload in-memory metadata too?
  6. Why is an existing journal checked before page 0 is interpreted on startup?
  7. What is the difference between “page was flushed” and “transaction committed”?
  8. Why is this design called a rollback journal rather than a redo/WAL design?
  9. What stronger meaning does autocommit give to a successful standalone INSERT?
  10. Which concurrency and filesystem guarantees are still missing?

If those answers are clear, you now understand the core reason database transactions require a storage protocol, not merely BEGIN and COMMIT keywords.

The next pressure point

We now have pages, integrity checks, B+trees, schemas, SQL, execution, and crash-safe transaction rollback. The next major database layers can build on a storage engine whose changes have an explicit atomicity boundary instead of hoping several page writes happen together.
