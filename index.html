10-part systems programming series

Build a small database engine from scratch.

MiniSQLite is a hands-on Go tutorial that starts with bytes in a file and ends with SQL parsing, query execution, transactions, secondary indexes, WAL, concurrency, and durability. Each chapter derives the idea first, then builds it in small runnable steps.

Start with Part 1View on GitHub

The series

The goal is not to copy a finished database. It is to understand why each layer exists by first feeling the limitation that forces the next design.

What you build

Every part keeps the previous layers visible. By Part 10 the same engine has a pager, checksummed pages, B+trees, schemas, SQL, cursors, recovery, planning, WAL, and a simple concurrency model.

How to use it

Work through the chapters in order. Type the small checkpoints, run them, inspect the files on disk, break things deliberately, and only use the complete source appendix after you understand how the pieces were derived.
